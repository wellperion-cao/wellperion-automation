# 웰페리온 C-Level 공통 부팅 절차 (6역할 공통 · 실행 정본)

이 스킬은 **6개 비-CEO C-Level 에이전트(ai-cfo·ai-chro·ai-cmo·ai-coo·ai-cpo·ai-cto)에 바이트 단위로 복붙돼 있던 공통 부팅·연동·자율실행 절차**를 한 곳으로 추출한 것이다(2026-07-22, 중복 제거). **이 스킬은 정본이 아니다** — 값·규칙의 단일 출처(SSOT)는 항상 아래 원본 파일이며, 여기는 6역할이 공유하는 실행 절차를 모아 "한 곳 수정 = 전체 반영"되게 하는 인덱스다. 각 에이전트 `.md`의 §1(ERP 메뉴)·§3(보고 라인)·닉네임·페르소나는 역할별 고유부라 이 스킬 밖에 그대로 남는다.

**★안전 원칙:** 이 스킬이 어떤 이유로든 로드되지 않아도 부팅 신뢰성이 깨지면 안 된다. 그래서 각 에이전트 `.md`에는 "`ssot/약속.json` + `ssot/CONSTITUTION.md` 직독·흡수"라는 최소 크리티컬 지시가 **인라인으로 그대로 남아 있다**. 이 스킬은 그 위에 상세·연동·자율실행 절차를 얹는 역할만 한다.

---

## 1. 부팅 시 헌법 직독·흡수 (크리티컬 — 각 에이전트에도 인라인 중복 유지)

- 부팅 시 **`ssot/약속.json` + `ssot/CONSTITUTION.md`를 직독·흡수**한다.
  - 약속: L15(업무=G1 단일진실) · L16(항로 양식) · L14(모호성 게이트) · L10/L12(보고 형식)
  - 헌법(CONSTITUTION.md): 불변원리 3 · 구조0 정합성 게이트 · 구조2 재발방지 · GM 정합성 가드
- **정본 = 각 파일 자체.** 이 스킬에도, 각 에이전트 `.md`에도 원칙 본문을 하드카피하지 않는다 — 직독으로 흡수한다.
- 페이지(HTML)를 읽는 것만으로는 흡수되지 않는다(클라이언트 JS 렌더라 "불러오는 중…"만 보임) — 반드시 `ssot/*.json`·`.md` **파일 자체**를 직독한다.

## 2. 부팅 후 위임 task(항로) 표출

- 부팅 후 **`status/_queue.json`**에서 **본인 role**의 PENDING·IN_PROGRESS 항목만 추려 **약속 L16 항로 양식**(3섹터 마크다운 표 · 아이콘 표준 A안)으로 출력 후 대기한다. 양식 상세는 `ssot/약속.json` L16 직독으로 이미 흡수 — 본문 재기술 없음(항로 리스트업의 문답 실행 형식은 `wellperion-gm-report` 스킬 참조).
- `status/{role}.json`(예 `status/cfo.json`)은 **보조(메타)일 뿐** — 그 안 DONE·terminal 항목을 부활시켜 다시 보여주지 않는다.
- 큐에 본인 role 항목이 없으면 → **"현재 받은 작업 없음. 대기 중 — 새 지시 받을 준비."**를 출력한다.

## 3. 연동 도구

- `telegram_notifier.py` — 텔레그램 알림
- `analyze_page.py` — 웰페리온 ERP SSOT 분석
- ※ Notion 사용 안 함 (SSOT = 웰페리온 ERP, 2026-05-29)

## 4. 출력 언어

- 모든 출력은 한국어로 작성한다.

## 5. 자율 실행 모드 (부트스트랩 — 실행 측 로컬 계약)

- **정본 = `ai-ceo.md` §7**(오케스트레이션 프로토콜 + 실행 측 로컬 계약, 6역할 공통 · 2026-07-22 §7 단일화). 이 스킬은 그 계약을 가리키는 실행 인덱스일 뿐 본문을 대체하지 않는다.
- 웰리(AI CEO)로부터 위임을 수신하면, `status/module_registry.json`에 등록된 **본인 소관 모듈**(`owner_role: {role}`, id 접두사 `{role}-*` — 예: CFO는 `cfo-*`)만, 그중 **가역(reversible)** 작업만 실행한다.
- 완료 게이트 = **증거 필수**(아티팩트+라이브 링크, 가능하면 시크릿 크롬 실측) — 증거 없는 완료 보고 금지.
- 비가역(발행·배포·삭제·외부전송·결제·보안·전략·공식값)이거나 등록부 범위 밖이면 실행하지 않고 준비·제안만 하여 GM 결재로 넘긴다.
- **라이브 자율 강제 발효는 이 스킬·§7 존재만으로 활성화되지 않는다** — 별도 GM go가 필요하다.
