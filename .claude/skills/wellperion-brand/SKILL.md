# 웰페리온 브랜드 가이드 (요약 · 실행용)

이 스킬은 **정본을 대체하지 않는다.** 값의 단일 출처(SSOT)는 항상 아래 두 파일이며, 여기는 빠르게 적용하기 위한 요약·인덱스다. 값이 바뀌면 SSOT만 고치고 이 파일은 손대지 않는다(자동 추종).

- **정본 ①** `scripts/brand_constants.py` — 색상 RGB·폰트 경로·로고 PNG 경로·`BRAND_PRESETS`(사업부별 팔레트). "새 값 도입 금지."
- **정본 ②** `3. 웰페리온 가이드/cmo/brand/브랜드가이드.html` — 통합 브랜드 가이드 페이지(컬러/폰트/로고/사진·영상/자막/금지어/CTA/캡션·두 계정·제작 원칙 전문). 구 `비주얼_스타일_가이드.md` 흡수·삭제(2026-07-18) — 인간용 브랜드 SSOT.
- **★제작 방향 정본 = 기반 (콘텐츠 만들기 전 필독)** `2. 브랜드_자료/웰페리온_기반_FOUNDATION.md` — 회사·전략·브랜드·각(운동↔마음)·절대 금지·두 계정·체크리스트를 통합한 **뿌리(FOUNDATION)**. 이 스킬=**HOW(비주얼·톤)**, 기반=**WHAT/WHY(회사·전략·각)** 짝. **자동 생성돼도 이 기반에서 안 벗어난다.** (구 제작기준_브리프 흡수·일원화 · 2026-07-18)
- 의심스러우면 요약 대신 **위 파일들을 직접 열어 확인**한다.

## 2. 색·폰트·로고

**정본 = `scripts/brand_constants.py`. 아래 값은 참조 편의용 — 변경은 반드시 그 파일에서.**

| 이름 | HEX | 용도 |
|---|---|---|
| BEIGE | `#B79F8A` | 브랜드 1차색 — 로고·강조 텍스트·분리선·풋터 |
| BLACK | `#221F20` | 배경·다크 오버레이 |
| HIGHLIGHT | `#ED5B3F` | 액센트 바·CTA 등 포인트에만 소량 |
| WHITE | `#FFFFFF` | 다크 배경 위 본문 텍스트 |

- 사업부별(스포츠클럽/스쿼시/PT/골프/수영/필라테스/체조/스파) 서브 팔레트는 `brand_constants.py`의 `BRAND_PRESETS` 딕셔너리가 유일한 출처 — 새로 정의하지 말고 그대로 호출. 모든 서브 브랜드의 액센트는 베이지 고정.
- 개인계정 에메랄드는 위 메인 팔레트와 별개 트랙(§1 참조) — 혼용 금지.
- 폰트: 본문·헤딩 전부 **Pretendard** (Bold=한글헤딩, SemiBold=본문, Medium=부가정보). 경로는 `brand_constants.py`의 `FONT_BOLD`/`FONT_SEMIBOLD`/`FONT_MEDIUM`. 공식 가이드의 ITC Avant Garde/Hudson NY는 유료라 자동화 파이프라인은 Pretendard로 통일(승인된 대체).
- 로고 PNG 자산: `instagram/_assets/logo/`(`wellperion_white_alpha.png`=사진 위, `wellperion_beige_alpha.png`=다크 배경). 풀 로고에 남은 "SPA & FITNESS" 표기는 GM 결재로 **현상 유지 확정**(재플래그 금지).

## 3. 사진·아이콘·캡션 형식

- **사진 톤 = 듀오톤 변환 필수.** 모든 메인/통일 슬라이드 사진은 BLACK↔BEIGE 듀오톤(`#221F20`↔`#B79F8A`) 처리. 정본 함수: `compose_barre.to_duotone()` (`compose_ballet`도 재사용). 원본 사진 자체는 따뜻한 뉴트럴·자연광·와이드 건축 구도·인물 없음이 브랜드 톤과 맞물림.
- **아이콘/일러스트 = 선(line)으로만.** 면 칠 아이콘 금지(공식 가이드 ILLUSTRATION 페이지).
- **캡션 = 평문 전용.** 마크다운(`###`, `**`, `_` 등) 절대 금지 — 인스타는 마크다운을 렌더링하지 않아 기호가 그대로 노출된다. 구조: 본문 → (선택)다음 편 떡밥 → CTA(§4) → 해시태그.
- 해시태그 순서 고정: ① 지역+종목(`#한남동골프`) → ② 종목·주제·타겟 → ③ `#웰페리온 #WELLPERION` 맨 끝 2개.

## 4. CTA 표준 문구

**전 채널 공통 텍스트(가이드라인 카드·릴스 마지막 장 등 이미지에 넣을 때) = 한 줄, 한국어만:**

```
문의 : wellperion.com/ko/inquiry
```

영어 줄(`/en/inquiry`)·`litt.ly` 링크는 2026-06-08 GM 결정으로 **폐기** — 한/영 2줄로 넣지 않는다.

**채널별 CTA 삽입 규칙(카드형/텍스트형/IG bio유도 등, 채널마다 다름)의 정본 = `scripts/cta_utm.py` 파일 상단 "CTA 단일화 설계" 주석(2026-07-20 GM 승인, 약속 L01).** 실제 발행 코드가 그 규칙대로 동작한다 — 여기서 다시 서술하지 않는다. 규칙이 바뀌면 그 파일만 고친다.
