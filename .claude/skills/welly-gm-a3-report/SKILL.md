## 3. 문서 구조 (5단 고정)

```
① 문서 헤더    브랜드 / 문서명 / 작성자·일자·문서번호 / 결재란(담당·GM·대표·회장)
   ▸작성자 표기 = **「AI 웰리」** 하나로 통일한다(GM 확정 2026-08-28). 「AI CEO 웰리」·「경영지원부 (AI CEO 웰리)」 로 쓰지 않는다. 담당·책임 표기는 그 옆에 따로 둔다.
② 결정 요청     "무엇을 결재받아야 하는가" — 최상단, 네이비 밴드, 최대 2건
   경고 밴드     견적 만료·비교 불가 등 치명적 결함 (있을 때만)
③ 비교표        열=선택지, 행=판단항목. 지면의 55%
④ 3분할         핵심 리스크 / 실행 액션 / GM 권고
⑤ 각주          추정치 표기, 산출 근거, 차기 보고 시점
```

**② 결정 요청** — "검토했습니다"가 아니라 **"이것을 결정해 주십시오"**로 쓴다. 3건 이상이면 문서를 분리.

**③ 비교표** — 아래 4개 그룹을 반드시 포함하고, 그룹 구분행으로 묶는다.

| 그룹 | 행 |
|---|---|
| 비용 | 계약형태 / 초기비용 / 월비용 / 3년 누계 / 5년 누계 (VAT 별도 명기) |
| 자산·서비스 | 만료 후 소유권 / 관제·출동 / A/S 조건 |
| 사양 충족도 | 수량 / 용량 / 필수장비 포함 / 제조사·원산지 |
| 검증 상태 | 견적 유효기간 / 단가 검증 가능 / 종합 위험도 |

**④ 3분할** — 각 박스 5줄 이내. 리스크는 ⚠️상 / △중 2단계.

**⑤ 각주** — **추정치에 반드시 `(추정)` 표기.** 확정 수치와 섞지 않는다.

## 4. 필수 검증 5종

작성 전 확인하고, 미충족 시 문서에 명시한다.

| # | 항목 | 미충족 표기 |
|---|---|---|
| 1 | 견적서 유효기간 경과 | `만료` 적색 + 상단 경고 밴드 |
| 2 | 단가·수량 공란 | `검증 불가` |
| 3 | 선택지 간 사양 동일성 | `직접 비교 불가` 경고 밴드 |
| 4 | 누락 장비·항목 | ⚠️ 리스크 박스 최상단 |
| 5 | 제조사·원산지·인증 | `미기재` |

> **절대 금지**: 사양이 다른 선택지를 같은 표에 넣고 "가장 싸다"고 결론 내리는 것. 1순위 액션은 항상 **"비교 가능하게 만드는 것"**이다.
