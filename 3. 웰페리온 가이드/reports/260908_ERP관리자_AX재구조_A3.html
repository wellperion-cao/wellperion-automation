③ 가르는 기준 모듈이냐 문서냐
모듈 카드로 남는 것
5칸을 다 채우고, 한 줄로 「누가 · 무엇을 · 어디에 남기는가」가 말해지는 것. 예: 「회원 등록 · 수정을 서버 원장에 남긴다 — 임정은M · /api/members」
문서로 내리는 것
읽기만 하는 안내 · 체계 · 가이드 35개. 지우지 않는다 — 관리자 화면 카드 자리에서 빼고 「문서함」 한 곳에 모은다
경계선(보는 화면 21개)
GM 판정 — 숫자가 매일 바뀌고 실무진이 그걸 보고 움직이면 모듈, 아니면 문서
④ 자산 한 원장 구독으로 가는 길
원장 통합 + 칸 하나 더
카드 · 자동화 · 에이전트 · 상담봇을 한 원장(등록부)에 모으고 칸 하나를 더 둔다: 「내부 전용 / 밖에 팔 수 있음 / 이미 파는 중」
이미 파는 중
상담봇(웰페리온 1호 · 다이어트캠프 2호 · 스포짐 3호 예정). 파는 것만 업체별로 복제한다 — 업체 추가 = 프로필 파일 1개 + 서버 경로 1줄
구독 단위
모듈 1개 = 월 구독 1건. 값은 GM 결재 전이라 이 장에 적지 않는다
⑤ UI/UX 개편 방향 4가지만
  • 1. 실행 화면만 카드 — 카드 자리에는 실행 화면만. 문서는 문서함 탭으로 분리
  • 2. 카드는 3줄 — 한 줄 설명 · 주인 · 상태 신호(초록/노랑/빨강)만. 그 밖의 글자는 뺀다
  • 3. 3축 배치 — 표준(규격 맞은 것) / 자산(내 것 목록) / 운영(오늘 상태)로 묶어 보여준다
  • 4. 역할별 노출 — 내 역할에 없는 카드는 아예 안 보이게. 지금은 전부 보여 실무진이 헤맨다
