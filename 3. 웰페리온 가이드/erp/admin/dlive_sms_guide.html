6. 관리자 화면 쓰는 법

경로: ERP 플랫폼관리 › 문자 발송
  1. 문구 고치기 — 목록에서 「편집」 → 본문 수정(45자 카운터가 바로 뜬다) → 저장. ✔ 이렇게 나오면 성공: 목록 미리보기 문장이 바뀐다
  2. 발효로 올리기 — 편집창의 「발효」 체크 → 저장. ✔ 목록 상태가 「발효」로 바뀐다(발효라야 화면 버튼 · 자동발송이 그 문구를 쓴다)
  3. 시험 발송 — 문구 선택 + 본인 번호 입력 + 「보내기」. ✔ 킬스위치가 켜져 있으면 본인 휴대폰에 문자가 온다(꺼져 있으면 로그에 dry 로만 남는다 — 실패 아님)
  4. 오늘 · 이달 건수 — 화면 맨 위 띠에서 바로 본다
  5. 발송 로그 보기 — 아래 표에서 최근 50건(시각 · 자리 · 상태 · 오류)을 본다

7. 문제 생기면

  • 킬스위치(SMS_ENABLED)가 켜져 있나 — 꺼져 있으면 dry 로만 남고 문자가 안 나간다
  • 오늘 상한(30건)이 안 찼나 — 찼으면 로그에 상태 「limit」이 뜬다
  • 딜라이브 잔액이 남아 있나 — 발송량 확인 웹에서 본다
  • 보내려는 문구가 「발효」 상태인가 — 초안이면 화면 버튼이 안 쓴다
  • 위 네 가지가 다 정상인데도 안 되면 — 서버 연결 문제이니 관리자(AI 시토)에게 전달한다

8. 카톡채널(알림톡) 확장

딜라이브는 같은 API 안(/kkomsg)에 알림톡 · 친구톡도 갖고 있다. 버튼 · 변수 · 문자 대체발송이 그 규격에 이미 있어 지금 쓰는 SMS 업체를 바꿀 필요가 없다. 언제 알림톡으로 넘어갈지는 GM 결정 사항이다.
