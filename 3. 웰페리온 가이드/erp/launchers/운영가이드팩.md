# ERP플랫폼관리 — 운영 가이드 팩

> 새 파트너사가 이 ERP 를 도입할 때 채워야 할 것의 지침서.
> 뼈대(frame)는 그대로 쓰고, 아래 파일만 새 회사 값으로 갈아끼우면 된다.
> 정본 = `ssot/tenant.json` > `new_tenant_onboarding`. 이 문서는 그 내용을 사람이 읽기 좋게 풀어 쓴 것이다.

---

## 1. 두 층 구조

| 층 | 소유자 | 내용 |
|---|---|---|
| **뼈대(frame)** | ERP플랫폼관리 | 원칙 조항·엔진 스크립트·보고 규격. 모든 파트너사가 공유 — 갈아끼우지 않는다 |
| **테넌트(tenant)** | 각 파트너사 | 회사명·색상·닉네임·채널. 회사마다 다르다 — 아래 파일을 채운다 |

---

## 2. 단계별 작업

### 1단계 — 필수 (반드시 바꿔야 함)

| 파일 | 채울 것 |
|---|---|
| `ssot/canon_values.json` | 회사명·주소·전화·포지셔닝·미션·공식링크·봇 이름 |
| `ssot/brand.json` | 브랜드 색상 코드·폰트·SNS 계정 |
| `ssot/ownership_map.json` | C-Level 별 닉네임·담당 화면 |
| `ssot/publish_channels.json` | 카카오톡 채팅방 ID·텔레그램 봇 토큰·채널 Chat ID |
| `ssot/forbidden_terms.json` | 회사 고유 금지어·대체어 목록 |
| `wellperion-agents/.claude/agents/ai-*.md` | C-Level 페르소나 7종(회사명·도메인·실무진 이름) |

### 2단계 — 권장 (운영 품질에 영향)

| 파일 | 채울 것 |
|---|---|
| `ssot/kpi.json` | C-Level 별 KPI 목표값·실무진 이름·역할 |
| `ssot/sheet_columns.json` | 회원·문의·점검 Google Sheets 열 이름 |
| `ssot/decision_contracts.json` | 주요 결정 이력·버전 계약 |
| `ssot/자율화규약.md` | 권한 분기 조건(자율 가능 범위) |
| `.claude/skills/wellperion-brand/SKILL.md` | 브랜드 제작 규격 상세 |

### 3단계 — 검증

```powershell
python ssot/forbidden_scan.py
python ssot/divergence_scan.py
python scripts/boot_pack.py --selftest
```

각 명령이 PASS 로 끝나면 도입 준비 완료.

## 3. 빈 테넌트 양식

아래 JSON 을 복사해 `tenants` 아래 회사 식별자로 새 블록을 만든다.
값을 이 파일에 쓰지 않는다 — 각 `경로` 파일에 쓴다(약속 L01).

```json
{
  "name_kr": "주식회사 [회사명]",
  "seq": 2,
  "swap_files": {
    "회사 공식값":           "ssot/canon_values.json",
    "브랜드 용어·컬러·계정":  "ssot/brand.json",
    "금지어·대체어":          "ssot/forbidden_terms.json",
    "역할 닉네임·소유 화면":  "ssot/ownership_map.json",
    "KPI·실무진":            "ssot/kpi.json",
    "발행 채널·계정":         "ssot/publish_channels.json",
    "결정·경위 기록":         "ssot/약속.json",
    "사고 기록·기준선":       ["ssot/incidents.json", "ssot/incident_baseline.json"],
    "시트 칸 계약":           "ssot/sheet_columns.json",
    "결정 이력":              "ssot/decision_contracts.json",
    "권한 분기 규약":         "ssot/자율화규약.md",
    "역할 페르소나":          "wellperion-agents/.claude/agents/ai-*.md",
    "브랜드 제작 규격":       ".claude/skills/wellperion-brand/SKILL.md"
  },
  "고유명_읽는_자리": {
    "역할 닉네임":      "ssot/ownership_map.json > roles[].nick",
    "회사 이름·주소":   "ssot/canon_values.json",
    "보고 방·봇":      "ssot/publish_channels.json"
  }
}
```
