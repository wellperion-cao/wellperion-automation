1. 목적과 톤

카카오톡 채널은 "친구 추가"한 고객에게 웰페리온 소식·프로그램을 직접 전하는 1:1 친화 채널이다.
인스타(브랜드 미학)·당근(동네 이웃 톤)과 달리, 카카오는 이미 관심을 보인 고객 대상이므로 정중·정보형 + 친근한 안내 톤이 맞다.

지킬 것:
- 정중·신뢰 톤. "안녕하세요, 웰페리온입니다." 식 안내형 첫 문장.
- 격조 유지, 과한 홍보·가격·할인 강조 금지 (VVIP 브랜드 보호).
- 브랜드 용어 준수: "피트니스" 금지 → "스포츠클럽". "현대하이페리온" 금지 → "웰페리온".
- 개인번호 노출 금지. CTA는 "문의: litt.ly/wellperion" 단일 (※ 자체 문의 페이지 전환 시 일괄 교체).
- 소식(포스트)은 정보 가치 중심. 스팸성 반복 발송 금지.

2. 발행 방식 — B안(GM/담당 직접 업로드) 확정

확정일: 2026-06-03 (CMO 자율 결정, 당근 B안과 동일 논리)

이유:
- 카카오톡 채널 '소식(포스트)' 작성에 공개 자동화 API 없음. 비즈메시지/알림톡 API는 유료+심사+발신 목적 한정.
- UI 스크래핑은 로그인 세션(카카오 보안 강함) + 구조 변경 취약 → 상시 블로커.
- B안은 추가 세팅 없이 즉시 운영 가능. 계정 보안·카카오 정책 완전 준수.
- 콘텐츠 준비·검수는 CMO 완전 담당, 발행 클릭만 GM/담당이 맡는 분업.

A안(반자동) 전환 조건: GM이 PC 브라우저에서 카카오 채널 관리자 로그인 세션 확보 + 스크립트 테스트 완료 시점. 현시점 미검토.

3. 운영 SOP (B안 기준)

단계 1. CMO 콘텐츠 가공
  산출물 위치: instagram/{YYMMDD_콘텐츠명}/output(카카오 채널)/
  규격:
    - 이미지 파일명: kakao_01.jpg ~ kakao_05.jpg (최대 5장)
    - 이미지 크기: 1080×1080(정방형) 권장. 카카오 채널 소식 카드 비율 호환.
    - 파일 용량: 장당 5MB 이하
    - 텍스트 파일: kakao_copy.md (제목·본문 최종본)
  kakao_copy.md 구성:
    제목 (20자 이내)
    ---
    본문 (200~500자, 정중 안내체, 1문단 3~4줄)
    ---
    문의: litt.ly/wellperion

단계 2. CMO 검수 (통과 시에만 다음 단계)
  ① 톤: 정중 안내체 / 가격·할인 강조 없음 / "피트니스"·"현대하이페리온" 없음(있으면 반려)
  ② CTA·개인정보: 마지막 줄 "문의: litt.ly/wellperion" 단일 / 전화번호·외부 할인링크 없음
  ③ 이미지 규격: 수(1~5)·크기·용량 충족
  검수 완료 후 채널별 업로드 캘린더 상태 → "가공완료".

단계 3. GM/담당에게 발행 패키지 전달
  전달 내용: output(카카오 채널)/ 경로 · kakao_copy.md 전문(복사용) · 이미지 목록 · 권장 발행 시간대
  전달 채널: CLI 또는 텔레그램 1줄 알림.

단계 4. 직접 업로드
  카카오톡 채널 관리자(center-pf.kakao.com) 또는 채널 관리 앱에서:
    ① 채널 로그인 → ② 소식(포스트) 작성 → ③ 제목·본문 kakao_copy.md 복사·붙여넣기 → ④ 이미지 순서대로 첨부 → ⑤ 게시
  예상 소요: 건당 5분 이내.

단계 5. 발행 확인·기록
  발행 후 CMO: 채널 소식 실등장 육안 확인 → 캘린더 "발행완료" → 게시 URL/ID 산출물 기록.
