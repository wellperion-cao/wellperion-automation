## 4. 리드 라우팅 메모 (폼 가동 후 연결)

폼 응답 → 텔레그램 알림 수신 대상 설계. **실제 연결은 폼 생성·gid 확정 후** `apps_script_survey.js`/알림 트리거에서 구현.

| 문의 유형 | 1차 수신(주관) | 협업 알림 | 근거 |
|---|---|---|---|
| **공간 렌트** | 운영부 + 시설부 | — | 대관 일정·공간 가용성=운영, 현장 세팅·설비=시설 |
| **비즈니스 파트너** | CMO(시모) + CEO(웰리) | — | 제휴·브랜드 협업=마케팅 주관, 사업제휴 판단=CEO |

구현 메모(폼 가동 후):
- `apps_script_survey.js`의 텔레그램 알림은 현재 `submit_inquiry`(자체폼) 한정. 구글폼 응답은 `_collectFormInquiries_`로 **집계만** 합류(개인정보 미노출).
- 신규 2종 알림이 필요하면 (a) 각 폼에 onFormSubmit 트리거 + 유형별 chat_id 분기 스크립트를 별도로 붙이거나, (b) 기존 텔레그램 알림 함수에 라우팅 분기를 추가. 수신 chat_id(운영부·시설부·CMO·CEO)는 GM 확정 후 ScriptProperties로 주입.
- 집계 대시보드(`inquiry_list`·`period_breakdown`)에는 `FORM_SHEETS` 2줄 활성화만으로 자동 합류됨(개인정보 제외, 유형·채널·시각만).

## 5. GM 액션 체크리스트 (제작 준비 → 가동)

준비분(시모 완료): ✅ 폼설계 명세 / ✅ 카드 틀(준비중 상태) / ✅ `FORM_SHEETS` placeholder 2줄

GM 액션(폼 생성은 GM 권한):
1. [ ] **구글폼 2개 생성** — 위 §1·§2 필드·옵션·필수여부 그대로. 응답 시트 연결(기존 랜딩/문의 시트 또는 신규).
2. [ ] **폼 UI에서 "조직으로 제한" 해제** — 비로그인 외부 방문자 제출 가능 확인(시크릿창 테스트).
3. [ ] **폼 공개 URL 확보** → `wp_inquiry_block.html`의 placeholder 교체:
       - `href="#__SPACE_RENTAL_FORM__"` → 공간 렌트 폼 URL
       - `href="#__BUSINESS_PARTNER_FORM__"` → 파트너 폼 URL
       - 각 카드의 `data-wp-disabled="1"`(준비중 표시) 제거 → 활성화
4. [ ] **응답 시트 gid 확보** → `apps_script_survey.js`의 `FORM_SHEETS` 2줄에서:
       - `ssId` = 실제 응답 스프레드시트 ID
       - `gid: '__GID__'` → 실제 응답탭 gid(숫자)
       - `type` 유지(`공간렌트`·`비즈니스파트너`)
5. [ ] **GAS 재배포 1회** — clasp push만으로는 `/exec` 반영 안 됨. **새 버전 웹앱 배포**(GM/CTO 1회).
6. [ ] (선택) 라우팅 알림 필요 시 §4 구현 메모대로 onFormSubmit 트리거·chat_id 주입.
7. [ ] 카드 활성화 후 라이브(워드프레스 문의 페이지) 재주입·검증.

> ⚠️ placeholder 상태에서는 카드가 "준비중"으로 표시되며 클릭해도 폼으로 이동하지 않음(깨진 링크 라이브 노출 방지). GM이 URL 교체+활성화하기 전까지 회귀 안전.
