# 문의폼 '어떻게 알고 오셨나요?' 표준 (출처 필수 캡처) — 2026-06-16

> 목적: 문의 시점에 **유입 출처를 필수로 기록**해, 콘텐츠/채널 ROI를 측정한다.
> 현재 전체 문의의 **42%가 출처미상**·인스타 등 디지털 채널이 사실상 0 → 이 필드 하나가 그 공백을 메운다.

- 멤버십 문의폼 (응답시트 12AWcAlg `26년 신규문의`)
- 성인강습 문의폼 (응답시트 1b0XU1 gid 111889422)
- 유소년강습 문의폼 (응답시트 1b0XU1 gid 268994754)
- (신규) 공간렌트·비즈니스파트너 폼

## 문항 (객관식·필수)
**질문:** `어떻게 알고 오셨나요? (필수)`
**유형:** 객관식 단일 선택 + '기타' 직접입력 허용
**필수:** 예

**선택지 (10 — 대시보드 채널 버킷과 1:1 정합):**
| 폼 선택지(사용자 표기) | 대시보드 버킷 |
|---|---|
| 네이버 (검색·블로그·플레이스) | 네이버 |
| 인스타그램 | 인스타그램 |
| 카카오톡·카카오채널 | 카카오톡 |
| 당근마켓 | 당근마켓 |
| 동부이촌동 커뮤니티(카페) | 동부이촌동 커뮤니티 |
| 지인 소개·추천 | 소개·지인 |
| 기존/과거 회원·수강생 | 기존·과거 회원 |
| 오프라인 (간판·현수막·방문) | 오프라인 |
| 전화 문의 | 유선전화 |
| 기타 (직접 입력) | 기타·미상 |

※ 위 표기는 `apps_script_survey.js`의 `_canonicalChannel_` 정규식과 자동 매칭됨(별도 매핑 불필요). 신규 표기 추가 시 정규식만 보강.

## 적용 방법 (택1)
### A. GM 수동 (간단·권장 첫 적용)
각 구글폼 편집 → 문항 추가(객관식·필수) → 위 10 선택지 입력 → '기타' 토글 ON. 4개 폼 동일.

### B. GAS 자동 적용 (반복·정합 보장)
아래 함수를 **문의 폼이 바인딩된 스프레드시트의 Apps Script**에 붙여 1회 실행(폼별 중복 추가 방지 포함):
```js
function setupSourceQuestion() {
  var OPTS = ['네이버 (검색·블로그·플레이스)','인스타그램','카카오톡·카카오채널','당근마켓',
              '동부이촌동 커뮤니티(카페)','지인 소개·추천','기존/과거 회원·수강생',
              '오프라인 (간판·현수막·방문)','전화 문의'];
  var Q = '어떻게 알고 오셨나요?';
  var url = SpreadsheetApp.getActive().getFormUrl(); // 바인딩된 폼
  if (!url) { Logger.log('이 시트에 연결된 폼 없음'); return; }
  var form = FormApp.openByUrl(url);
  var exists = form.getItems(FormApp.ItemType.MULTIPLE_CHOICE)
                   .some(function(it){ return it.getTitle().indexOf('어떻게 알고') >= 0; });
  if (exists) { Logger.log('이미 있음 — 스킵'); return; }
  var item = form.addMultipleChoiceItem();
  item.setTitle(Q).setRequired(true).showOtherOption(true)
      .setChoiceValues(OPTS);
  Logger.log('출처 문항 추가 완료');
}
```
- 실행 권한: 폼/시트 소유 계정(cao). clasp 연동된 폼은 push 후 편집기에서 실행.
- ⚠️ 객관식 '기타' = `showOtherOption(true)` → 응답이 '기타·미상' 버킷으로 정규화됨.

## 효과 (정합)
- 신규 문의부터 출처가 10버킷으로 확정 → 대시보드 `type_channel_breakdown`·`funnel_conversion`의 채널 정확도 즉시 상승, '출처미상률' 하락.
- 과거 데이터(미상 42%)는 소급 불가(보존). **신규부터 정확**해지는 구조(시모·GM 2026-06-16).
