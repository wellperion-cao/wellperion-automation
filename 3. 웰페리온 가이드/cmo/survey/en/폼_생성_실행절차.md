## 2. GM 실행 절차 (5단계)

### Step 1 — GAS 에디터 접속
1. 브라우저에서 [https://script.google.com](https://script.google.com) 접속 (cao@wellperion.com 계정)
2. 좌측 **"내 프로젝트"** → **"새 프로젝트"** 클릭

### Step 2 — 코드 붙여넣기
1. 기본으로 열리는 `코드.gs` 탭의 내용을 **전체 삭제**
2. 아래 파일 내용을 전체 복사해서 붙여넣기:
   ```
   파일 경로: 3. 웰페리온 가이드/cmo/survey/create_english_forms.gs
   ```
3. 프로젝트 이름 입력 (예: `Wellperion_EN_Forms`) → **저장** (Ctrl+S)

### Step 3 — 함수 실행
1. 에디터 상단 함수 선택 드롭다운에서 **`createEnglishForms`** 선택
2. **실행(▶)** 버튼 클릭
3. 최초 실행 시 **권한 승인 팝업** 발생:
   - "권한 검토" → "계속" → cao@wellperion.com 계정 선택
   - "Google에서 확인하지 않은 앱" 경고 → 좌하단 **"고급"** → **"(프로젝트명)(으)로 이동"** → "허용"
4. 실행 완료 후 하단 **"실행 로그"** 확인

### Step 4 — 폼 URL 4종 수집
실행 로그에서 아래 형식으로 URL이 출력됩니다:

```
=== 생성 결과 요약 ===
[성공] 멤버십 문의 (EN)
  공개 URL : https://docs.google.com/forms/d/e/XXXXX/viewform
  편집 URL : https://docs.google.com/forms/d/YYYYY/edit
[성공] 성인 강습 문의 (EN)
  공개 URL : https://docs.google.com/forms/d/e/XXXXX/viewform
  편집 URL : https://docs.google.com/forms/d/YYYYY/edit
[성공] 유소년 강습 문의 (EN)
  공개 URL : ...
[성공] 여름 특강 문의 (EN)
  공개 URL : ...
=== 완료 ===
```

**공개 URL(getPublishedUrl) 4개를 복사해 둡니다.**

### Step 5 — wp_inquiry_block_en.html 에 URL 삽입
`3. 웰페리온 가이드/cmo/inquiry/wp_inquiry_block_en.html` 파일을 열고 아래 placeholder를 실제 URL로 교체합니다:

| Placeholder | 교체할 URL |
|---|---|
| `__EN_FORM_URL_MEMBERSHIP__` | 멤버십 문의 공개 URL |
| `__EN_FORM_URL_ADULT__` | 성인 강습 문의 공개 URL |
| `__EN_FORM_URL_YOUTH__` | 유소년 강습 문의 공개 URL |
| `__EN_FORM_URL_SUMMER__` | 여름 특강 문의 공개 URL |

교체 후 파일 저장 → git commit → Netlify 자동 배포 확인.

## 4. Language 필드 안내

각 폼에 **"Language"** 텍스트 항목이 추가되어 있습니다.  
응답자가 직접 입력하거나, 폼 공유 시 prefill URL을 활용해 `EN` 값을 기본으로 넣을 수 있습니다.

prefill URL 생성 방법:
1. 폼 공개 URL에서 `/viewform` 뒤에 `?usp=pp_url&entry.FIELD_ID=EN` 추가
2. FIELD_ID는 폼 편집 화면에서 해당 항목 우클릭 → "사전 입력 링크 가져오기"로 확인
