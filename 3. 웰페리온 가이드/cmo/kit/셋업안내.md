# 마케팅 자동화 셋업 안내

새로 맡는 업체 하나를 세우는 순서입니다. 위에서부터 그대로 따라 하면 됩니다.
각 단계 끝에 **「이렇게 나오면 성공」** 이 붙어 있습니다. 그게 안 나오면 다음으로 넘어가지 마세요.

---

## 0. 준비 (1분)

컴퓨터에 파이썬이 있어야 합니다. 명령창을 열고 아래를 칩니다.

```
python --version
```

**이렇게 나오면 성공** — `Python 3.11` 처럼 숫자가 보입니다.

⚠️ `python` 을 못 찾는다는 말이 나오면 파이썬을 먼저 깔아야 합니다.
윈도우에서 이미 깔았는데도 안 되면 `C:\Python314\python.exe` 처럼 전체 경로로 부르세요.

---

## 1. 업체 정보 받기 (가장 오래 걸리는 단계)

`새업체_마케팅설정.json` 을 메모장으로 열어 빈칸을 채웁니다.

- **모르는 칸은 그냥 비워 두세요.** 지어내면 그 값이 그대로 손님에게 나갑니다.
- 대표님께 한 번에 다 묻지 마세요. 자료(가격표·플레이스·간판)로 채울 수 있는 것은 먼저 채우고,
  남은 것만 하루 한두 개씩 여쭙니다.

특히 이 여덟 개가 있어야 시작됩니다.

| 무엇 | 어디서 받나 |
|---|---|
| 업체 번호·영문 이름 | 우리가 정합니다 (예: `3_spogym`) |
| 상호(한글) | 간판·사업자등록증 |
| 업종 한 줄 | 대표님 말 그대로 |
| 업체를 한 줄로 | 대표님께 여쭙니다 |
| 말투 기준 | 대표님께 여쭙니다 (예: 담담하게, 과장 없이) |
| 문의를 받는 곳 | 예약 링크 · 전화 · 카톡 채널 |
| 주 몇 회 내보낼지 | 대표님과 정합니다 |
| 승인받을 곳 | 대표님 카톡 1:1 방을 권합니다 |

**이렇게 나오면 성공** — 파일을 저장했고, 위 여덟 칸에 값이 들어 있습니다.

---

## 2. 어디까지 찼는지 확인 (10초)

```
python 셋업.py
```

못 받은 칸, 형식이 틀린 칸, 서로 어긋나는 칸을 알려 줍니다.

⚠️ 자주 걸리는 것 세 가지
- 색을 `빨강` 이라고 적음 → `#RRGGBB` 여섯 자리로 적습니다 (예: `#221F20`)
- 문의 주소를 `example.com` 으로 적음 → `https://` 로 시작해야 합니다
- 업체가 안 쓰기로 한 말이 업체 소개문에 그대로 들어 있음 → 소개문을 고칩니다

**이렇게 나오면 성공** — 맨 아래에 `✅ 시작할 수 있습니다` 가 뜹니다.

---

## 3. 설치 (5초)

```
python 셋업.py --설치
```

`업체/{업체번호}/` 폴더가 생기고 그 안에 네 개가 들어갑니다.

| 파일 | 무엇 |
|---|---|
| `brand.json` | 색·말투·문의 링크. 콘텐츠는 전부 이 값을 따릅니다 |
| `forbidden_terms.json` | 업체가 대외에 쓰지 않는 말 |
| `aws요청.json` | 서버 자리를 만들어 달라는 요청서 한 장 |
| `지금할일.md` | 남은 사람 손 목록 |

**이렇게 나오면 성공** — `✅ 만들었습니다` 아래에 파일 네 개가 보입니다.

---

## 4. 채널 로그인 (업체마다 다름)

계정은 **업체에서 받습니다.** 우리가 만들지 않습니다.
채널마다 브라우저를 한 번 띄워 사람이 직접 로그인합니다. 이 단계는 자동이 될 수 없습니다 —
어느 채널이든 처음 한 번은 본인 확인을 요구합니다.

⚠️ **계정 비밀번호를 설정 파일에 적지 마세요.** 이 꾸러미는 사람 손을 여러 번 거칩니다.

**이렇게 나오면 성공** — 각 채널 관리자 화면이 로그인된 상태로 열립니다.

---

## 5. 서버 올리기 (담당에게 넘김)

`aws요청.json` 한 장을 담당에게 전달합니다. 담당이 서버에 업체 자리와 공개 주소를 만듭니다.

**이렇게 나오면 성공** — `지금할일.md` 에 적힌 공개 주소가 브라우저에서 열립니다.

| 단계 | 상태 |
|---|---|
| 업체 정보 받아 정리 | 됩니다 |
| 업체 브랜드 값·금지어 세우기 | 됩니다 |
| 작업 폴더·서버 요청서 만들기 | 됩니다 |
| 콘텐츠 만들기 | 우리 도구를 그대로 씁니다 (업체 색·말투 적용) |
| 채널로 자동 발행 | **아직입니다** — 발행기가 우리 계정에 맞춰져 있어, 업체별로 바꾸는 작업이 남았습니다 |
| 성과 집계·월간 보고 | 발행이 붙은 뒤 |

발행 자동화까지 걸리는 시간은 채널 수에 따라 다릅니다.
인스타·블로그는 계정 이름만 바꾸면 되고, 카페·당근·카카오는 번호를 하나씩 더 바꿔야 합니다.
