1. 목적과 톤

당근 비즈프로필은 한남동·이촌동 반경 주민에게 웰페리온을 "동네 스포츠클럽"으로 자연스럽게 인식시키는 채널이다.
인스타그램(브랜드·그리드 미학)과 달리, 당근은 이웃끼리 대화하듯 쓰는 게 맞다.

지킬 것:
- 동네생활·이웃 톤 유지. "안녕하세요, 한남동에 있는 웰페리온입니다" 식 첫 문장.
- 격조는 유지하되 과한 홍보 문구·가격·할인 강조 금지 (VVIP 브랜드 이미지 보호).
- 브랜드 용어 준수: "피트니스" 금지 → "스포츠클럽". "현대하이페리온" 금지 → "웰페리온".
- 개인번호 노출 금지. CTA는 "문의: litt.ly/wellperion" 단일.
- 동네 신뢰·경험 중심. 수치·가격보다 라이프스타일·공간 분위기를 앞세운다.

2. 발행 방식 — B안(GM 직접 업로드) 확정

확정일: 2026-06-02 (CMO 자율 결정)

이유:
- 당근 공개 API 없음. UI 스크래핑은 구조 변경 시 즉시 깨짐.
- 로그인 세션(쿠키) 확보는 GM님 직접 작업 선행 필요 → 블로커 상시 존재.
- B안은 추가 세팅 없이 즉시 운영 가능. 계정 보안·당근 정책 완전 준수.
- 콘텐츠 준비·검수는 CMO가 완전 담당하고, 발행 클릭만 GM님이 맡는 분업 구조.

A안(Playwright 반자동) 전환 조건:
  GM님이 PC 브라우저에서 당근 비즈프로필 로그인 세션 확보 + 스크립트 테스트 완료 시점.
  현시점에서는 검토하지 않는다.

3. 운영 SOP (B안 기준)

단계 1. CMO 콘텐츠 가공

  작업 대상: 인스타그램 슬라이드 제작 완료 후 당근용 별도 가공.
  산출물 위치: instagram/{YYMMDD_콘텐츠명}/output(당근)/

  output(당근) 규격:
    - 이미지 파일명: danggn_01.jpg ~ danggn_05.jpg (최대 5장)
    - 이미지 크기: 1080×1080 (정방형) 또는 1080×810 (4:3 가로)
    - 파일 용량: 장당 5MB 이하
    - 텍스트 파일: danggn_copy.md (제목·본문 최종본)

  danggn_copy.md 구성:
    제목 (15자 이내, 지역명 포함 권장)
    ---
    본문 (200~400자, 이웃 대화체, 1문단 3~4줄 이하)
    동네 키워드 자연 삽입 (한남동, 이촌동, 용산)
    ---
    문의: litt.ly/wellperion

단계 2. CMO 검수

  아래 3항목 체크 후 통과 시에만 다음 단계 진행.

  ① 톤 체크
    - 이웃 대화체 유지 여부
    - 가격·할인 강조 문구 없는지
    - "피트니스" / "현대하이페리온" 사용 여부 (있으면 반려)

  ② CTA·개인정보 체크
    - 마지막 줄: "문의: litt.ly/wellperion" 단일 여부
    - 전화번호·카카오 링크·할인 코드 없는지

  ③ 이미지 규격 체크
    - 파일 수(1~5장), 크기, 용량 기준 충족 여부

  검수 완료 후: 채널별 업로드 캘린더 DB 상태 → "가공완료" 전환.

단계 3. GM에게 발행 패키지 전달

  CMO가 GM님께 전달하는 내용:
    - 발행 패키지 경로 (output(당근)/ 폴더 위치)
    - danggn_copy.md 전문 (복사용 제목·본문 텍스트)
    - 이미지 파일 목록
    - 발행 권장 시간대 (필요 시)

  전달 채널: CLI 또는 텔레그램 보고봇 1줄 알림.

단계 4. GM 직접 업로드

  GM님이 당근 앱 또는 웹(biz.daangn.com)에서:
    ① 비즈프로필 로그인
    ② 게시물 작성 화면 진입
    ③ 제목·본문 danggn_copy.md에서 복사·붙여넣기
    ④ 이미지 output(당근)/ 폴더에서 순서대로 첨부
    ⑤ 게시 (동네 범위: 한남동·이촌동·용산 설정 권장)

  예상 소요 시간: 건당 5분 이내.

단계 5. 발행 확인·기록

  GM님 발행 완료 후 CMO가:
    - 당근 비즈프로필에서 게시물 실등장 육안 확인
    - 채널별 업로드 캘린더 DB 상태 → "발행완료" 전환
    - 발행 URL 또는 게시물 ID 산출물 필드에 기록
