              본문 말미에 동네 키워드 자연 삽입 (예: "한남동", "이촌동", "용산").
CTA        : 마지막 줄 고정 — "문의: litt.ly/wellperion"

output/danggn 산출물 규격:

  - danggn_copy.md 에 제목·본문 작성 (이웃 톤 검토 필수).

단계 2. CMO 검수
  - 톤·CTA·브랜드 용어 3항목 체크.
  - 이미지 매수·파일 규격 확인.
  - 검수 완료 시 채널별 업로드 캘린더 DB 상태 → "가공완료" 전환.

단계 3. 발행
  아래 A·B 두 방식 중 하나로 진행 (현재 미확정 — GM 결정 필요).

4. 발행 방식 2안 비교

A안 — Playwright 반자동
  방법: 웰페리온 당근 비즈니스 계정 세션 쿠키를 저장해두고,
        스크립트가 비즈프로필 게시물 작성 화면에 제목·본문·이미지를 자동 입력 후 게시.
  장점: CMO가 명령 한 줄로 발행. 사람 손 최소화.
  단점: 당근 공개 API 없음 → UI 구조 변경 시 스크립트 깨짐.
        최초 로그인 세션(쿠키) 확보를 GM님이 직접 해주셔야 함.
        당근 정책상 자동화 위반 위험 존재 (단, 비즈프로필 게시는 낮은 위험).

B안 — GM 직접 업로드
  방법: CMO가 danggn_copy.md + output(당근)/ 이미지 준비 완료 후,
        GM님께 "발행 준비 완료" 알림. GM님이 당근 앱/웹에서 직접 붙여넣기·업로드.
  장점: 계정 보안 위험 없음. 당근 정책 완전 준수. 구현 즉시 가능.
  단점: GM님 수동 작업 필요 (건당 5분 내외).

CMO 권장안: B안 (GM 직접 업로드)
  이유: 당근 공개 API 부재 + 로그인 세션 블로커가 해소되지 않은 현시점에서
        안전하고 즉시 시작 가능한 B안이 합리적.
        콘텐츠 준비·검수는 CMO가 완전 자동화하고, 발행 클릭만 GM님 담당으로 분리.
        추후 A안 전환은 GM님 세션 확보 + 테스트 후 결정.
