# 전환 단계 퍼널 — 설계 SSOT (2026-06-15)

문의 → 가입 사이 "중간 단계"를 처음으로 눈에 보이게 만든다. 어느 단계에서 콜드 리드가 새는지 측정.

## 5단계 (누적 깔때기 — 각 단계 = "최소 이 단계까지 도달한 문의 수", ①≥②≥③≥④≥⑤)
| 단계 | 이름 | 정의 |
|---|---|---|
| ① | 문의 | 접수된 모든 문의 |
| ② | 응대 | 우리가 연락(콜백·회신)한 문의 |
| ③ | 예약 | 투어·상담 예약을 잡은 문의 |
| ④ | 방문 | 실제 방문한 문의 |
| ⑤ | 가입 | 회원 전환 (유효회원 시트 전화번호 매칭 — 기존 신뢰 측정 유지) |

side: **이탈/보류** = 진행 중단(어느 단계에서 멈췄는지 마지막 단계로 카운트 + 이탈 표시)

## 상태 입력 (리셉션 로그 '진행상태' 칸 — 리셉션/CS가 진행에 따라 갱신)
표준값 드롭다운: `신규 · 응대 · 예약 · 방문 · 가입 · 이탈`
- 자유텍스트 매핑 `_stageOf_`: 신규·접수→① / 응대·연락·통화·문자·회신→② / 예약·투어·상담→③ / 방문·내방·방문완료→④ / 가입·등록·전환·회원→⑤ / 이탈·보류·포기·거절·취소→이탈
- 빈칸·미인식 = **① 문의**(최소단계). 상태 칸이 아직 없는 시트도 전부 ①로 안전 처리.

## 집계 (GAS `action=stage_funnel`)
```
{ ok, generatedAt,
  total: {문의,응대,예약,방문,가입,이탈},   // 전체기간
  month: {문의,응대,예약,방문,가입,이탈},   // 이번달
  retain: {응대,예약,방문,가입}             // 각 단계 직전대비 잔존% (이번달 기준)
}
```
- 각 단계 = 해당 rank 이상 도달 문의 수(누적). ⑤ 가입 = `상태=가입` 또는 `유효회원 매칭` 중 max(신뢰 우선).
- 상태 칸은 `_findCol_(['진행상태','상태','진행','단계'])`로 어느 소스 시트든 탐색. 없으면 전부 ①.

## 화면 (대시보드 '전환 단계 퍼널' 섹션)
- 계단형 ①→⑤ + 각 단계 수 + 직전 대비 **잔존/이탈%**.
- 상태 미입력이라 ①에 몰리면 안내문: *"②~④는 리셉션 진행상태 입력 시작 후 채워집니다(현재 대부분 ①=정상)."*
- 양 끝(①문의·⑤가입)은 기존 period_breakdown으로 즉시 표시 → 틀은 지금 바로 보임.

## 역할
- **상태 도장**(진행상태 칸 추가·갱신) = 리셉션(시우) + CS·회원(시포)
- **집계 GAS + 화면** = 시모
- GAS 신규 action → **웹앱 재배포 1회(GM/CTO)** 필요(clasp push≠배포).
