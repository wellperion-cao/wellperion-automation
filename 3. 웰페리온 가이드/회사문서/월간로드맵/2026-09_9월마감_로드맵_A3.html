9월 마감 로드맵 — ERP(원천·권한) · 브로제이 · 상담봇 · 검색 · 정리

2026-09-05(토) 기준 · 원장 = status/_queue.json 배 note · 작성 AI 웰리 · 빨간 줄 = GM 손
방향
9월 안에 ERP·브로제이·상담봇을 닫는다 — 셋 다 「서버가 원천」이라는 한 축이다.
지금 서버가 원천인 것 = 문의·접수·습득물·발행원장·로그인. 아직 시트가 원장인 것 = 회원 1,746 · 업무 208 · 점검 173 · 휴회 145 · 결재 49 · 강습 8 · 매출/퍼널/보드 집계. 브로제이는 연동 전.
AWS 이관·ERP 권한·검색 3건은 별개 일이 아니라 이 축에 붙는 갈래다 — 원천이 하나면 권한도 한 곳에서 갈리고, 검색·상담봇이 같은 문장으로 답한다.

GM 손이 필요한 것

  1. 브로제이 API 사양·키 — 9/7(월). 받는 날 소급 호출까지 간다. 트랙 3 전체가 여기서 시작한다.
  2. 상담봇 API 키 발급 — 월 한도 걸어 1만 원 안쪽. 없으면 답이 FAQ 문장 그대로 나간다.
  3. 붙여넣기 5곳 — 카카오채널 · 페이스북 · 네이버 플레이스 · 인스타 fit · 인스타 공식.
  4. 호스팅 FTP 3건 — llms.txt · AI 크롤러 허용 · 사이트맵. 접속 정보를 주시거나 「카드 줘」 하시면 그대로 진행.
  5. 당근 — 업종 변경 폼(증빙 사진) · 주소 「한남동 하이페리온」 지도 정정.
  6. 외부 7채널 문구 표 — 공식값 확정 뒤 채널에 반영.
  7. ERP 권한 켜는 날 — 날짜만 주시면 전날 웰리가 실무진 안내 1통.
  8. 새 홈 도메인 전환 · 카카오 채널 API 도입 — 판단 뒤 각각 5단계 · 2단계.
모두 GM 업무 · 결재 SSOT 에 걸려 있다. 이 종이는 순서를 보는 용도다.

이 달을 무너뜨릴 수 있는 것

  • 브로제이 사양이 늦어지면 — 트랙 3만 멈춘다. 서버 골격은 이미 서 있고 키 4줄만 채우면 그 자리에서 돈다. 다른 트랙은 기다리지 않는다.
  • 회원 원천 전환이 크다 — 쓰기 7종을 서버 원장에 먼저 적게 재구현해야 한다. 그래서 시포 8건을 병렬로 먼저 돌린다.
  • 대조가 안 맞으면 교체하지 않는다 — 브로제이도 회원도 같다. 숫자가 어긋난 채 화면을 바꾸면 그게 더 큰 사고다.
  • 실무진 화면은 안 바뀐다 — 링크 · QR · 입력 칸 그대로. 바뀌는 건 뒤(서버)와 로그인 방식뿐이고, 그것도 전날 안내가 먼저 간다.
