📖 사용 가이드

⚙️ 작동 원리▾
매일 09:00 텔레그램 정각 매출·업무 보고의 매출보고 이미지 아래 "📤 카톡 3방 전송" 인라인 버튼을 GM이 탭하면, 텔레그램 봇(bot.py)이 그 사진을 로컬 archive 폴더에 저장한 뒤 scripts/kakao_report_sender.py를 실행합니다. 이 스크립트는 카카오톡 PC 앱 화면을 직접 자동조작(pywinauto)해 이미 열려 있는 채팅방 창을 이름으로 찾아 이미지+캡션을 순서대로 붙여넣고 전송합니다. 방 목록·캡션 앞머리는 이 페이지에서 편집한 값(웹 SSOT)을 우선 사용하고, 웹(GAS) 연결이 안 되면 로컬 kakao_rooms.json 캐시로 자동 폴백합니다.
✅ 사용 조건▾
  • GM PC가 켜져 있고 카카오톡 PC 앱에 로그인된 상태여야 합니다.
  • 방이 미리 열려 있지 않아도 자동으로 검색해 열지만(실측 검증됨), 실패 시 GM이 먼저 방을 한 번 열어두면 가장 안정적입니다.
  • 방 이름은 여기 목록의 이름과 완전히 동일한 글자여야 합니다(공백·오탈자 불일치 시 전송 실패).
🧪 안전한 테스트 방법▾
실제 방으로 바로 실전송하지 말고, 아래처럼 CLI에서 --dry-run(전송 트리거 없이 미리보기까지만)과 --only-room(방 1개만)을 함께 써서 검증하세요:
python scripts\kakao_report_sender.py --image "C:\...\report.png" --caption "테스트" --dry-run --only-room "웰페리온 운영부"
회장님방·관리부방 등 실제 업무 채널에는 안전 검증 없이 바로 실전송하지 않는 것을 원칙으로 합니다.
⚠️ 한계 · 실패 시▾
카카오톡 PC 앱 UI(창 클래스·팝업 구조·검색 아이콘 위치)는 버전 업데이트로 바뀔 수 있어 취약합니다. 카톡이 업데이트된 후 갑자기 전송이 안 되면 이 UI 자동화 좌표/구조가 깨졌을 가능성이 큽니다 — 이 경우 명확한 실패 메시지가 텔레그램으로 회신되며, GM이 해당 방에 수동으로 직접 전달하는 것이 안전한 폴백입니다. 자동 복구를 시도하지 않고 정직하게 실패를 알립니다.
