제  목교회 사용 공간 무상 임차(사용대차) 협조 요청

1. 귀 교회의 무궁한 발전을 기원합니다.

2. 당사는 당사 소유 건물 내 옥외광고물(간판 2개)을 관련 법령에 맞게 정비하고자 해당 건물에 당사 지점(사무실) 사업자등록을 준비하고 있습니다.

3. 사업자등록에는 해당 공간 사용 권원 증빙이 필요하여, 귀 교회가 현재 임차하여 사용 중인 공간 일부를 아래와 같이 당사가 무상으로 사용할 수 있도록 사용대차 계약 체결을 요청드립니다.

가.대상 공간 : 【호실 3개 — 호수 기재】

나.사용 목적 : 당사 지점(사무실) 사업자등록 및 간판 표시 신고

다.사용 조건 : 무상 (귀 교회의 현재 사용 및 임대차 관계 변동 없음)

라.기    간 : 【 】

4. 계약서(안)는 법적 검토를 거쳐 별도 전달드리겠습니다. 협조 부탁드립니다.
