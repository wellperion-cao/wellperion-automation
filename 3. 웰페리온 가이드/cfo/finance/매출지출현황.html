매출 구성

누적 기준.
매출현황 — 센터전체 / 부서별 / 월별 (단위: 원)
센터 전체 = 회원권(멤버십) + 강습(부서별). 6월은 부분월(보고일 기준)이라 월말 마감 시 증가합니다.
지출현황 — 부서별 (구매성 + 인건비)
각 부서 셀 = 구매성 + 인건비 합. 인건비는 시트 실시간, 구매성은 승인건 기준. 7~12월은 해당 월 도래 시.
