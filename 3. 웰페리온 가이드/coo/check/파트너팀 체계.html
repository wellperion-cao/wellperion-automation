📋 파트너팀 규정

강습 6개팀(수영·PT·필라테스·골프·스쿼시·체조) 파트너 운영·계약·요금·시설 이용 공식 규정입니다. 요금·유효기간 등 공식값은 임의 변경 금지(GM 컨펌 필수).

⏱ 강습 운영 기준

항목기준
강습 타임PT·필라·스쿼시·수영 50분 / 골프 25분 / 스쿼시 30·50분 선택
유효기간회차별 차등 (PT 10회 2개월 … 100회 12개월) · 요금표 기준 준수
추가 연장무사유 연장 1회 한해 가능(회원 고지 X) / 범위 외는 증빙(티켓·진료확인) 필수
무단 수정유효기간 임의 추가·수정 적발 시 계약 해지 조항 적용
기준 외 계약담당 팀장 컨펌 + 계약서 명시 (사유 납득 가능 · 남용 금지)

💳 요금·결제 규정

항목기준
회차 할인20회 5% / 30회 10% / 50회 15% / 100회 25% (PT 기준)
준회원정회원가 + 시설이용 공제금(1회당 약 1.5만원 차액) / 단체반 별도 요금
사우나1:1 정규강습 제공 / 단체반 미제공
결제 기록스포피아 수강 비고란에 혜택·유효기간 필수 기재 (모두싸인 발송 전)

🔁 환불·양도·변경

항목기준
환불위약금 10% 공제 + 이용기간 일할 차감(월이용료/30일) · 잔여 환불금 없을 수 있음
양도1회 가능 / 강습 양도·변경 신청서로 진행
종목 변경각 강습부 팀장 컨펌 후 진행
연장 신청강습 연장 신청 서베이 → 승인 시 스포피아 반영

🛁 시설 이용 규정

대상기준
준회원강습 외 시설 이용 불가 / 강습 50분 + 주차 100분 / 스케줄 미등록·기간만료 시 입장 제한
위반 시1차 담당자 안내 → 2차 이용수칙 문자 → 3차 면담·탈회 검토
파트너(강사)지정 시간 실습·자기관리 허용 / 사우나 금지(B2 일반샤워만) / 복장·매너 전문가 수준
유소년보호자 카드 소지 입장 / 전용 통로 이용

🤝 파트너 계약·인사

항목기준
채용구인 → 1차 팀리더·실무자 면접 → 2차 GM·대표 면접 → 확정
계약위탁(파트너) 계약 + 서약서(정보보호·개인정보·주차)
종료계약종료확인서 + 레슨 인수인계서(페이롤 특이사항) + 비품 회수
페이롤각 강습부 팀장 관리 / 주차비·수당 반영

🗓 회의·보고

항목기준
정기 회의매주 화 14:00 (다섯째 주 없음) / 부서장 회의 매월 첫째 주
업무보고매출 목표·현황·이슈 사항 보고 필수
패널티연 3회 이상 회의 불참 시 해당 팀 리더 패널티

📖 파트너팀 가이드

강습부 운영 방향·응대·점검·수업 진행 절차 가이드입니다.

🎯 운영 방향·목표

항목내용
26년 목표강습부 월 평균 3억(VAT 포함) · 연 33억
팀별 월 목표수영 1.1억 · PT 9,900만 · 필라·골프·스쿼시·체조 각 3,300만
정원정회원 1,000명 정원제 / 1~10일 재등록 · 11일~말일 신규
방향회원권+강습 동시 등록 지향 · 준회원 정회원 전환 유도

🤝 강사·파트너 기본 에티켓

1. 회원이 먼저회원이 보이면 하던 일을 멈추고 먼저 인사
2. 한 발 앞서요청받기 전에 불편사항 발견·조치
3. 모르면 연결확인 후 안내드리겠습니다 → 담당 팀장 즉시 연결
4. 끝까지 책임접수·상담 건은 끝까지 추적·기록(유효회원 시트)
5. 하이엔드 격조말투·복장·수업 퀄리티 모두 프리미엄 수준

🗣 응대 태도

상황판단 기준
회원 첫 인사눈 맞춤 + 미소 / 이름 알면 호칭 사용
강습 문의담당 팀장 전담 안내 / 인적사항·희망강습 받아 서베이 작성
신규·체험OT·체험 유도 → 니즈 파악 → 맞춤 제안 (강압 금지)
준회원시설 이용 제한 정중·단호 안내 / 반복 위반 시 팀장 보고
안전·사고즉시 중단 → 119·제휴병원·GM 보고 (사고 매뉴얼 준수)

🔁 신규·재등록 운영

구분프로세스
신규(OT)회원권 등록 → OT 제공 → 문제인식·해결제시·실행 상담 → PT 전환 / OT 후 48h 내 follow-up
재등록종료 3~4주 전(잔여 5~8회) 사전 상담 → 목표 재설정 → 회차 재구성
OT 대상재등록 회원(오래된 PT·새 종목 관심) + 신규(강습권 + 종목별 1회)

🗂 수업 운영 절차

① 수업 전 준비
  • 업장·소도구·기구 점검 및 청결 확인
  • 당일 예약·출석 회원 확인
  • 회원 컨디션·목표 점검
② 수업 진행
  • 안전 최우선 / 위험요소 즉시 제거
  • 회원 맞춤 진행 · 동기부여
  • 강습 시간 준수 (50분 / 골프 25분)
③ 수업 후·기록
  • 차회 일정·과제 안내
  • 유효회원 시트에 진행·컨택 기록
  • 업장 정리정돈·청결 마무리
