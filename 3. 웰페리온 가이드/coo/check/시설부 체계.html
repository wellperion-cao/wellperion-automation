가이드

시설부 가이드를 카드로 정리했습니다. 각 카드의 편집 버튼으로 내용을 바로 수정·저장하면 모든 기기에 반영됩니다. ＋ 카드 추가로 새 가이드를 추가할 수 있습니다.

요일별 업무 보드 (트렐로 칸반)
위 요일 버튼을 켜고 끄면(여러 개 동시 선택 가능) 켠 요일이 트렐로 컬럼으로 나란히 표시됩니다. 컬럼이 많으면 가로로 스크롤하세요. 각 컬럼 안에 👨남 / 👩여 / 🏢외곽 카드가 세로로 있고, 카드의 편집 버튼을 누르면 표(시간 칸 | 내용 칸)를 바로 편집할 수 있고, ＋ 행 추가/✕ 삭제로 항목을 늘리거나 지운 뒤 저장하면 모든 기기에 반영됩니다. 선택한 요일은 다음에 다시 와도 기억됩니다. 저장 시 시간 순으로 자동 정렬됩니다.
