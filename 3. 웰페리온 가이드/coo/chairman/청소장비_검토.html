아직 못 대는 것

지금 쓰는 청소 장비의 보유 현황(무엇을 몇 대·어떤 상태로 갖고 있는지)이 저장소에 없다 — 자산대장에 청소·관리 장비가 0건이다. 보유 현황 없이는 이번 견적이 비싼지 싼지 판단이 반쪽이다 — 현장 목록 확보가 먼저다.

참고 — 견적 전 사전조사(2026-08-07)
지하 1층(사우나·락커룸·복도) 청소 장비를 갖춘다 — ① 카처 중심 업소용 건·습식 겸용 청소기, ② 탕 물을 직접 끌어 쓰는 자흡식 고압세척기(수돗물 호스 없이 사우나 탕 물 이용 · 온수 사용 가능 온도 확인 필수), ③ 화장실 청소용 폼건(거품분사기)과 세제(사우나 바닥 산성세제 금지 준수), ④ 이태리산업 구매 품목 정리. 김남욱 GM 지시

결론 · 4갈래 요약 — 가격·온도·규정 확인된 것과 확인 못한 것을 구분

1) 청소기는 카처 WD4~WD5 국내 정가가 확인됐고 예산에 맞춰 바로 결정 가능합니다. 2) 고압세척기는 온수 입수 허용 온도가 K5=40°C, K7=60°C로 갈린다는 점이 핵심 — 탕 물(온탕·열탕) 실측 온도를 시설부에서 받아야 K5로 충분한지 K7이 필요한지 정해집니다. 3) 화장실 세제는 사우나 바닥에 산성세제 금지 규정이 이미 점검표에 있어 중성·알칼리성만 후보로 좁혔습니다. 4) 이태리산업은 웹 검색으로 특정하지 못해 확인 필요로 남겨둡니다.

갈래 1 · 청소기 가성비 WD4(199,290원)~최고가 업소용 NT48/1(국내가 확인 필요) — 바로 결정 가능.

갈래 2 · 고압세척기 K5(40°C 한계) vs K7(60°C) — 탕물 실측 온도 확인이 선결.

갈래 3 · 폼건·세제 세제는 산성 금지 규정상 중성·알칼리성 위주. 폼건은 가격 확인이 얇음.

갈래 4 · 이태리산업 웹에서 특정 불가 — GM·지원부 직접 확인 필요.

사내 SSOT 재확인 — 웰페리온 점검표(시설부·지원부 체계)에 “대리석·코팅면 산성세제 사용 금지”, “건/습식 사우나 바닥 고압세척(매주 수요일) · 산성세제 금지” 가 이미 명시돼 있습니다. 이번 검토의 세제·폼건 후보는 이 규정을 벗어나지 않는 범위에서만 뽑았습니다.

확인이 필요한 것

폼건 3종 모두 정확한 국내 결제 가격을 확보하지 못했다(쿠팡·지마켓 접속 차단·타임아웃). 중성 세정제(슈퍼액션)의 정확한 pH가 제조사 페이지에 표기돼 있지 않아 ‘중성 추정’일 뿐 확정이 아니다 — 실제 발주 전 제조사·판매처에 액성 확인이 필요하다.

4. 이태리산업 구매 품목 정리 웹 검색 범위에서 확인한 것만 — 지어내지 않음

확인 결과 — 특정 실패

“이태리산업”이라는 상호로 다나와·네이버·사업자정보(나이스비즈인포 등)·구글 검색을 여러 각도로 시도했으나, 세제·청소용품을 취급하는 동일 상호의 업체를 웹에서 특정하지 못했다. “이태리”가 들어간 회사명은 다수 존재하나(안경·물류 등) 청소용품·세제 업태와 일치하는 곳은 확인되지 않았다.

확인 필요 — GM 또는 지원부에 직접 문의가 필요하다. 실제 발주 내역(세금계산서·거래명세서)이나 지원부 담당자를 통해 상호·사업자번호·취급 품목군을 확보하면 이후 검토서에 채워 넣을 수 있다.

확인 방법 제안

  • 지원부 물품 구매 대장·최근 세제 발주 영수증에서 거래처명 확인
  • 회계(카드·계좌이체) 내역에서 “이태리산업” 또는 유사 상호 검색
  • 확인되면 취급 품목군·단가·거래 조건을 이 문서에 추가해 갈래 4를 완성한다
