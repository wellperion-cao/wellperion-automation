# 휴회 조기 방문 처리 기준

**작성**: AI COO 시우 (웰리 위임) · 2026-07-27
**배경**: 이경연M 피드백 FB260724-125420 (2026-07-24) · GM 판단 2026-07-25 · 시포 전달
**상태**: 초안 — 시포(CPO) 화면 반영 전 검토용

---

## 1. 정의

**휴회**: 멤버십 유효기간 내에 이용을 일시 중단하고 잔여 기간을 보존하는 제도.

**조기 방문**: 아래 두 상황을 포괄한다.

| 유형 | 설명 |
|---|---|
| **A형 — 시작 전 방문** | 휴회 신청 후, 지정 시작일 이전에 클럽을 방문하는 경우 |
| **B형 — 조기 복귀** | 휴회 기간 중(시작~종료 사이) 이용 재개 의사를 갖고 방문하는 경우 |

---

## 2. 처리 기준

### A형: 휴회 시작 전 방문

| 항목 | 기준 |
|---|---|
| 입장 여부 | **정상 입장 허용** |
| 멤버십 처리 | 오늘 이용은 정상 차감, 휴회 시작일은 변경 없음 |
| 실무 안내 문구 | "회원님 휴회 시작일은 [날짜]이며, 그 전까지는 정상 이용 가능합니다" |
| 시스템 처리 | 없음 (시작일 소급 변경 금지) |

**원칙**: 회원이 지정한 휴회 시작일은 변경하지 않는다. 시작일 이전 방문은 정상 이용으로 간주하며 잔여일에서 차감한다.

---

### B형: 휴회 기간 중 조기 복귀

회원에게 두 가지 선택지를 안내한다.

| 선택지 | 내용 | 처리 방법 |
|---|---|---|
| **① 즉시 복귀** | 오늘부터 이용 재개 (잔여 휴회일 포기) | 회원 동의 확인 → 시포(회원 화면)에서 휴회 종료일을 오늘 날짜로 수정 |
| **② 일정 유지** | 원래 휴회 종료일까지 대기 | 안내 후 종료일에 재방문 요청 |

**절차**:

1. 회원에게 두 선택지 설명 및 선택 확인
2. ① 즉시 복귀 선택 시 → 시포(CPO)에게 "휴회 조기 종료 처리" 요청 (회원명·연락처·오늘 날짜 전달)
3. 처리 완료 후 회원에게 구두 확인

**주의사항**: 즉시 복귀 선택 시 포기되는 잔여 휴회일 수를 회원에게 반드시 고지한다 (예: "남은 휴회일 15일이 소멸됩니다").

---

## 3. 실무진 확인 순서

```
방문 회원 → "혹시 현재 휴회 중이신가요?" 확인
                │
         아님 → 정상 처리
                │
         맞음 → A형인지 B형인지 구분
                │
     A형(시작 전) → 정상 입장 허용, 안내 문구 전달
                │
     B형(기간 중) → 선택지 ① / ② 안내 → 선택 확인
                         │
                    ① 즉시 복귀 → 시포에게 처리 요청
                    ② 일정 유지 → 종료일 안내 후 귀가
```

---

## 4. 시포(CPO) 연계 사항

이 기준이 확정되면 시포에게 아래 화면 반영 요청:

1. **회원 화면(membership.html) 휴회 패널**
   - "조기 복귀 처리" 기능 추가
   - 종료일을 오늘 날짜로 수정 → 잔여 휴회일 소멸 경고 표시 후 확인

2. **이경연M 회신**: 시포가 화면 반영 완료 후 기준 안내 회신 예정 (시포 소관)
