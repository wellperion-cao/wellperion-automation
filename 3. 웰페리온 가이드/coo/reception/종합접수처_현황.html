🙋 회원 접수 8종(분실물·습득물·시설물 고장·청결 이슈·컴플레인·칭찬·쓴소리·휴회)을 한 보드에서 접수→처리중→완료로 관리합니다. 모두 GAS 실시간 자동 반영 — 사람이 새로고침만 하면 됩니다.

② 새 접수를 넣는 법

  • 대부분은 회원이 직접 홈페이지 접수 폼으로 넣습니다 → 헤더의 📲 회원 접수 폼 링크가 그 폼입니다. 회원이 제출하면 이 보드에 자동으로 뜹니다.
  • 습득물만 다릅니다 — 직원이 물건을 주우면 별도 습득물 접수 폼으로 직접 등록합니다(카드 안 링크, ⑦ 참고).
  • 이 화면 자체에는 "새 접수 추가" 버튼이 없습니다 — 접수는 항상 폼에서 들어옵니다.

③ 처리 상태를 바꾸는 법

  1. 카드를 열어 「처리자」 칸에 본인 성함을 적습니다
  2. 「처리 메모」에 어떻게 하셨는지 남기고 [저장]을 누릅니다
  3. 「상태」 드롭다운에서 접수 → 처리중 → 완료로 바꾸면 즉시 저장됩니다 — 또는 [✅ 전달 완료] 버튼 한 번으로 바로 완료 처리도 됩니다

단, 🧳 습득물은 상태 드롭다운이 없고 [✅ 수령] 버튼으로만 완료되며, ⏸️ 휴회 접수는 여기서 상태를 바꿀 수 없습니다(각 ⑦·⑨ 참고).

④ 회원께 답변을 다는 법

  • 처리 메모 = 내부 기록용입니다. 회원은 못 봅니다.
  • 📣 회원 안내 = 회원이 접수를 조회할 때 실제로 보는 문구입니다. 비워두면 상태에 맞는 기본 문구가 대신 뜹니다.
  • 카드의 [📋 문구 복사] 버튼을 누르면 전달문구(처리 메모)가 복사됩니다 — 문자·카톡으로 그대로 보내시면 됩니다.

⑤ 접수자·처리자 점수는 이렇게 매겨집니다

  • 점수판 = 접수 1점 + 처리 완료 1점. 서버가 자동 계산하며, 화면은 그 값을 그대로 보여줄 뿐입니다.
  • 「접수자」 칸에 이름을 적어야 접수 1점이 붙습니다 — 비워두면 점수가 안 붙습니다.
  • 「처리자」를 적고 상태를 "완료"로 바꾸면 완료 1점이 붙습니다.
  • 점수판 상단 [이번 주]/[이번 달]/[전체] 탭으로 기간을 나눠 볼 수 있습니다.

⑥ 기한 초과란

카드 상단 배지가 기한 상태를 보여줍니다 — 정상(회색) → 임박(주황) → 초과(빨강, "+N시간/N일"). 카테고리마다 기본 기한이 있고, 카드마다 「기한(일)」 칸에 숫자를 넣어 그 건만 따로 조정할 수 있습니다(비우면 기본값 적용).

⑦ 분실물·습득물은 흐름이 다릅니다

📦 분실물 접수는 다른 카테고리와 같습니다(③의 3단계 그대로). 회원의 신고를 접수해 처리합니다.

🧳 습득물 접수는 별도 흐름입니다 — 직원이 습득물 접수 폼으로 등록하면 사진·습득 장소·시점이 카드에 뜹니다. 주인이 찾아오면 [✅ 수령]으로 서명을 받아 완료 처리하고, 잘못 등록했으면 [🗑 삭제], 폐기할 땐 [🖨 A3 처분공지]로 인쇄합니다. 습득 다음 달 공지 → 그다음 달 자동 폐기(월 사이클)이며, 카드 하단에 습득물 접수 폼·습득물 보기(공개)·운영 가이드 링크가 있습니다.

⑧ 헷갈리기 쉬운 것

  1. 습득물 카드는 「상태」 드롭다운이 없습니다 — 완료 처리는 반드시 [✅ 수령] 버튼으로만 됩니다.
  2. 「처리 메모」와 「📣 회원 안내」는 다른 칸입니다 — 회원에게 실제로 보이는 건 후자뿐입니다.
  3. 「접수자」 칸을 비워두면 카드는 저장돼도 접수 점수는 잡히지 않습니다.

⑨ 휴회 접수

이 보드에는 현황만 표시됩니다(읽기 전용). 승인·반려는 회원 관리 시트에서 처리합니다.

구분 칸에 신규 또는 연장이 뜹니다(GM 확정 2026-08-20). 연장은 이미 휴회 중인 분이 기간만 늘리는 신청입니다 — 7일 이상 휴회 중일 때 휴회 기간 안에서만 받고, 횟수는 차감하지 않고 일수만 늘립니다. 휴회가 끝난 뒤 들어온 건은 연장이 아니라 일반 휴회로 보아 횟수·일수를 함께 차감합니다.
