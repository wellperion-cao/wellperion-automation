A. 스포피아에서 매출 데이터 내려받기

▶
스포피아(POS)에서 그날의 매출 데이터를 엑셀 파일로 내려받습니다.
A-1 · 스포피아에서 메뉴 들어가기
스포피아에 로그인 → 화면 맨 위 오른쪽 ①[영업분석] 클릭 → 펼쳐진 목록에서 ②[매출 집계표(일별)] 클릭.
A-2 · 날짜 조회하고 엑셀로 저장
날짜를 그날로 맞추고 ③[찾기] → 매출 목록이 뜨면 ④데이터 클릭해 선택 → ⑤[엑셀] 버튼으로 엑셀 파일 저장.
A-3 · 내려받은 엑셀 원본 모습
엑셀을 열면 한 줄에 한 건씩 매출이 들어 있습니다. 이 파일로 다음 단계를 진행합니다.

B. 엑셀에서 데이터 가공하기

▶
원본을 [가공] 시트로 옮긴 뒤 필요한 값만 남깁니다.
B-1 · 원본에서 복사
내려받은 엑셀 원본에서 B열~V열 전체를 복사합니다.
B-2 · 가공 시트에 붙여넣기
구글시트 [가공] 시트(예: "2025년 0월 매출 및 급여")의 A1 칸을 클릭하고 붙여넣기(Ctrl+V). 붙여넣으면 아래처럼 채워집니다.
B-3 · 매크로1 — 데이터 정렬
Ctrl + Alt + Shift + 4를 동시에 누릅니다. 필요한 값만 추려 정렬해 주는 매크로입니다.
  • 옛 안내문엔 "Ctrl+Art+Shift"로 적혀 있지만 가운데 키는 Alt가 맞습니다.
B-4 · 매크로2 — 불필요한 열 삭제
이어서 Ctrl + Alt + Shift + 5를 누릅니다. 필요 없는 열을 지워 줍니다.
B-5 · 전체 데이터에 필터 씌우기
데이터 전체를 선택한 뒤 필터 버튼을 눌러 필터를 씌웁니다.
B-6 · 품목별 오름차순 정렬
C열(품목) 기준으로 오름차순 정렬하면 같은 품목끼리 모입니다.
B-7 · 매출 0원 줄 삭제
D열(매출)이 0원인 줄은 삭제합니다. (주차권 등 0원 데이터)
B-8 · 결제수단(E열) 채우기
결제수단은 카드사 열(H열)을 보고 채웁니다.
  • H열(카드사)에 값이 있으면 → E열(결제수단)에 그대로 복사/붙여넣기.
  • H열(카드사)에 값이 없으면 → 영수증리스트·일일옵션 확인 후 직접 기입. 예) ①현금결제는 영수증리스트 확인, ②서울페이는 일일옵션에 기재됨.
B-9 · 마지막 점검
담당자 · 결제금액 · 결제수단이 맞는지 확인하고, 회원권 매출과 강습 매출을 구분해 둡니다.

C. 시트에 입력하기

▶
정리한 데이터를 회원권/강습 시트와 매출보고서에 옮겨 적습니다.
C-1 · 회원권 시트 입력
[회원권] 시트의 해당 날짜 칸에 A~G열 데이터를 입력합니다.
C-2 · 강습 시트 입력
[강습] 시트의 해당 날짜 칸에 A~G열 데이터를 입력합니다.
  • 반드시 해당 날짜 칸에 입력해야 보고서에 반영됩니다. 날짜를 꼭 확인하세요.
C-3 · 등록분류 · 등록경로 확인
당일 날짜 시트에서 회원권 매출의 등록분류(자동)와 등록경로(수동)를 확인합니다.
  • 회원권 등록경로는 ‘멤버십’ 시트의 ‘신규문의’에서 찾을 수 있습니다.
  • 라커·일일입장·굿즈는 등록분류·등록경로를 둘 다 비워 둡니다.
  • 정상 회원권 등록(신규·재등록)이 아닌 특이사항(업/다운그레이드, 결제변경 등)은 등록분류만 채우고 등록경로는 비움.
  • 인원 수 카운팅 → 회원권 칸은 등록경로, 강습 칸은 등록분류로 셉니다.
C-4 · 수기 입력 항목(4종)
아래 4가지는 자동이 아니라 직접(수기) 입력합니다.
  • 1) 단말기 매출 : 리셉션 단말기 집계 영수증 확인(특이사항 외 거의 없음).
  • 2) 무인발권기 : 스포피아 영수증리스트 → 신용카드 → 찾기(당일 날짜).
  • 3) 스포피아 금액 : 영수증리스트의 (현금+카드) 합계.
  • 4) 스포피아 현금영수증 : 영수증리스트 내 현금결제 합계(승인번호 꼭 확인).

D. 최종 확인

▶
보고서를 닫기 전 아래 4가지를 점검합니다.
D-1 · 비고차액
비고(차액)가 생기면 특이사항 칸에 이유를 기재합니다.
D-2 · 당일 LOSS현황
‘멤버십’ 시트 → 유효회원 → LOSS 날짜 입력.
D-3 · 일일방문객
회원분석 → 회원 출결 정보리스트(일자별) → 검색조건(수강분류: 스포피아플러스·회원권)으로 확인해 기재.
D-4 · 수식오류 체크
그 밖에 수식오류가 없는지 마지막으로 확인합니다.

E. 특이사항 처리

▶
환불·강습변경은 매출/인원이 틀어지기 쉬우니 규칙대로 처리합니다.
E-1 · 회원권 환불
회원권 공제금 = 이용금액 + 위약금으로 처리.
E-2 · 강습 환불
강습 공제금 = 수업 진행분으로 처리하고 위약금은 따로 처리.
E-3 · 강습변경
선생님 매출(페이롤)이 맞아야 하므로 반드시 신경. 환불처리로 카운팅됐던 인원 수 정상화.
