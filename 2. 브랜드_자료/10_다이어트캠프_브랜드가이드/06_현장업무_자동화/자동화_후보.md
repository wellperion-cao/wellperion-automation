# 다캠 현장업무 자동화 — 후보 목록 (GM 지시 2026-09-03)

> 대표님이 손으로 반복하는 일을 아침 질문으로 받아 적고, 웰페리온에서 이미 돌고 있는 것으로 옮길 수 있는 것부터 정리한다.
> 지어내지 않는다 — 「대표님 답」 칸이 비어 있으면 후보일 뿐이다. 답이 오면 그 줄을 채우고, 옮길 수 있으면 Before&After 페이지로 보여드린다.

| 현장에서 손으로 하는 일(후보) | 대표님 답(미수령이면 비움) | 웰페리온에서 이미 도는 것 | 다캠에 옮기면 |
|---|---|---|---|
| 예약·취소·노쇼 접수 | | 무조건 예약제 + 종합접수처(폼→시트→카톡 알림) | 예약 폼 1장 + 카톡 확인 자동 |
| 문의 답장 | | 문의 접수처 + 카톡 답장 에이전트(다캠 방에서 이미 가동) | 자주 묻는 질문 자동 답장 |
| 출석·잔여 횟수 안내 | | 강습 등록원장(횟수·종료일) | 잔여 횟수 자동 안내 |
| 재등록 안내 | | 회원 종료 예정 스냅샷 → 안내 | 종료 2주 전 자동 안내 |
| 결제 안내 | | (금액·결제 = GM 결재 영역, 자동화 대상 아님) | — |
| 식단 사진 피드백 | | 없음 | 후보만 — 대표님 답 뒤 판단 |
| 회원 기록(수첩·엑셀·앱) | | 회원 DB 시트 | 시트 1장으로 통합 |
