# 마케팅 자동 발행 파이프라인 — 인사팀 전달 자료

> 인사팀이 우리 마케팅 자동 업로드·파이프라인을 **자기 도메인에 적용**하기 위한 한 장 안내.
> 작성: AI CMO(시모) · 2026-07-18 · 대상: 인사팀 + 시로(CHRO)/시토(CTO)

---

## 1. 이게 뭔가 (한눈에)

콘텐츠를 **만들고 → 검수하고 → 여러 채널에 자동 발행하고 → 성과를 보는** 흐름을 반자동화한 시스템입니다.

```
기반  →  제작  →  검수  →  발행(여러 채널 자동)  →  성과  →  (다음 기획으로 환류)
```

사람은 **각(내용·방향)**만 정하고 승인하면, 나머지(여러 채널에 올리기·링크 회수·요약 보고)는 자동으로 돕니다.

---

## 2. 핵심 원리 — 모든 콘텐츠는 '기반'에서 나온다

파이프라인의 뿌리는 **기반(FOUNDATION)** 입니다 = 회사소개서 + 전략 + 브랜드(톤·금지어·타깃).
새 콘텐츠를 만들어도 이 기반에서만 움직여 브랜드·전략에서 벗어나지 않습니다.

> **인사팀은 '기반'만 인사판으로 바꿔 끼우면 됩니다.**
> (마케팅 기반 정본 예시: `2. 브랜드_자료/웰페리온_기반_FOUNDATION.md` — 이 구조 그대로, 값만 인사 도메인으로 교체)

---

## 3. 인사팀이 정할 것 (설정 4종만 바꾸면 됨)

| 설정 | 인사팀이 채울 내용 | 예시 |
|---|---|---|
| ① 기반 | 인사 도메인 소개 · 목표 · 톤 · 금지어 · 타깃 | "좋은 동료를 모으고 지킨다" / 신뢰·진솔 톤 |
| ② 채널 · 자격증명 | 어디에 올릴지 + 로그인 정보 | 채용 채널·사내 게시판·인사 SNS 등 |
| ③ 콘텐츠 템플릿 | 인사 콘텐츠 양식 | 채용공고 · 사내소식 · 복지·문화 안내 |
| ④ 자동보고 방 | 발행 요약을 받을 방 | 인사팀 텔레그램/카톡 방 |

**이 4종만 인사판으로 채우면 파이프라인 흐름은 그대로 재사용됩니다.**

---

## 4. 재사용하는 뼈대 (복사 말고 공용)

마케팅팀이 이미 만든 공용 부품을 그대로 씁니다 — 새로 개발할 것 아님:
- **검수 등록**(제작완료 → 검수 대기로) · **검수 큐**(승인/반려) · **발행 디스패처**(여러 채널 자동) · **접근 게이트**(권한)
- 발행 요약 자동 보고 · 링크 회수·정정

---

## 5. 적용 순서 (셋업)

1. **기반(FOUNDATION) 인사판 작성** — 위 §2 구조로
2. **채널 · 자격증명 등록**
3. **콘텐츠 템플릿 정의** (인사 양식)
4. **소량 검수·발행 테스트** (한두 건으로 흐름 확인)
5. **자동보고 방 연결**
