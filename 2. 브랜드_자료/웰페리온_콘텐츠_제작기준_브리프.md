## 2. 누구에게 · 왜 (전략)

- **콘텐츠용 외부 포지셔닝 문구(GM 확정, 2026-06-06 deep-interview) = "프리미엄 라이프스타일 클럽."** "스포츠·스파·웰니스가 한 공간에 통합된 곳" / "하루의 품질을 설계하는 곳"으로 풀어 쓴다.
- 회사소개서상 타겟(For Members)은 한남동 3,000평 프리미엄 라이프스타일을 찾는 층 — **유소년(WSC 7개 종목)부터 시니어까지 가족 전 연령**을 커버.
- 전략로드맵 3단계("브랜드 구축", 예정 단계) 목표 = **"하이엔드 웰니스 & 멘탈 케어 허브" 포지셔닝 확립** + 공간 밸류업 + 외부 콘텐츠 제휴. 콘텐츠 각(§4)의 "운동↔마음" 연결은 이 방향과 일치.
- 현재(2026-07) 로드맵상 위치 = 1·2단계(자동화·매뉴얼 체계 + 체크리스트 경영·핵심 인재 확보) 동시 진행 중. 3단계 브랜드 구축은 "예정" 단계.
- **확인 필요** — 전략로드맵 v1.5는 GM 직속 3라인·부서 통합관리 등 조직·운영 로드맵이 중심이며, 콘텐츠 마케팅 전용 구체 타겟 연령·팔로워/전환 수치 목표는 문서에 없음. 콘텐츠 KPI 수치 목표는 별도 확인 필요.

## 3. 톤 · 보이스

- **대놓고 마케팅 금지.** "지금 등록!" 같은 강한 후킹·세일즈 압박 표현 사용하지 않는다.
- 강습·서비스 안내는 **"한남동에 성인을 위한 전문성 있는 강습하는 곳이 있다" 정도로 알리는 선까지만.** 압박 0.
- 내용 방향은 **'천천히 루틴을 만드는'** 결 — 서두르지 않고 꾸준함을 말한다.
- 전문성은 **은근히** 드러낸다(과시 금지).
- 개인(@namuk.wellperion)·공식(@wellperion) 두 계정 **공통 톤** — 계정이 달라도 무드는 동일.

## 4. 콘텐츠 각 (무엇과 연결)

- **참신함의 핵심 = 운동/서비스를 마음·정신건강·현대인의 삶과 연결.** "1:1 맞춤", "실내에서 폼부터", "전신 운동" 같은 진부한 기능 클리셰는 반려 대상.
- 종목별 마음 각(예시): 수영=디지털 디톡스(알림 안 닿는 유일한 30분) · 스쿼시=잡생각 제로(스트레스 해소) · PT=핑계가 안 통하는 자기직면 · 골프=조급함·힘빼기 · 필라테스=몸과 화해·자기수용 · 그룹강습=어른의 외로움.
- 기획 시 항상 먼저 물을 질문: **"이걸 마음/삶의 어떤 진실과 연결하나?"** — 기능 나열은 그다음.
- 톤은 **담담한 통찰**까지만. 설교조·현학적·AI스러운 미사여구 금지.
- **현실감 필수** — 실제로 일어날 법한 장면·경험으로 구성. 멋있어 보여도 사실과 안 맞는 비현실·과장 설정(예: "AI가 당직 선다")은 금지.

## 7. CTA · 해시태그 표준

- **CTA 표준(전 채널 공통, 한 줄·한국어만):**
  ```
  문의 : wellperion.com/ko/inquiry
  ```
  영어 줄·`litt.ly` 링크는 폐기됨. IG·당근은 본문에 평문 URL을 넣지 않고 프로필 링크(bio)로 유도 — 캡션 말미는 "궁금하신 점은 프로필 링크로 문의해 주세요" 류 안내 문구만.
- **해시태그 순서 고정(전 채널 공통):** ① 지역+종목(`#한남동골프` 등) → ② 종목·주제·타겟 태그(유소년·주니어 등 대상층 포함) → ③ `#웰페리온 #WELLPERION` 맨 끝 2개 고정.
  예: `#한남동골프 #유소년골프 #주니어골프 #KPGA #골프레슨 #스포츠클럽 #웰페리온 #WELLPERION`

3. 이 콘텐츠는 "1:1 맞춤"·"전신 운동" 같은 기능 클리셰가 아니라, 운동을 마음/삶의 진실과 연결하는 각을 갖고 있나? (§4)
4. 장면·경험이 실제로 일어날 법한 현실적인 내용인가, 비현실·과장 설정은 없나? (§4)
5. 계정(개인/공식)에 맞는 로고·컬러·디자인 톤을 썼나? (§6)
6. CTA는 채널 규칙대로(IG·당근은 bio 유도, 평문 URL 없음) 처리됐나, 해시태그 순서는 지켰나? (§7)
