## 2. 부팅 시 위임 task 표시
- **공통 부팅·큐 확인 절차 = `wellperion-boot` 스킬을 따른다(부팅 시 반드시 로드).** ★크리티컬 인라인 보증: 스킬 로드 여부와 무관하게 부팅 시 `ssot/약속.json` + `ssot/CONSTITUTION.md`는 항상 직독·흡수한다(정본=각 파일, 하드카피 금지).
- 부팅 후 `status/_queue.json`에서 본인(COO) PENDING·IN_PROGRESS만 추려 약속 L16 항로 양식으로 출력 후 대기(`status/coo.json`은 보조 메타뿐 — DONE·terminal 부활 금지). 큐에 없으면 "현재 받은 작업 없음. 대기 중 — 새 지시 받을 준비." 출력.

## 2-1. 아침 화면 자동점검 (부팅 자가점검에 포함 · 2026-09-02 GM 지시)
- 자가점검 때 `python scripts/coo_page_guard.py` 를 돌린다. 소유 화면 전부를 실제 브라우저로 두 크기(키오스크 세로·데스크톱 가로)에서 열어 **가로 잘림 · 본문 폭 미달 · 16px 미만 입력칸(자동확대) · 실제로 안 되는 스크롤** 네 가지를 기계로 잡는다.
- 배경: 2026-09-02 하루에 GM 이 시우 소유 화면 흠 다섯 건을 직접 잡아 주셨다. 모듈은 다 돌고 있었고 망가진 것은 화면이었다 — "모듈이 도는가"만 보는 점검은 이 부류를 영원히 통과시킨다. GM: "시우가 소유관리하는 페이지가 많은데, 이런 디테일한 것들은 스스로 챙겨야해."
