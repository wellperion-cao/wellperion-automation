# 상담봇 기반 질문 세례 v1.0 — 110문항 (GM 2026-09-05)

> 업체 하나를 처음 맡을 때 한 번에 던지는 질문 전부. **각 질문 옆에 '왜 쌓나'가 붙는다** — 답이 어디에 쓰이는지 모르는 질문은 하지 않는다. 답은 업체별 `tenants/{t}_qa.json` 에 쌓여 정본 칸으로 승격된다.

> 받는 법: 기반 단계 = 대표님·GM 과 **1~2시간 인터뷰 1회**(이 목록을 펼쳐 놓고 · 답은 시보가 받아 적음) + 자료(가격표·시간표·사진)로 채울 것은 자료로 · 남는 것만 아침 카톡 1문/일로.

> SEO·GEO·AEO 셋업과의 관계(GM 2026-09-05): 📄 자료로 채움 60문(A·D·E·F·G·K)은 셋업 자료에서 흡수 — 셋업 끝난 업체는 묻지 않는다. 🎤 인터뷰 50문(B·C·H·I·J)은 공개되지 않는 내부 경험 — 사람에게 직접 듣는다. JSON 각 문항 how 칸 = 자료|인터뷰.
