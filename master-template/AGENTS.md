# AGENTS.md — 에이전트 기계 계약

> 이 파일이 모든 에이전트의 헌법. 지시 우선순위: 이 파일 > 개별 에이전트 파일 > 런타임 프롬프트.

## 미션

```
[이 프로젝트의 미션을 한 문장으로 교체하세요]
예: 웰페리온 스포츠클럽 운영 자동화를 완성한다
```

## 부팅 (필수 — 반드시 먼저 실행)

에이전트 시작 시 아래 3종 JSON을 **직독**해 흡수한다. 페이지 렌더 금지.

```
ssot/약속.json      # 공유 규칙·교훈
ssot/incidents.json # 재발방지 사례
ssot/canon.json     # 공식값 레지스트리
```

흡수 후 확인: 로드된 약속 수 / 미해결 인시던트 수 / 공식값 키 목록 출력.

## 지시 우선순위

1. `ssot/약속.json` 약속 (불변)
2. 이 파일 (AGENTS.md) 조항
3. 개별 에이전트 파일 (`agents/`)
4. 스킬 파일 (`skills/`)
5. 런타임 지시

상위가 하위를 항상 이긴다. 충돌 시 상위 준수 후 에스컬레이션.

## 인테이크

새 작업 진입 시:
1. `skills/intake/SKILL.md` 실행
2. 목표·범위·성공조건·제약 명확화
3. 모호도 > 5% → 휴먼 승인 요청
4. 명확화 완료 → `state/_queue.json`에 태스크 추가

## 계획 및 분해

- `skills/decompose/SKILL.md` 실행
- 태스크를 검증 가능한 단위로 분해
- 각 단위: 입력·출력·검증 조건 명시
- 의존성 그래프 작성 (병렬 가능한 것 병렬화)

## 에이전트 라우팅

| 태스크 유형 | 담당 에이전트 | 권장 모델 |
|------------|--------------|---------|
| 전략·통합 판단 | orchestrator | Opus |
| 계획·분해 | planner | Opus |
| 실행·구현 | executor | Sonnet |
| 검증·품질 | reviewer | Sonnet |
| 리서치·정보 | researcher | Haiku/Sonnet |

라우팅 규칙:
- 판단·결정·검토 = 상위 모델 (Opus)
- 루틴·실행·집계·송부 = 하위 모델 (Sonnet/Haiku)
- 반복 작업에 Opus 직접 사용 = 위반

## 실행 원칙

- 이미 읽은 파일 재확인 금지
- 독립적인 도구 호출은 병렬 실행
- 불필요한 도구 호출 금지
- 20줄+ 출력은 서브에이전트 위임

## 검증

완료 = 다음 4요건 모두 충족:

1. **완전성**: 명세된 모든 항목 처리됨
2. **정확성**: 실제 결과가 기대값과 일치 (상태값 변경만으로는 불충분)
3. **검증 증거**: 재현 가능한 증거 존재 (스크린샷·로그·테스트 결과)
4. **문서 최신**: 관련 SSOT 업데이트됨

`skills/verify/SKILL.md` 및 `loop/quality-gates.md` 참조.

## 반성

사이클 종료 시 `skills/retrospective/SKILL.md` 실행:
- 잘된 것·개선점·재발방지 조치 도출
- 새 교훈 → `ssot/약속.json` 추가
- 인시던트 → `ssot/incidents.json` 추가

## 메모리

- 세션 간 영구 기억: `state/memory/` (파일별 1개 사실)
- 작업 큐 단일 진실: `state/_queue.json`
- 규칙: 메모리에 없으면 항로에도 없다
- `skills/memory-update/SKILL.md` 참조

## 정지 조건

아래 중 하나 충족 시 즉시 중단 + 에스컬레이션:

- [ ] 재시도 예산 소진 (태스크당 최대 3회)
- [ ] 최대 사이클 초과 (기본 10사이클)
- [ ] 수렴 불가 (3사이클 연속 진전 없음)
- [ ] 휴먼 승인 필요 항목 미승인 상태
- [ ] 공식값(`canon.json`) 누락으로 진행 불가
- [ ] 파괴적 동작 감지 (데이터 삭제·외부 발행·결제)

## 재시도 예산

- 태스크당: 최대 3회
- 동일 오류 2회 반복 시: 다른 접근법 시도 또는 에스컬레이션
- 예산 소진 = BLOCKED 상태로 전환, 사유 기록

## 에스컬레이션

아래는 반드시 휴먼 승인:
- 💰 결제·비용 발생
- 🔒 보안·인증·권한 변경
- 🚫 파괴적 동작 (삭제·덮어쓰기·외부 발행)
- 전략적 방향 전환
- 공식값 변경

승인 없이 진행 = 계약 위반.
