# AGENTS.md — 에이전트 기계 계약

> 이 파일이 모든 에이전트의 헌법. 지시 우선순위: 이 파일 > 개별 에이전트 파일 > 런타임 프롬프트.

---

## 미션

웰리는 스포츠클럽의 모든 문제를 자동화·고도화하기 위해 존재하며, 단일 도구로 ERP를 활용한다.

---

## 부팅 (필수 — 반드시 먼저 실행)

에이전트 시작 시 아래 4종을 **직독**해 흡수한다. 페이지 렌더 금지.

```
ssot/약속.json         # L01~L17 공유 약속
ssot/incidents.json    # 재발방지 사고원장
ssot/canon.json        # 공식값 레지스트리
ssot/kpi.json          # 역할별 담당 KPI (존재 시)
```

부팅 후 확인: 로드된 약속 수 / 미해결 인시던트 수 / 공식값 키 목록 출력.

S2(웰페리온 가이드 HTML)는 사람용 렌더 — JS 렌더 페이지에서 규칙 흡수 시 "불러오는 중…"만 보임. **정본 = ssot/ 직독.**

---

## 지시 우선순위

1. `ssot/약속.json` L01~L17 (불변)
2. 이 파일 (AGENTS.md) 조항
3. 개별 에이전트 파일 (`agents/`)
4. 스킬 파일 (`skills/`)
5. 런타임 지시

상위가 하위를 항상 이긴다. 충돌 시 상위 준수 후 에스컬레이션.

## 절대 기준 3대

### ⚖️ 절대 원칙 (항상 우선 적용)

1. **단일 진실**: 한 주제는 한 곳에만 존재. 중복 하드코딩 금지.
2. **코드로 박제**: 약속·재발방지·규칙은 문서가 아닌 기계가 읽는 JSON/코드로.
3. **실증 검증**: 완료 = 상태값 변경이 아닌 실제 결과 재현.

### ✅ 완료 4요건

완료 선언 전 4가지 모두 확인:
1. **완전성**: 명세된 모든 항목 처리됨
2. **정확성**: 실제 결과가 기대값과 일치
3. **검증 증거**: 재현 가능한 증거 존재 (로그·파일·스크린샷)
4. **문서 최신**: 관련 SSOT 업데이트됨

### 🌉 브릿지

완료마다 '다음'을 남겨 항로가 끊기지 않게. 완료 시 후속 배를 `state/_queue.json`에 등록.
