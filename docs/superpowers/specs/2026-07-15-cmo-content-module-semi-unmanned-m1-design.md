# AI CMO 콘텐츠 모듈 — 반무인 자동화 + M1 페이지 재정렬 (설계)

**날짜:** 2026-07-15 · **소유:** 시모(CMO) · **연결:** ship 747(제품화 레퍼런스) · `2026-07-09-clevel-autonomy-shared-platform-design.md` · 메모리 `project_clevel_autonomy_brain_productization`

## 0. 배경·GM 결정
GM 비전: 각 C-Level 업무를 '모듈'로 정리하고 나중에 타 업체에 판매(제품화). AI CMO(콘텐츠 제작→검수→5채널 자동발행)가 플래그십.
- **제품/‘AI 없이 도는’ 프레이밍은 ERP 페이지에 노출 금지 — GM·시모 내부 지식으로만.** 페이지는 파이프라인을 잘 구성·자동화하는 데 집중.

## 1. 자동화 모델 — 반무인 → 완전무인 (GM 확정 2026-07-15)
| 모드 | 흐름 | 사람 개입 | 시점 |
|---|---|---|---|
| **반무인** | AI 자동생성 → **사람 [승인] 1회** → 자동발행 | 승인 탭 1회 | **지금 (기본)** |
| **완전무인** | AI 자동생성 → **자동승인(품질 게이트만)** → 자동발행 | 0 | **신뢰 쌓인 뒤** |
- 두 모드 차이 = **승인 게이트 하나**. 완전무인 전환 = 승인 자동화 스위치(기본 OFF), 무결성 게이트를 강화한 뒤 GM go로 켠다.
- 신뢰 기준(전환 조건, 후속 확정): N회(예 10회) 무결 발행 실증 후 채널·유형별로 단계 전환. 메모리 `feedback_live_verify_always_then_taper_with_trust` 준용.

## 2. 정직 경계 (과장 금지 · 약속 L05)
- **제작(창작)** = AI 엔진(또는 사람)이 담당. "무인"은 가능(스케줄 AI 생성)하나 **"AI 없이 무에서 생성"은 불가**. 템플릿 렌더(정해진 텍스트→슬라이드)만 순수 스크립트.
- **발행(배포)** = **AI 없이 스크립트로 무인 구동** (예약작업+Playwright+게이트). 진짜 AI-free 조각.
- **검수** = 반무인(사람 1탭) / 완전무인(자동승인).
- ⇒ 제품 경계 = **"고객(또는 AI)이 콘텐츠만 공급 → 엔진이 5채널 무인 배포."**

## 3. M1 페이지 재정렬 (제작→검수→발행→보고)
현행 16섹션이 흩어져 과밀 → **일 흐름 순서**로 그룹핑:
- **상단:** 간결 모듈 라인(이 모듈은·CMO 콘텐츠 운영) + 📊 마케팅 현황 + 🔗 문의 진입점
- **① 제작:** 🌟 북극성 제작 루프
- **② 검수:** 📨 검수 대기 · ✅ 채널별 검수 프로세스 — *반무인 [승인] 지점(내부 주석: 신뢰 후 완전무인)*
- **③ 자동발행:** 🚀 5채널 발행 방식 · 📡 채널 현황 · 🏁 종료 절차
- **④ 정기·보고:** 🗓️ 정기 보고
- **📎 참고·규칙 (하단 토글로 접기):** 🏛️ 6대 기둥 · 📐 홈페이지 구성 · 🗂️📁📤 폴더 3종 · 📋 표기 규칙 · 📑 안내 가이드
- **보존 필수:** 모든 앵커 id(m1-*)·라이브 배선(kpi_values fetch·검수대기 카운트·자동화 스크립트)·자동발행 파이프. 재배치는 순서만, 기능 회귀 0.

## 4. 내부 셋업 가이드 (GM·시모 전용 · 페이지 아님)
AI 없이 자동발행이 돌기 위한 모듈 셋업 3요소 (= 스펙 747 Platform B):
1. **채널 계정·세션 등록** — IG·네이버(블로그·카페)·카카오·당근 로그인 프로필 1회 등록·자동로그인
2. **예약작업 등록** — 무인 구동 스케줄(발행 감시기·디스패처·수집기)
3. **큐·게이트 배선** — 검수→승인→발행 파이프 + 무결성/요새화 게이트
→ 타 업체 도입 = 자기 채널만 등록하면 동일 엔진 재사용. (실제 구현 로드맵은 747)

## 5. 재발방지·가드
- 페이지에 제품/‘AI 없이’ 문구 노출 금지(내부 전용) — 리뷰 시 확인.
- 완전무인 자동승인 스위치는 기본 OFF·GM go·즉시 역롤백(비가역 발행 보호).
- M1 재정렬은 앵커·배선 보존(기능 회귀 0)이 완료 조건.
