## 1. 목표

현재 메인 문의 페이지(`/ko/inquiry/`, WP page 8394)는 **6종 구글폼 버튼 그리드**다(멤버십·성인강습·유소년강습 3종만 자체폼 링크로 전환됨, 나머지 3종은 구글폼). 이를 **6종 전부 자체 프리미엄 폼**으로 전환한다.

**완료 정의:**
1. 6종 유형별 전용 화면(가이드 + 폼)이 프리미엄 디자인(B안 브랜드 정본색)으로 완성
2. 메인 허브(`/ko/inquiry/`)의 6버튼이 각 유형 전용 화면으로 연결
3. 6종 모두 제출 → 구글시트 저장 무결(유실 0) + 텔레그램 알림
4. 라이브(시크릿 크롬) E2E 검증 통과
5. 구글폼 완전 교체 발효 = **GM go**(비가역 유입경로)

## 3. 아키텍처

### 3.1 페이지 구조 (단일 self-contained 파일 + ?type= 딥링크)

```
/ko/inquiry/ (메인 허브 = 6버튼)  ← wp_inquiry_block.html 리디자인(B안 톤)
     │  각 버튼 → 아래 딥링크
     └─ /ko/inquiry-form/?type={membership|adult|youth|summer|rental|business}
            = wp_inquiry_form.html (단일 정본, ?type=로 유형별 전용 화면 렌더)
                ├─ 유형별 가이드 블록 (GUIDES[type])
                ├─ 유형별 폼 (FORMS[type])
                └─ 제출 → GAS intake_submit → 유형별 구글시트 라우팅
```

- **단일 파일 유지 근거:** 6개 별도 파일은 디자인·엔진 중복 → 유지보수 6배·드리프트 위험(INC-001 결). `?type=` 딥링크가 이미 구현돼 있어(현행 3종) 사용자에겐 "버튼→전용 화면"으로 동일하게 보임. 유형 미지정 진입 시 6버튼 선택 화면 폴백.
- 메인 허브(`wp_inquiry_block.html`)도 B안 톤으로 리스킨하되, **기존 구글폼 버튼은 롤백 자산으로 보존**(발효 전까지 병렬).

### 3.2 유형별 폼 필드 (FORMS)

기존 3종(membership·adult·youth)은 현행 유지, 신규 3종 추가:

| 유형 | 핵심 필드 |
|---|---|
| membership | 성함·연락처·관심프로그램(多)·경로·투어희망일·문의사항 |
| adult | 성함·연락처·강습종목(多)·희망시간·경로·문의사항 |
| youth | 성함(보호자)·연락처·자녀나이·강습종목(多)·희망시간·경로·문의사항 |
| **summer**(여름특강) | 성함·연락처·대상(성인/유소년)·집중종목(多: 수영·체조·스쿼시·골프·유소년PT)·희망월(7/8월)·문의사항 |
| **rental**(공간렌트) | 성함·연락처·대관공간(多)·용도(행사·촬영·세미나·워크숍·모임)·희망일·인원·문의사항 |
| **business**(비즈니스) | 회사명·담당자·연락처·제휴유형(콜라보·입점·B2B복지·콘텐츠·공급·투자)·소개자료 링크·제안내용 |

전 유형 공통: 개인정보 수집·이용 동의(PIPA) 필수 + 허니팟·타이밍게이트(현행 스팸방어 유지).

### 3.3 저장 라우팅 (백엔드 GAS `intake_submit`)

- **기존(무변경):** membership → `'26년 신규문의'` 탭 / adult·youth → `'강습 신규문의'` 탭
- **신규 3종 라우팅 추가 필요(시토/시포):** summer·rental·business의 저장처 결정 + `intake_submit` category 분기 추가.
  - 권고: summer → `'강습 신규문의'`(집중강습이라 강습 계열) 또는 전용 탭 / rental·business → 각 전용 탭 신규(구글폼 응답탭 대체).
  - ⚠️ 신규 탭 추가 시 헤더 상수(LESSON_INTAKE_HEADERS 패턴)·시트 append 로직·텔레그램 알림 문구 3곳 동시 배선(feedback_new_ledger_subkey_wire_all_consumers).
- 텔레그램 알림: 현행 `_notifyTelegram`(doPost 인라인) 6종 공통 재사용.
