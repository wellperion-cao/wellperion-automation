## 1. 배경
개인 시리즈를 여름 시즌 맞아 "완전 새로운 디자인"으로 개편(GM 지시). 범위 = **개인계정 디자인 시스템 전면 개편**(에메랄드 시그니처 유지, 템플릿·레이아웃·무드 새로). 현재 "따뜻한 종이" 룩에서 탈피.

## 2. 이야기 (콘텐츠가 스킨보다 먼저 — GM 확정)
**3번째 이야기 = "시스템은 AI가, 공간은 내가."**
- **AI로 ERP(시스템)를 짓고**, 그렇게 번 시간을 **스포츠클럽 '공간의 본질' 연구**에 쓴다 — 더 큰 실효를 위해.
- 디지털 시스템은 AI가 / 물리 공간은 사람이. 이 이중성이 핵심 대비.
- **실화 기반**(지어내지 않음). 오늘 실제로 마케팅 측정을 AI가 대신 보게 만든 것이 근거.

### 스토리 스파인
| 단계 | 내용 |
|---|---|
| Before · 반복 | 매일 손 가던 운영 — 숫자 집계·점검 취합·보고·발행 검수 |
| Shift · AI | AI로 ERP를 짓는다 — 반복 운영은 시스템이 대신, 사람은 확인·결정 |
| After · 본질 | 공간의 본질 연구 — 스포츠클럽이 무엇이어야 하나·공간이 주는 실효 |

## 3. 디자인 시스템 (형식=메시지)
핵심 원리: 주제가 '공간의 본질' → **여백(빈 공간) 자체를 디자인 언어**로. 화려함을 비우면 공간·본질이 말을 함.

- **여백 그릇**: 넓은 화이트스페이스, 밝고 시원한 여름 에디토리얼. (기존 "따뜻한 종이" 폐기)
- **자동화 신호 한 줄**: 하단 모노스페이스 상태줄(예: `auto-run · ERP가 반복 운영 처리 중` / 실제 자동 처리 건수) = "시스템은 AI가"를 담음. 숫자는 **실값만**.
- **에메랄드 시그니처 유지**: 라이트 #2E6E5B / 다크 #63BBA0. 딥 에메랄드 잉크 #164b3a.
- **여름 악센트**: 시트러스 #d9c94a(하이라이트 #ecdf6a) — 좌측 레일·헤드라인 밑줄 한 곳만.
- **W 심볼 유지**: 딥 에메랄드 배경 라운드 배지.
- **바탕**: 쿨 페일 민트그레이 #eef3f0 + 하단 밴드 #e5ede8.
- **타이포**: 한글 시스템 스택(Pretendard/Apple SD Gothic/Malgun) · 헤드라인 굵게(850)·타이트 트래킹 -.022em · 모노=상태줄.
- **비율**: 인스타 4:5. 좌측 시트러스 레일 + 좌여백.

## 4. 템플릿 세트 (한 벌)
1. **표지(Cover)**: 헤드라인("시스템은 AI가. 공간은 내가.") + 서브 + 자동화 신호줄 + W + 저장 CTA.
2. **본문(Body)**: `AI가 대신(반복) → 내가 집중(본질)` 2열 대비 그리드 + 자동화 신호줄. 실제 내용(ERP 자동화 항목 / 공간 연구 항목)로 채움.
3. **마무리(Closing)**: (미확정) 저장·팔로우 유도 + 다음 편 브릿지. 카피 후속 확정.
