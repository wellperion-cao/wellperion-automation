## 2. 계약 스키마 — 결정→실행SSOT 박제 계약

### 2.1 핵심 개념
각 자동 루틴에 대해 **"실행 SSOT"**(=코드가 '무엇을 발행/발송/선정할지' 결정할 때 읽는 유일한 원천)를 명시하고, **종결/취소/전환 결정이 그 실행 SSOT에 반영됐는지**를 코드가 강제·검증하게 한다.

### 2.2 계약 저장 위치 (레지스트리 스키마 무변경 제안)
- 신규 SSOT 파일 **`ssot/decision_contracts.json`** 한 곳(약속 L01: 단일 원천). `status/module_registry.json` 스키마는 **건드리지 않는다**(스키마 변경=웰리 승인 사안 회피). 등록부와는 `module_id`로 조인.
- 소비자(감지 하네스·회귀감시)는 이 파일만 읽는다.

### 2.3 계약 스키마 (모듈 1개당 1블록)
```jsonc
{
  "module_id": "cmo-case-series-dispatch",
  "class": "select-dispatch",          // select-dispatch | verbatim-render | state-honor
  "execution_ssot": {                  // 코드가 '무엇을 낼지' 읽는 유일한 원천
    "kind": "md",                      // md | json | prompt | sheet | queue
    "ref": "instagram/_실전사례_2주플랜.md"
  },
  "decision_events": ["종결","취소","전환","폐기"],  // 이 모듈이 반드시 존중할 결정
  "guard": {                           // 결정을 코드가 강제하는 장치(§3 패턴)
    "pattern": "K",                    // K=킬스위치/상태존중 · N=정규화/캐논렌더
    "impl_ref": "scripts/case_series_dispatch.py:_SERIES_TERMINATED_RE / _find_queued_item(폐기)",
    "marker": "시리즈\\s*상태\\s*[:：]\\s*(종결|중단|폐기)",  // 실행 SSOT 안에 박히는 기계판독 마커
    "effect": "휴면"                    // 휴면 | 제외 | 정규화
  },
  "replay_log": "status/decision_replay_log.jsonl",  // 가드가 재생을 막을 때 남기는 공용 신호(§4)
  "verify": "python scripts/case_series_dispatch.py --plan-only  # 종결 감지→휴면 확인",
  "rollback": "편성표의 '시리즈 상태: 종결' 줄 삭제(즉시 정상 복귀) · or 가드 커밋 revert",
  "status": "guarded"                  // guarded | proposed | unguarded
}
```

### 2.4 계약 불변식 (검증 대상)
1. **실행 SSOT는 정확히 1곳**(L01). 두 곳에서 읽으면 한쪽이 옛것으로 어긋난다.
2. **결정은 실행 SSOT 안에 기계판독 마커로 박힌다**(L02) — 결정이 ship·큐·대화 원문에만 남고 실행 SSOT엔 없으면 위반.
3. **가드는 마커를 읽고 존중한다** — 존중 못하면 옛것 재생.
4. **가드가 재생을 막으면 공용 로그에 1줄 남긴다**(surface 신호원).

## 3. 표준 패턴 템플릿 — 두 수리를 일반화

오늘 2건의 수리를 재사용 가능한 **2개 패턴**으로 승격. 신규 결정소멸형 모듈은 반드시 둘 중 하나를 장착.

### 3.1 패턴 K — 킬스위치·상태존중 마커 (select-dispatch·state-honor 클래스)
> 결정(종결/취소/전환)을 **실행 SSOT 자체에 기계판독 마커로 박고**, 자동화가 그 마커를 읽어 **휴면 또는 제외**한다.
- 일반화 원본: case_series 킬스위치(`시리즈 상태: 종결`) + 폐기 status를 '이미 처리된 편'으로 포함.
- 규격:
  - **마커 형식**: 실행 SSOT 상단 1줄, 정규식 판독(예: `시리즈 상태: 종결(YYYY-MM-DD)`).
  - **가드 위치**: 선정/발송 로직의 **최전단**(선정 전 즉시 검사 → 있으면 부작용 0으로 종료).
  - **항목 단위 취소**: 취소된 개별 항목의 상태값(`폐기`/`취소`)을 '재선정 후보 아님'으로 취급(재선정 원천차단).
  - **되살리기**: 마커 줄 삭제 = 즉시 정상 복귀(문서에 명시).
- 되묻지 않는다: 마커 유무는 결정론적 — 사람 개입 없이 코드가 강제.

### 3.2 패턴 N — 정규화·캐논렌더 규칙 (verbatim-render 클래스)
> 자동화가 원문(이름·호칭·상태·직함)을 렌더할 때, **정규화 규칙셋이 "나온 그대로"보다 우선**해 원문 토큰을 캐논값으로 매핑한다.
- 일반화 원본: ops_digest 정체 정규화(김남욱→GM·'대표님'→전응준 전용·차의주→회장님).
- 규격:
  - **정규화 규칙셋의 원천 = 캐논 SSOT**(`ssot/canon_values.json`). 프롬프트에 하드코딩 금지 → 캐논 직독/주입(L01·INC-005류 재발방지).
  - **우선순위 명시**: "원문 그대로" 류 규칙보다 **절대 우선·예외 없음**을 프롬프트에 명문화.
  - **적용 대상**: 인명·직함·업장용어(브랜드 금지어 포함: "피트니스"→"스포츠클럽" 등).
- 검증: 합성 입력(오호칭 혼재)으로 실제 LLM 호출 → 정규화 성공 + 정당 보존 둘 다 확인(08b95c30 방식).

## 4. 옛것 재생 감지 하네스 — self_health_watchdog §6 편입

### 4.1 편입 방식 (기존 하네스 확장 · 새 플러밍 0)
`scripts/self_health_watchdog.py`는 이미 read-only 애그리게이터(§1~§5). 여기에 **§6 🔁 결정 정합** 섹션 함수 하나를 추가한다 — 기존 조립·게이트·dedup·하트비트 경로를 그대로 재사용.

```
§6 🔁 결정 정합 — build_section_decision_consistency()
   소스: status/decision_replay_log.jsonl(가드가 남긴 '재생 차단' 신호) + ssot/decision_contracts.json
   노출(이상만):
     (a) 오늘 '옛것 재생 차단' N건 — 가드가 실제로 막은 재선정/재발송(정상 작동 증거이자 결정 미박제 흔적)
     (b) 미보증 모듈 M건 — 계약상 결정소멸형인데 guard.status=unguarded/proposed(로드맵 잔여)
   전부 정상(차단 0·미보증 0)이면 None → 무노출(침묵).
```

### 4.2 surface-only 철학 (stall 감지기와 동일)
- **자율 write/차단 = 기본 OFF.** §6은 **정보 표시만** 한다 — 실제 차단은 각 모듈의 패턴 K/N 가드가 이미 최전단에서 수행. 하네스는 그 신호를 **하루 1통 자동화현황방 디제스트**에 모을 뿐.
- 게이트: 기존 **`SELF_HEALTH_WATCHDOG_LIVE`**(기본 OFF)를 그대로 상속. 새 게이트 안 만든다(별도로 §6만 끄고 싶으면 `DECISION_GATE_SURFACE` 보조 플래그, 기본 ON이되 §6은 하네스 게이트에 종속).
- dedup: 하네스의 날짜 dedup(하루 최대 1통) 그대로.
- 자가증명: 기존 `record_heartbeat("cto-self-health-watchdog", ...)` 그대로.

### 4.3 신호원 = 가드 자기보고 (지어내지 않음)
- 각 패턴 K/N 가드는 **재생을 막는 그 순간** `status/decision_replay_log.jsonl`에 1줄 append(`{date, module_id, subject, action:"blocked", detail}`). 하네스는 그 로그만 읽는다(재점검·네트워크 호출 0 — §3 erp_status·§5 sheet_contract와 동일 read-only 패턴).
- 가드 미장착 모듈은 로그가 없다 → (b) '미보증'으로 계약 파일 기준 카운트만(surface heuristic, 판정 아님).

## 6. 게이트 · 롤백 · #267/INC-016 자동 봉합

- 하네스 §6: `SELF_HEALTH_WATCHDOG_LIVE` 기본 OFF 상속 — GM go 전엔 실발신 0(scan-only로만 확인).
