## 2. 탐지 강화 — v2 기준 (실측 역산 설계)

원칙: **규칙 = 후보 발굴(재현율), 두뇌(claude CLI via model_router — 기존 배선 재사용) = 최종 판정(정밀도).** 규칙이 확신할 필요 없다 — 후보를 넉넉히 물어오고 LLM이 병합/갱신/보류를 판정.

## 3. 카드 정보 위계 재설계 — "변화가 주인공, 무변화는 각주"

**v1 문제: 지표 대칭 나열(모든 줄 N→N).** v2 원칙: **① 고친 것(실명 스토리) → ② 배운 것(제안) → ③ 행동 필요(정체 배 목록) → ④ 무변화는 ✅ 1줄 압축.** `N→N` 강제 규칙은 유지하되 **변화 있는 줄에만 적용** — 변화 0 지표는 개별 줄 금지, ✅ 묶음 1줄로.

### 렌더 규칙 (스크립트 강제 — 박제)
1. 첫 줄 제목 + 둘째 줄 ⏱30초 요약 (변화 총량 한 문장) — 유지.
2. **🔧 이번 주 고친 것** 섹션이 최상단: 병합·갱신 실행 건을 **파일 실명 + "무엇이 낡았었나 → 뭘로 고쳤나"** 서술 (최대 3건, 각 2줄). 숫자보다 실명 앵커가 체감의 핵심.
3. **📡 배운 것 → 적용 제안**: 제안마다 `현재는/바뀌면` 대비 + 승인 커맨드 (v1 유지, 위치만 승격).
4. **🧭 행동 필요**: 정체 배는 **번호·이름 나열 + 처분 제안 1줄** ("상시업무는 모듈 전환·프로젝트 배는 재점화" 등). 숫자만 나열 금지.
5. **✅ 이상 없음** 1줄: 변화 0 지표 전부 묶음 (`인덱스 정합·중복 0·삭제 대기 0` 식).
6. 마지막 줄 = 기록 위치 + 스냅샷 zip 경로 (가역 증빙 — GM 안심 장치).
7. 변화 완전 0인 주 = 3줄 카드 (v1 유지).
