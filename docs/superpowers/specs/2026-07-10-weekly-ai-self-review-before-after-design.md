### 2-1. 파트 A — 메모리·컨텍스트 정리 (신규 핵심 기능)

**대상:** `C:\Users\jjky0\.claude\projects\C--Users-jjky0-welperion-automation\memory\` (.md 220개 + MEMORY.md 인덱스)

**절차 (weekly_self_review.py 내):**
1. **스냅샷(가역화 장치):** 정리 전 폴더 전체를 `status/_memory_snapshots/YYYY-MM-DD.zip` 백업, 4주 보관 후 자동 삭제. → 이 장치로 병합·갱신·아카이브가 전부 **가역**이 됨 (배237: 가역=자율).
2. **스캔·탐지 (두뇌=claude CLI via `model_router.run_claude` — proposer와 동일 정본 경로):**
   - **중복:** 같은 주제 파일 다수 (파일명 클러스터 + 본문 유사) → 병합 후보

   - **낡음:** 90일+ 미수정 AND MEMORY.md 인덱스 미참조 → 갱신 또는 삭제 후보
   - **인덱스 정합:** MEMORY.md에 없는 고아 파일 / 파일 없는 죽은 링크
3. **적용 (자율/게이트 분리):**
   - 자율(스냅샷 전제 가역): **병합**(N→1, 내용 보존) · **갱신**(낡은 값→현행) · **인덱스 정리**
   - 게이트(비가역): **완전 삭제** → 카드에 "삭제 대기 N건" + 승인 회신 안내. 승인 전 파일 유지.
4. **수치 기록:** 전/후 카운트를 `status/self_review_log.jsonl`에 append (주차별 추세 = 다음 주 카드의 Before 소스).

**Before/After 수치 정의 (카드에 그대로 노출):**
`파일 수 · 총 KB · 중복쌍 · 모순 건 · 90일+ 낡음 건 · 인덱스 불일치 건` — 6개 전부 전/후 대비.

### 2-2. 파트 B — AI 트렌드 학습 → "우리 적용" (기존 개선)

- 수집·요약·제안 생성 = **기존 3종 그대로 재사용** (learner 7소스 → proposer 카드).
- **개선 1 — 제안 JSON 스키마에 대비 2필드 추가** (`ai_learning_proposer.py` 프롬프트 수정):
  - `"현재는"`: 지금 우리 시스템이 이 일을 어떻게 하는지 (Before)
  - `"바뀌면"`: 반영하면 무엇이 어떻게 달라지는지, 가능하면 수치 (After)
  - → 카드가 추상 요약이 아니라 "지금 이렇게 함 → 이렇게 바뀜" 대비로 렌더 가능.
- **개선 2 — 정체 해소:** 카드 하단에 승인 대기 건을 번호로 나열 + 승인 커맨드 명시. (Phase 3: `bot.py`에 `/승인 <id>` 회신 핸들러 — 텔레그램 탭 한 번으로 승인. 기존 GM 승인 회신 전용 채널의 자연 확장.)
- 개별 텔레그램 발송 2건(learner 헤드라인 덤프 · proposer 1줄)은 OFF — 내용은 통합 카드에 흡수. (구현: 각 스크립트에 `--no-send` 플래그 또는 예약작업 인자로 발송 생략 — 스크립트 기능 자체는 보존.)
