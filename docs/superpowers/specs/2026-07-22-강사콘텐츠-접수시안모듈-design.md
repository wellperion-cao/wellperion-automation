# 강사 콘텐츠 접수·시안 모듈 (M1) — 설계 스펙

- 작성: 시모(AI CMO) · 2026-07-22 · GM 방향 확정
- 상태: 설계 승인 완료 → 본 스펙 GM 검토 대기 → 구현 계획(writing-plans) → 제작(P1부터)
- 관련: ship1197(각 강사 마케팅 지원) · ship747(CMO 자율화 두뇌) · [[project_ai_daily_series_official_design]] · M1(콘텐츠 제작 프로세스)

## 1. 목적·배경
공식계정(@wellperion) 마케팅을 "강사(사람) 소개 콘텐츠"로 한동안 전개한다. 종목 안내를 넘어 실제 수업을 이끄는 강사의 전문성·따뜻함을 보여 **강사·클럽 신뢰(브랜딩)**를 쌓는 게 목표. 이런 캠페인의 최대 실패 원인은 **강사 자산(사진·영상) 수집 지연**이므로, 일회성이 아니라 **상시 접수 폼 + 반자동 시안 제작 모듈**로 만들어 수집→제작→발행을 파이프라인화한다("계속 해도 될듯" = 마감 없는 롤링 접수).

## 2. 목표·성공기준
- 강사가 M1 페이지 폼으로 **직접** 사진·영상·소개 텍스트를 제출할 수 있다.
- 접수분으로 **반자동 시안**(사진 캐러셀·사진 릴스 자동 / 제출 영상 반자동)이 만들어져 검수큐에 오른다.
- GM이 검수카드 [승인]만 누르면 발행되는 기존 파이프라인에 그대로 얹힌다.
- 성공지표: (초기) 접수 강사 수·시안 발행 수 / (중기) 강사 콘텐츠 저장·댓글 반응, 강사 언급 문의.

## 3. 범위 (단계)
- **P1 — 접수 폼 + 저장 + 알림 (MVP).** 완료 즉시 부서장 카톡방 공지 발송·수집 시작 가능.
- **P2 — 반자동 시안 생성 배선.** 접수분 → 사진 캐러셀·릴스 자동 시안 → 검수큐 등록.
- **P3 — M1 접수 현황 패널.** 강사별 상태(접수/시안/검수/발행) 한눈에.
- **비범위(YAGNI):** 제출 영상의 완전 자동 편집(자막·컷)은 초기 제외(반자동=시모 간단 손질 or 캡컷 수동). 완전 자동은 신뢰 후 확장.

## 4. 아키텍처·컴포넌트

### 4-1. 접수 폼 (P1)
- 위치: M1 페이지(`3. 웰페리온 가이드` CMO M1) 내 신설 섹션 "강사 콘텐츠 접수".
- 입력 필드: 강사 이름 · 팀(종목 select) · 사진 3~5장(이미지 업로드) · 영상 15~30초(선택, 파일) · 한 줄 소개 · "제 수업에서 회원이 얻는 것" 한 문장 · (동의 체크: 공식계정 게시 동의).
- 저장: 기존 GAS 폼/드라이브 표준 재사용(우리 표준 — Survey.js/GAS `doPost` → 파일 base64 → `DriveApp` 강사별 폴더 저장, 메타는 `강사접수` 시트 + JSON 미러). 파일 업로드 용량·형식 검증.
- 제출 후: 확인 메시지 + **텔레그램 알림**(업무보고방/문의알림방에 "새 강사 접수: {이름}/{팀}") — 기존 알림 배선 재사용.
- 보안·동의: 강사 사진·이름은 공개 콘텐츠 전제(제출=게시 동의). PII 게이트 대상 아님(마케팅 공개물). 단 미승인 상태에선 발행 안 됨(검수 게이트).

### 4-2. 반자동 시안 모듈 (P2)
- 접수 감지: 신규 시트 행/JSON 폴러(기존 폴러 패턴 재사용).
- 사진 → **강사 소개 캐러셀**: `compose_html` **강사 소개 템플릿 신설**(공식 디자인 = 베이지·W풀로고·볼드 헤드라인·회색 본문·풋터). 강사 사진은 브랜드 규칙대로 듀오톤(`compose_barre.to_duotone`) 처리해 배치. 제출 텍스트(한 줄 소개·"회원이 얻는 것")로 카피 자동 조립.
- 사진 → **릴스**: `make_reel.py`(사진 세트→Ken Burns+자막+음악, 베이지 톤) 자동 1개.
- 제출 영상 → 초기 반자동: 그대로 첨부 또는 시모 간단 손질(자막/트리밍) 후 첨부. (자동 편집은 비범위)
- 등록: `review_queue.json`에 **강사별 검수대기** 등록. id 규칙 `CMO-INSTR-{팀}-{이름}-{YYYYMMDD}`, `account: "wellperion"`, `channel: "인스타그램 (wellperion 공식)"`, slides=생성 캐러셀, (릴스는 별도 항목 or 첨부). → 기존 검수카드 → GM 승인 → 발행엔진.
- ※ 공식 IG 카드는 오늘 배선한 형제 채널 자동 그룹핑(멀티채널 발행)이 적용 가능 — 초기엔 IG 단독으로 시작, 필요 시 형제 등록.

### 4-3. M1 접수 현황 패널 (P3)
- M1 페이지에 강사별 카드: 접수일 · 상태(접수/시안생성/검수대기/발행완료) · 발행 링크. `강사접수` 시트/review_queue 조인.

### 4-4. 공지 (P1 완료 후)
- 폼 링크 포함 공지문을 **부서장 카톡방**에 발송 — 시모가 T2 카톡전송기로(GM 결재 후). 초안 = 본 세션 작성분(강사 직접 제출·마감 없음·롤링).

## 5. 데이터 흐름
강사 → M1 폼 제출 → GAS(Drive 파일+시트 메타) → 텔레그램 접수 알림 → (P2) 폴러 감지 → 시안 생성(compose_html/make_reel) → review_queue 검수대기 → 검수카드(텔레그램) → GM 승인 → 발행엔진 → 공식계정 발행 → (기존) 발행 다이제스트.

## 6. 재사용 / 신규
- **재사용:** `compose_html`(캐러셀)·`make_reel`(릴스)·`compose_barre.to_duotone`(사진)·`review_queue`+검수카드+`ig_review_publish_watcher`(발행)·GAS 폼/Drive·텔레그램 알림.
- **신규:** ① M1 접수 폼(GAS doPost + Drive 저장 + 시트) ② `compose_html` 강사 소개 템플릿 ③ 접수→시안 폴러 배선 ④ M1 현황 패널.

## 7. 에러·엣지
- 파일 용량 초과/형식 오류 → 폼 단계 검증·안내.
- 사진 수 부족(<3) → 제출 허용하되 시안 품질 경고, 반자동에서 시모 보완.
- 제출 영상 없음 → 사진 캐러셀·릴스만 생성.
- Drive 권한·용량 → 강사별 폴더·정리 정책.
- 중복 제출(같은 강사 재제출) → 최신 우선, 기존 시안 폐기 판단은 시모.

## 8. 테스트 관점
- 폼 제출→Drive 저장→시트 기록→알림 e2e(P1).
- 시안 생성: 샘플 접수 1건으로 캐러셀·릴스 생성·검수큐 등록 확인(P2, 픽스처).
- 발행 파이프라인은 기존 검증분 재사용.

## 9. 미결·가정
- 강사 소개 캐러셀 템플릿의 정확한 레이아웃(사진 배치·텍스트 위치)은 구현 시 L시리즈 톤 기준 1차안 → GM 시각 검수로 확정.
- 폼 파일 업로드의 GAS 용량 한계(대용량 영상) → 초기 영상 크기 상한(예 50MB) 두고, 초과 시 드라이브 직접 업로드 링크 대안.
- 부서장 카톡방 정확한 방 식별자·T2 발송 경로는 발송 직전 확인.
