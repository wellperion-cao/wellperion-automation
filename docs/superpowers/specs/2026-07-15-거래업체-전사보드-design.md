# 거래업체 전사 보드 (부서별 필터·복수 소속) — 설계

- 날짜: 2026-07-15
- 소유: 시우(COO) · GM 승인 완료(대화)
- 배: G1 신규 COO 배

## 1. 목적 (GM)
거래업체를 전사 일정처럼 한 곳에 모으고, **부서별로 자기 업체만** 보게. 한 업체가 **여러 부서 소속 가능**(복수 지정).

## 2. 현황
- 거래업체 = `시설_거래업체` 시트 1개. GAS = `.deploy-check/지원팀 일일점검.js`(CHECK_API_URL `AKfycbyXw4Za…`), action `vendor_list`/`vendor_save`(전체 교체).
- VENDOR_HEADERS = `id|분류|colKey|업체명|담당자|연락처|계약형태|단가|갱신일|거래상태|비고|생성일|수정일`. **부서 칸 없음.**
- 시설부 체계.html에 **풍부한 거래업체 UI**(#tab-vendor: 칸반/목록·분류관리·＋업체등록, JS vendorSetView/vendorOpenAddForm/vendorSave 등). 다른 부서엔 없음.

## 3. 확정 (GM 결정)
- UI = **기존 시설부 UI 재활용**(추출).
- 필드 = **전 필드 전 부서 공유**(단가·계약형태 포함).
- 부서 = **복수 소속**(depts, 다대다). `?dept=X` 보드 = X가 depts에 포함된 업체만.

## 4. 데이터 확장 (GAS)
- VENDOR_HEADERS에 **`부서`** 칸 1개 추가(기존 인덱스 뒤·비파괴). 값 = 복수 부서를 구분자(예: `,`)로 저장하거나 JSON 문자열.
- `vendorList()` 반환에 `depts:[...]`(파싱) 추가. `vendorSave()`가 `depts` 저장.
- 기존 행 마이그레이션: 부서 빈값 → `시설부` 기본(1회 or 프론트 폴백).
- 배포 = clasp push + `AKfycbyX…` 배포 ID 재배포(GM go, 방금 일정과 동일 절차). ★스키마 비파괴(칸 추가만).

## 5. `전사_거래업체.html` (신규 공유 보드)
- 시설부 #tab-vendor UI(칸반/목록·분류그룹·분류관리·등록/편집)를 standalone 페이지로 추출.
- `?dept=X&embed=1`: dept 필터(X∈depts) + 군더더기 숨김(전사_일정 embed 패턴 동일). fitFrame 자체높이(이중 스크롤 0). 전폭 좌측정렬.
- **편집 폼에 부서 복수 체크박스**(시설부·운영부·지원부·주차관리부·파트너팀). 신규 등록 시 현재 dept 기본 체크.
- 저장 = vendor_save(depts 포함). 인라인/폼 편집(일정 인라인 UX 참고, 단 기존 칸반 등록폼 유지 가능).
- dept='전체'(비임베드) = 전 업체 + 부서 칩 필터.

## 6. 부서 체계 페이지 5종 — `🏢 거래업체` 탭
- 시설부·운영부·주차관리부·지원부·파트너팀 각각: 탭 버튼 + `<div id="tab-vendorboard">` + iframe(`전사_거래업체.html?dept={부서}&embed=1`, lazy) + switchTab 배선 + `#tab-vendorboard` 전폭 CSS. (일정 탭과 동일 기계작업)
- **시설부 기존 #tab-vendor = 공유 보드 임베드로 교체**(중복 제거). 기존 rich UI는 전사_거래업체.html로 이관됐으므로 시설부는 임베드만.

## 7. 순서
- Phase A: GAS depts 칸 + 배포. 전사_거래업체.html 추출·dept필터·embed·복수부서 편집. **시설부 시범 탭**. 라이브 검증(시크릿).
- Phase B: 나머지 4부서 탭 확산(executor). 라이브 검증 → GM 1줄 보고.

## 8. 안전
- GAS = 비파괴 칸 추가(기존 데이터 보존). 배포=GM go(clasp).
- 페이지 추출/임베드=가역. 커밋·푸시 즉시, 라이브 검증 후 완료(L03).
- 시설부 기존 UI 교체 전 데이터(vendor_list) 무손실 확인.

## 9. 비목표 (YAGNI)
- 부서별 접근권한 차등(전 필드 공유 결정). 거래업체↔일정 vendor_id 연동 재설계(기존 유지). 계약 만료 알림(추후).
