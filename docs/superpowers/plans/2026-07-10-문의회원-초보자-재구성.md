# 문의회원 페이지 초보자 재구성 — 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 신규 상담사(초보자)가 문의회원 페이지에서 "지금 처리할 것"을 한눈에 잡고, 흩어진 가이드를 상단 팝업 하나로 여닫도록 IA를 재구성한다.

**Architecture:** 단일 파일 `문의회원.html`(약 6569줄)의 프론트 IA만 손댄다. 본문 탭·GAS 백엔드·라이브 데이터 로직은 불변. 변경은 (1) 헤더 툴바 3구역 그룹핑 (2) 초보자 안내 배너 신설 (3) 오늘 현황 요약 히어로(기존 `cpoTodayStrip` 리스타일) (4) 가이드·교육 허브 팝업(기존 opener 재사용 런처) — 4가지. 강습은 공유 헤더/공유 배너를 통해 동일 틀로 자동 적용되며, 데이터 없는 칸만 정직하게 비운다.

**Tech Stack:** 순수 HTML/CSS/JS(빌드 없음). 기존 CSS 변수(`--accent --border --bg --text --dim --red --red-bg --red-border --teal --accent-bg`)와 기존 모달 패턴(`.gdoc-overlay.open` / `openGdoc()` / ESC 닫기 2552행)을 재사용.

## Global Constraints

- 대상 파일: `3. 웰페리온 가이드/cpo/member/문의회원.html` (단일 파일).
- 모든 표시 숫자 = **라이브 바인딩**. 목업/예시/하드코딩 수치 금지.
- 본문 탭(달력·문의DB·등록·활성회원)·강습 서브탭·기존 모달(멤버십현황·강습현황·문의이후·오늘할일·이탈관리)·자동보고 상태줄(`#cpoReportStatusLine`)·인쇄 = **기능·데이터 회귀 0**.
- 검증 = **시크릿(incognito) 크롬 라이브 실측**. 멤버십·강습 양쪽 각각. 콘솔 에러 0.
- 커밋 = task 단위 원자 커밋. 파괴적 git 금지. 동시 watcher 경합 대비(내용 무결성 우선).
- 강습에 없는 데이터(출석·만료 기반 이탈·오늘할일)는 **억지 숫자 금지 → 정직 공백 표기**.
- 정적 콘텐츠는 **이전(move)이 아니라 재노출(reuse)** 우선 — `#gdoc-tpl` 템플릿·`#pane-guide`는 그대로 두고 허브가 기존 opener를 호출한다(인덱스 고정참조·호출부 깨짐 방지).
- 역롤백: 각 task 커밋을 되돌리면 해당 변경만 원복되도록 파일 영역 분리.

/* ── 가이드 & 교육 허브 (배754, 2026-07-10) — family별 카드 세트를 그려 기존 opener를 호출하는 런처 ── */
function openGuideHub() {
  var lesson = (typeof _curFamily !== 'undefined' && _curFamily === 'lesson');
  var cards = [
    { ic: '📖', t: (lesson ? '강습 문의 처리 SOP' : '문의 처리 SOP'), d: '문의 접수 → 예약 → 등록 전환 절차·담당 R/R', fn: 'openGuidePopup()' },
    { ic: '📋', t: '운영 원칙 · 정기 루틴', d: 'CPO 운영원칙·일/주/월 정기 루틴(정직 배지)', fn: "openGdoc('principle,routine')" },
    { ic: '🎓', t: '스포츠클럽 영업 · 회원관리 교육', d: '영업 스크립트·회원관리 노하우 — 자리 준비, 이후 채움', fn: "openGdoc('salesedu')", slot: true }
  ];
  if (!lesson) {
    cards.splice(2, 0, { ic: '🚪', t: '이탈 사유 분류 (교육용)', d: 'LOSS 신호 분류·대응 매트릭스(읽는 교육) — 라이브 이탈 현황은 📊현황', fn: "openGdoc('churnsummary,churn')" });
  } else {
    cards.push({ ic: '🚧', t: '강습 이탈관리', d: '출석·만료 데이터 없어 정의 보류 — 데이터 파이프(≈9월) 후 편입', fn: '', slot: true });
  }
  var grid = document.getElementById('guideHubGrid');
  grid.innerHTML = cards.map(function(c){
    var clickable = c.fn ? (' onclick="' + c.fn + '"') : '';
    return '<button class="hubx-card' + (c.slot ? ' hc-slot' : '') + '"' + clickable + (c.fn ? '' : ' disabled style="cursor:default;opacity:.6"') + '>' +
      '<span class="hc-ic">' + c.ic + '</span><span><h4>' + c.t + '</h4><p>' + c.d + '</p></span></button>';
  }).join('');
  document.getElementById('guideHubOverlay').classList.add('open');
}
function closeGuideHub() {
  document.getElementById('guideHubOverlay').classList.remove('open');
}
