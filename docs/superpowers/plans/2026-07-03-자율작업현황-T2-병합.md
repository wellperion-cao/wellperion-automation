### Task 2: 히어로 — 결과물 중심 요약 (results-first)

**Files:**
- Modify: `3. 웰페리온 가이드/자율현황.html` (`#hero-autonomy` + `<script>`)

**Interfaces:**
- Consumes: 기존 로드된 로그(`gm_aide_scan_log.jsonl`·`northstar_log.jsonl`·`learning_proposals.json`).
- Produces: `renderHero()` — 오늘 날짜 기준 집계 1줄.

- [ ] **Step 1: renderHero 집계 로직**
오늘(KST) 기준: 자율 처리 건수(포착 중 실제 처리/자율실행), 포착 건수(gm_aide_scan today), 학습 반영 건수(learning_proposals status='반영'). 측정 불가 항목은 문자열 `"미측정"`.
```js
function renderHero(logs){
  const today = kstDate();
  const captured = logs.aide.filter(r=>r.date===today).length;
  const learned = logs.learn.filter(p=>p.status==='반영').length;
  const handled = logs.aide.filter(r=>r.date===today && r.auto_applied>0).length; // 실제 자율처리
  el('#hero-autonomy').innerHTML =
    `🤖 <b>자율이 오늘 한 일</b> — 자율 처리 <b>${handled}</b>건 · 포착 <b>${captured}</b>건 · 학습 반영 <b>${learned}</b>건`;
}
```

- [ ] **Step 2: 로드 파이프라인에 renderHero 연결**
기존 `Promise.all([...logs]).then(...)` 렌더 체인에 `renderHero(logs)` 추가.

- [ ] **Step 3: 라이브 렌더 검증(시크릿 크롬)**
Run: `--incognito`로 라이브 URL 열어 히어로 1줄 노출·숫자 정합(이력 건수와 대조) 확인.
