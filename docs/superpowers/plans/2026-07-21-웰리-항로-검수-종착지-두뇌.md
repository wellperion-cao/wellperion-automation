## Goal

큐(`status/_queue.json`)의 모든 배를 순회해 **① 상태 정직성을 검수(read-only)** 하고 **② 종착지(다음 한 수 + 최종 북극성)를 LLM 두뇌로 생성**하며 **③ 배별 카드를 간격 제어로 GM께 텔레그램 핑**한다. GM 승인 시에만 **④ 기존 `clevel_post_action --next` 배관**으로 항로에 반영한다. 흩어진 3조각(북극성 추천·표류 감지·next 촉구)의 **두뇌·신호를 라이브러리로 재사용**(net-zero)하고, 새 코드는 **신규 파일 위주**로 작성해 시토의 `gm_aide_scan.py` 병합(배9420)과 충돌을 최소화한다.

## Architecture

```

  │     └─ 재사용: stall_watch.detect_stalled / stall_threshold (stale)

  ├─ generate_destination(ship, run_claude, ...)   # ② 생성 (LLM 두뇌)
```

1. **Windows·경로:** python = `C:\Python314\python.exe`. `.bat`·`.vbs`는 **영문(ASCII)만** (CP949 안전).
2. **재사용(net-zero):** 위 기존 함수를 **import/호출로만** 재사용 — 로직 복제 금지.

4. **검수 read-only:** `audit_ships`는 상태를 **바꾸지 않고 판정만**. 자동 상태변경 금지.
5. **반영 배관 단일화:** `_queue.json` next 반영은 **GM 승인 시에만** 기존 `clevel_post_action --next` 배관 경유 + `queue_lock` 직렬화(동시커밋·임시인덱스 손상 메모리 준수).

7. **텔레그램 간격 제어:** 배별 즉시 = 다음 폴 틱 안에서 간격 큐잉. 다발 발송(429) 금지.
8. **거짓 종착지 금지:** LLM `confidence < CONFIDENCE_THRESHOLD(0.6)` → **"저확신 제안"** 라벨. 지어내기 금지.
9. **★시토 충돌 경계(필수):** 시토가 `gm_aide_scan.py` 자율화 병합(배9420)을 IN_PROGRESS 진행 중. 본 모듈은 `gm_aide_scan.py`를 **재작성하지 않는다** — `scan_drift` 등 신호는 **import/read만**. `gm_aide` next_augment placeholder 제거는 **Phase 2로 명시하되 '시토 조율 후' 게이트**(이 계획 핵심 태스크에서 실행 금지).
10. **한국어 주석/문구**(레포 관례) · **정직성**(저확신·미상은 그대로 표기).

**목표:** stable key = `ship_no + 문맥해시`. GM 결정 배 재핑 차단, 문맥 변하면 새 key로 재제안 허용.

**③ 최소 구현:**
```python
def ledger_key(ship: dict) -> str:
    ctx = "|".join(str(ship.get(k, "")) for k in ("title", "note", "next", "status"))
    h = hashlib.sha1(ctx.encode("utf-8")).hexdigest()[:10]
    return f"{ship.get('ship_no')}|{h}"

def load_decisions(path: Path) -> dict:
    out = {}
    if not Path(path).exists():
        return out
    for line in Path(path).read_text(encoding="utf-8").splitlines():
        line = line.strip()
        if not line:
            continue
        try:
            rec = json.loads(line)
            out[rec["key"]] = rec
        except (json.JSONDecodeError, KeyError):
            continue
    return out

def already_decided(key: str, decisions: dict) -> bool:
    return key in decisions

def record_decision(path: Path, ship: dict, decision: str) -> str:
    key = ledger_key(ship)
    rec = {"key": key, "ship_no": ship.get("ship_no"),
           "decision": decision, "decided_at": datetime.now().strftime("%Y-%m-%d %H:%M:%S")}
    with open(path, "a", encoding="utf-8") as f:
        f.write(json.dumps(rec, ensure_ascii=False) + "\n")
    return key
```

```python
        if already_decided(ledger_key(ship), decisions):
            continue                    # 이미 GM 결정 = 재핑/재생성 안 함
        cards.append(generate_destination(ship))
    pending = {"generated_at": datetime.now().strftime("%Y-%m-%d %H:%M:%S"),
               "findings": findings, "cards": cards, "card_count": len(cards)}
    PENDING_FILE.write_text(json.dumps(pending, ensure_ascii=False, indent=2), encoding="utf-8")
    if send:
        token = _telegram_send_fn()          # northstar send 패턴 재사용(_env_val)
        ping_gm(cards, decisions=decisions, ship_by_no=by_no, send_fn=token)
    else:
        print(f"[드라이런] 카드 {len(cards)}건 → {PENDING_FILE} (텔레그램·큐쓰기 없음)")
    return pending

def _telegram_send_fn():
    """카드 1장 텔레그램 발송 클로저 — northstar_recommender._env_val 재사용(토큰 .env 직독)."""
    sys.path.insert(0, str(ROOT / "scripts"))
    import urllib.parse, urllib.request
    from northstar_recommender import _env_val
    tok, chat = _env_val("TELEGRAM_BOT_TOKEN"), _env_val("TELEGRAM_CHAT_ID")
    def _send(card):
        if not tok or not chat:
            print("[WARN] 텔레그램 미설정 — 발송 생략")
            return
        text = (f"🧭 <b>웰리 항로 검수 — 종착지 제안</b>\n"
                f"배 #{card.get('ship_no')} · {card.get('title','')}\n"
                f"{'⚠️ 저확신 제안' if card.get('low_confidence') else '추천'}: "
                f"{card.get('next_step','')}\n{card.get('path_map','')}")
        data = urllib.parse.urlencode({"chat_id": chat, "text": text, "parse_mode": "HTML",
                                       "disable_web_page_preview": "true"}).encode("utf-8")
        try:
            urllib.request.urlopen(urllib.request.Request(
                f"https://api.telegram.org/bot{tok}/sendMessage", data=data, method="POST"), timeout=15)
        except Exception:
            print("[WARN] 카드 발송 실패(토큰 trace 미노출)")
    return _send

def main():
    ap = argparse.ArgumentParser(description="웰리 항로 검수·종착지 두뇌")
    ap.add_argument("--dry-run", action="store_true", help="드라이런(기본) — 카드 pending 기록만")
    ap.add_argument("--send", action="store_true", help="텔레그램 카드 발송(간격 제어)")
    ap.add_argument("--audit-only", action="store_true", help="검수 판정만 출력(read-only)")
    a = ap.parse_args()
    run(send=a.send, audit_only=a.audit_only)

if __name__ == "__main__":
    main()
```
