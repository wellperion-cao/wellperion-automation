# 부서별 현황판 설계안
> COO(시우) 작성 · 2026-06-08 · GM 확정 대기

---

## 0. 배경 및 목적

GM 희망: "운영 통합 체계에도 **업무&결재 현황 SSOT처럼 현황판**이 있으면 좋겠다. 시설부 현황·지원부 현황 이렇게 각각 필요."

현재 운영 통합 체계(`coo/check/`)에는 **입력(점검 체크리스트) 앱**만 있고, 관리자가 날짜·부서별 집계를 한눈에 볼 수 있는 **독립 현황판**이 없다.
이 제안서는 현황판 신설을 위한 설계안이며, GM 확정 전까지 실제 구축은 진행하지 않는다.

## 1. 기존 패턴 실측

### 1-1. 라이브 렌더 방식 (업무·결재 현황 SSOT 기준)

| 항목 | 내용 |
|---|---|
| 데이터 소스 | GAS 웹앱 단일 엔드포인트 (`TODO_API_URL`) |
| 호출 방식 | `fetch(GAS_URL + '?action=todo_list', {redirect:'follow'})` — GET |
| 응답 봉투 | `{ok, count, data}` — `data` 배열에 업무 객체 |
| 캐시 방지 | `window.__PV` + `?pv` 파라미터로 CDN 강제 갱신 |
| 렌더 | 순수 JS DOM 조작 (`innerHTML`) — 별도 프레임워크 없음 |
| 필터 | 담당자 칩·상태·카테고리 필터 바 + 캘린더/칸반 뷰 토글 |

| 항목 | 내용 |
|---|---|
| GAS 엔드포인트 | `https://script.google.com/macros/s/AKfycbzcOTihPYfTWQ64rbNMpfgv9p2keav0mcf7x0LrPhHm8nOUIlsqPTwCOumzE-JIcv1F/exec` |
| 구글 시트 | `1DKEKRrpsi9Nit7dNdNGsXLYtzie3PopbwD7EJzJCku0` |
| 부서 격리 | `DEPT='facility'` / `DEPT='support'` 쿼리 파라미터로 시트 탭 라우팅 분리 |

### 1-3. 현재 운영 통합 체계 페이지(메인 가이드 O1 섹션) 링크 구조

메인 가이드 `data-id="O1"` 섹션에 현재 연결된 버튼:
- 🏭 시설부 체계 (`coo/check/시설부 체계.html`) ↗
- ✅ 지원부 체계 (`coo/check/지원부 체계.html`) ↗
- 🏟️ 강습팀 가이드라인 ↗
- (운영 통합체계 내부 링크)

업무·결재 현황 SSOT는 O1과 별도 섹션(O2)에 독립 버튼으로 연결돼 있음.

## 2. 설계안 — 시설부 현황판

### 2-1. 목적
이정헌 소장 관할 시설 점검 상태를 GM이 날짜·구역별로 한눈에 확인.
입력(체크리스트)과 분리된 **읽기 전용 집계판**.

### 2-2. 표시 항목

| 섹션 | 표시 내용 | 데이터 출처 |
|---|---|---|
| 오늘 요약 | 총 점검항목 수 / 완료 / 미완료 / 완료율(%) | 기존 GAS `?date=오늘&dept=facility` |
| 교대별 현황 | 오전·오후·야간조 완료율 + 제출자명 + 제출 여부 | 동일 |
| 이슈 목록 | 당일 보고된 이슈 전체(점검자·구역·내용) | 동일 |
| 날짜 이력 | 날짜 선택기 → 과거 날짜 집계 조회 | 동일 (date 파라미터 교체) |
| 주간 트렌드 | 최근 7일 완료율 추이 바 차트 | GAS 신규 action 필요 (`action=weekly&dept=facility`) — **신규 GAS 함수 필요 (GM 결재 포인트)** |
| 미결 유지보수 | 이슈 등록 후 미처리 건 누적 목록 | **신규 시트 탭 필요** (`시설_이슈대장`) — **GM 결재 포인트** |
| 소장 결재 대기 | 시설 관련 결재 현황 SSOT에서 `[4] 시설·환경` 카테고리 필터 | 기존 결재현황 GAS (`TODO_API_URL?action=todo_list&category=시설환경`) |

### 2-3. 데이터 출처 정리

```
기존 재사용 가능:
- GAS 엔드포인트: 체크리스트 GAS (AKfycbzcO...)
  - ?date=YYYY-MM-DD&dept=facility → 당일 집계 (이미 동작)
  - action=board&key=FACILITY_* → 보드/정책 데이터
- 결재현황 GAS (TODO_API_URL) → 카테고리 필터로 시설 결재건 추출

신규 필요 (GM 결재 후 개발):
- GAS 신규 action: action=weekly&dept=facility → 최근 7일 집계 배열
- 구글 시트 신규 탭: 시설_이슈대장 (이슈 등록~처리 이력 누적)
```

### 2-4. 배치 위치 (안)

**안 A — 기존 시설부 체계 HTML 내 탭 추가**
- 장점: URL 1개 유지, 기존 GAS 연결 재사용 즉시 가능
- 단점: 점검 입력 앱과 현황판이 같은 파일 → 크기 증가

**안 B — 독립 HTML 신설** (`coo/check/시설부 현황판.html`)
- 장점: 업무·결재 현황 SSOT처럼 독립 페이지로 GM이 즐겨찾기 가능, 메인 가이드 O1에 버튼 추가
- 단점: 파일 추가 + 메인가이드 O1 섹션 버튼 짝 추가 필요 (feedback_dept_system_link_parity 준수)

**COO 권장: 안 B** — 독립 현황판이 업무·결재 SSOT 패턴과 일치하고 GM 접근성 우수.

메인 가이드 O1 섹션에 버튼 짝 추가 필수.

## 4. 운영부 현황판 — 추가 필요 여부 의견

현재 운영부(이경연 실장 · 리셉션)는 별도 체크리스트 앱 없음.
업무·결재 현황 SSOT에서 `[1] 매출·영업 / [3] 운영 정책` 카테고리로 간접 관리 중.

**COO 의견**: 운영부는 현황판보다 **업무현황 SSOT + 결재현황 필터**로 충분히 커버 가능.
별도 현황판은 이번 스코프에서 제외하고, 시설·지원 2개 먼저 구축 후 필요 시 추가.

## 5. 공통 패턴 — 라이브 렌더 방식

```
렌더 방식:
1. 페이지 로드 시 오늘 날짜로 자동 조회 (fetch → GAS → 집계 JSON)
2. 날짜 선택기로 과거 날짜 조회 가능
3. window.__PV 캐시 방지 패턴 적용 (기존 체계 동일)
4. Pretendard 폰트 / 다크 CSS 변수 동일 적용 (--bg:#1a1815 계열)
5. 모바일 최적화 (max-width 전체 / overflow-x:auto 테이블)

데이터 흐름:
fetch(GAS_URL + '?date=' + d + '&dept=' + DEPT)
→ {total, done, pct, shiftStats, submitterStats, allIssues}
→ DOM 렌더 (innerHTML)

부서 격리: dept 파라미터 — 기존 GAS가 이미 지원 (facility/support 분기)
```

## 7. GM 결재 포인트 정리

| 번호 | 항목 | 결재 필요 이유 |
|---|---|---|
| A | 독립 HTML 2개 신설 (`시설부 현황판.html` · `지원부 현황판.html`) | 파일 신설 |
| B | GAS 신규 action 추가 (`action=weekly`) | 기존 GAS 스크립트 수정 + 재배포 필요 |
| C | 구글 시트 신규 탭 (`시설_이슈대장` · `지원_이슈대장`) | 시트 구조 변경 |
| D | 메인 가이드 O1 섹션·홈 카드 버튼 추가 | 가이드 HTML 수정 |

B·C는 주간 트렌드·이슈대장 기능 원하실 경우에만 필요. **MVP는 B·C 없이도 가능** (날짜별 당일 집계만 표시 — 기존 GAS 즉시 재사용).

## 8. 구축 단계 로드맵

### MVP (B·C 없이 즉시 구축 가능 — 기존 GAS 재사용)

| 단계 | 내용 | 예상 작업량 |
|---|---|---|
| 1 | `시설부 현황판.html` 신설 — 오늘 요약·교대별·이슈·날짜이력 | 소 (기존 대시보드 탭 로직 분리·독립화) |
| 2 | `지원부 현황판.html` 신설 — 동일 구조 dept=support | 소 (시설부 복제 + DEPT 교체) |
| 3 | 메인 가이드 O1·홈 카드 버튼 짝 추가 | 소 |

### 고도화 (GM 결재 B·C 후)

| 단계 | 내용 |
|---|---|
| 4 | GAS action=weekly 추가 → 주간 트렌드 바 차트 |
| 5 | 시트 이슈대장 탭 신설 → 미결 이슈 누적·처리 이력 |
| 6 | 소장/실장 결재 대기 건 연동 (결재현황 GAS 카테고리 필터) |

## 9. COO 최종 의견

- **MVP 먼저**: 기존 GAS를 그대로 쓰는 날짜별 집계판(단계 1~3)은 신규 인프라 없이 바로 구축 가능. GM 확정 즉시 착수 가능.
- **이슈대장은 후속**: 미결 이슈 추적(시트 신규 탭)은 실제 운영하면서 필요성 확인 후 추가 권장.
- **주간 트렌드는 선택**: GAS 수정이 필요하므로 MVP 검증 후 결정.
