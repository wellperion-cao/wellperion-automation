# 🧩 스킬·플러그인 치트시트

_시토 자기학습(주간)이 설치 스킬·플러그인을 훑어 활용법을 발굴·제안한다._
_반영(박제)은 GM 승인 카드에 한해 수동으로만 — 아래 표에 채운다._

- 인벤토리 수집: `python scripts/skill_inventory.py` (설치 스킬·미활용 표시, read-only)
- 제안 생성: 주간 `ai_learning_proposer.py` — 반영위치 "스킬·플러그인 활용" 카드
- 승인→반영: `--approve <id>` → 수동 박제(이 표) → `--mark-applied <id>`

## 우리 워크플로 활용 등록부

| 스킬 | 언제 쓰나 | 우리 사례 |
|---|---|---|
| _(예: brainstorming)_ | _(예: 새 기능 설계 착수 전 요구사항 탐색)_ | _(GM 승인 후 실제 사례 기록)_ |
| autoresearch | 반복 집계 배(예: 점검 월간 리포트)를 '측정 가능한 성공기준(evaluator 계약)'에 물려 전월 대비 개선 여부를 스스로 판정·기록하고 싶을 때 | 시우 — 점검 월간 분석 리포트 자동화(자기개선 루프): `.omc/autoresearch/monthly_check.mission.md`에 '성공=전월 대비 완료율↑ 또는 미완료 이슈 수↓(근거=시트 G열 집계값)' evaluator 계약 명시 → 월별 집계 스크립트가 이번달·전월 JSON을 autoresearch에 입력 → 결정로그를 `.omc/autoresearch/YYYY-MM.md`에 append, 텔레그램 요약에 전월대비 델타 1줄 추가 (GM 승인 2026-07-02, prop_20260702_160024_1a123f) |

> 표의 '스킬' 칸에 스킬 이름이 등장하면 skill_inventory 가 '정리됨(☑)'으로 인식한다.
> 아직 비어 있으면 전부 '✨미활용'로 표시된다(정상 — 뼈대 단계).
