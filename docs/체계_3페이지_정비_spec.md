# 체계 3페이지(운영부·시설부·지원부) 정비 스펙 (GM 결재 2026-06-11)

> 근본 원인: 3 페이지가 서로 복사돼 **절반만 개작** → 부서 교차오염(운영부 매뉴얼=시설부 주차 복사본 / 시설부 점검=지원부와 동일). 페이지별 '본인 부서 내용'으로 일관 재정비.

## 🌐 전 페이지 공통
- **G1. 저장/저장완료 버튼**: 우측 상단 → **가운데 상단**으로 이동.
- **G2. 가이드/점검 칸반 풀폭**: 좌→우 끝까지(full-width). (운영부 "전부" 결재)
- **G3. 부서 교차오염 제거**: 각 페이지 = 본인 부서 콘텐츠만. 저장소 키 부서별 분리.
- **G4. 점검 = 단일 리스트**(재점검 삭제) → 제출 시 '점검일지'에 스냅샷 적립 + **체크박스 리셋**(다음 점검 준비).
- **G5. 이슈/노하우**: 메모 **저장 버튼** + **반영완료 버튼**(시트에도 기록).
- **G6. 온도 기록**: 점검 항목에 온도 입력칸(사우나·탕·냉온수기·냉장고 등) + 기준 벗어나면 자동 경고(빨강).
- **G7. 점검자 칸**: 점검시간 + 점검자 선택 **반반**.
- **G8. 요일별 집중청소**: 맨 아래 X → 오늘 요일 해당분만 상단 '오늘 점검' 자동 합류, 전체는 접이식.
- A3 인쇄 정합: 점검 ↔ 매뉴얼 1:1 (인쇄해서 그대로 점검 가능).

## 🧑‍💻 운영부 (coo/check/운영부 체계.html)
- O1. 규정 — '점검 안내' 칸반 삭제 ✅(완료 1b444acc)
- O2. 가이드 풀폭(전부 — 근무·휴게 컬럼 100% + 가이드 탭 본문 확장)
- O3. 매뉴얼 보드 — **구역별 상세 절차(주차 매뉴얼)는 시설부로 이관**, 나머지 **운영부 내용으로 재작성**(정본 = setupBaseSlots WEEKDAY/WEEKEND 리셉션 체크리스트: 오픈점검·오전응대 등). 보드 시드·라벨·공통유의의 시설부/주차 잔존 제거.
- G1 저장버튼 가운데.

## 🖥️ 시설부 (coo/check/시설부 체계.html)
- F1. 규정 — **주차 관리 가이드 구축**(운영부에서 이관된 주차 매뉴얼 내용 흡수).
- F2. 가이드 풀폭.
- F3. 매뉴얼 추가 — **골프룸 PC**(오픈 ON / 마감만 OFF · 이용·종료 시 모니터만 ON/OFF), **천정 센서**(반응 없을 시 별도 천정센서 OFF→5초 후 ON).
- F4. **직원 구성/역할 → 규정으로 이동**(매뉴얼 아님).
- F5. **점검(남)/(여) 삭제 → "시설 점검일지" 1탭**.
- F6. 점검 저장소 **부서 분리**(지원부와 동기화 끊기).
- G1~G8 공통 적용.

## 🛠️ 지원부 (coo/check/지원부 체계.html)
- S1. 전체 업그레이드 + 온도/이슈 기록(G6).
- S2. 가이드 풀폭.
- S3. 매뉴얼 — **헬스장 정수기 청소 1주1회**(주기 항목) 추가. A3 인쇄 정합.
- S4. 점검:
  - 이슈/노하우 **저장 + 반영완료 버튼**(시트 기록) — G5.
  - 점검자 칸 = 점검시간 + 선택 반반 — G7.
  - 칸반 **풀폭** — G2.
  - **단일 점검리스트 + 제출 리셋 + 일지 적립** — G4.
  - 항목 재구성: **E 외곽청결→E 내부(오전) / D 외부(오후)→D 내부(오후) / 상시 F 회원응대 → 가이드로 이관·합병 / 요일별 집중청소 상단 합류**(G8).

## 🔧 점검 셋업 편집 위치 (GM 2026-06-11)
- **점검 항목 셋업 편집(setupBaseSlots)이 '매뉴얼' 탭에 있는데 → '점검' 탭으로 이동**해야 함. 전 체계 공통(복사 오염).
- ※ 체계 페이지 = 5개 부서로 더 있음: 운영부·시설부·지원부 + **파트너팀·주차관리부**. 정비·점검 위치 수정 시 5개 전부 확인.

## 실행 순서
운영부 → 시설부(운영부서 이관 주차 흡수) → 지원부 → 파트너팀·주차관리부 확인. 각 페이지 본인 파일만, 커밋만(웰리 검증 후 push). 페이지별 입항 후 다음.
