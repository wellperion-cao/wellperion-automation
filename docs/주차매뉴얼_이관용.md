# 주차 매뉴얼 (운영부 → 시설부 이관용)

> 출처: `3. 웰페리온 가이드/coo/check/운영부 체계.html` 매뉴얼 탭에 잔존하던 주차장 매뉴얼 내용.
> 운영부 정비(2026-06-11) 시 추출 → 시설부 규정 '주차 관리 가이드'(F1)로 흡수 예정.
> 시설부 페이지 정비 시 이 문서를 원천으로 사용.

## 공통 유의사항 (주차)
- **차량 접촉/파손·차단기 고장·화재 위험은 즉시 조치 후 팀장·소장 보고** (자의 판단 금지)
- 차량번호·CCTV 영상은 회원 개인정보 — 외부 유출·임의 열람 금지
- 순찰 시 야광 조끼·안전화 착용 / 차량 이동 동선 주의
- 사고·민원 발생 시 현장 보존 + 사진 + CCTV 시각 기록 의무

## 구역별 상세 절차

### 출입통제 · 차단기 (출)
- **차단기**
  - 입·출차 차단기 바(barrier) 작동·손상 여부 확인
  - 센서·리모컨 반응 점검 / 오작동 시 즉시 수동 개방 후 보고
- **LPR(번호인식) 카메라**
  - 렌즈 청결 / 번호 인식 정상 / 표시판 점등 확인
- **회원/방문 운영**
  - 회원 차량 자동개방 / 방문 차량 안내·등록 절차 준수

### 정산 · 요금기 (정)
- **무인 정산기**
  - 화면·버튼·카드리더 정상 / 지폐·동전 투입구 막힘 여부
  - 잔돈 보유량 / 영수증 용지 잔량 확인
- **현금 시재**
  - 교대 시 현금 시재 인수인계·기록 의무
  - 미정산/미수 건 즉시 공유

### 지상 주차장 (지상)
- **순찰**
  - 불법·이중·무단 장기 주차 계도 및 기록
  - 통행로 적치물 / 바닥 주차선·번호 식별
- **설비**
  - 조명 점등 불량·깜빡임 구역 기록 (야간 대비)
  - 배수구 막힘 / 천장·벽면 누수 / 결빙 위험(동절기)

### 지하 주차장 (층별) (지하)
- **층별 순찰**
  - B1·B2 등 층별 순회 / 불법·이중 주차 / 적치물
  - 층별 빈자리 현황 파악 및 안내
- **환기·누수**
  - 조명 점등 / 환기·제연 팬 가동음·매연·악취
  - 천장·벽면 누수 / 바닥 고임물 / 차수판(우수기) 상태

### 우선 · 지정 구역 (우)
- **장애인 전용구역**: 불법 점유 단속 / 표지·바닥도색 식별 / 비정상 주차 계도·기록
- **여성우선 구역**: 위치·조명 양호 / 표지 식별 / 불법 점유 점검
- **전기차 충전구역**: 충전기 작동 / 비충전 차량 점유 점검 / 케이블 정리

### 안전 · 소방 · CCTV (안)
- **소방**
  - 소화기·소화전 비치 위치·수량 / 압력게이지 / 통로 가림 여부
  - 비상구 유도등 점등 / 피난통로 적치물 제거 / 비상벨 위치
- **CCTV**
  - 주차구역 CCTV 화면 이상 / 사각지대 / 녹화 정상 여부
  - **영상 열람은 사고·민원 처리 목적 + 책임자 승인 한정**
- **주차장 화장실**: 청결 / 비품(화장지·손세정제) / 악취·조명

## 요일별 집중 점검 (주차)
| 요일 | 집중 점검 항목 |
|---|---|
| 월 | 바닥 주차선·표시 / 차단기 정밀 점검 / 장애인·여성우선 구역 집중 |
| 화 | 배수구·차수판 / 조명 전수 점검 / 안내·규정 게시물 |
| 수 | CCTV 사각지대 / 환기·제연 설비 점검 |
| 목 | 바닥 청소·오염 제거 / 소화기·소화전 / 주차장 화장실 집중 |
| 금 | 정산기 정밀 점검 / 전기차 충전구역 / 비상구·피난통로 집중 |
| 토 | 천장·벽면 누수 전수 / 주차유도·만차 표시기 / 혼잡 대응 |
| 일 | 전 구역 대청소 / 장기 미출차 차량 정리 / 미비 부분 보완 |

## 보드 시드(요일별 트렐로) 원본 — 지상/지하/공통 분류
> 운영부 매뉴얼 보드(BOARD_SEED)에 잔존하던 주차 시드. 시설부 보드 구축 시 참고.

### 월 (mon)
- 지상: 오전 순찰(08:00~12:00) 지상 바닥 주차선·번호 식별 점검 / 지상 조명 점등 불량 구역 기록
- 지하: 오전 순찰(08:00~12:00) 지하 층별 순찰·빈자리 현황 / 지하 누수·배수구 점검
- 공통: 오전(08:00~12:00) 차단기 정밀 점검(바·센서·리모컨) / 장애인·여성우선 구역 집중 단속

### 화 (tue)
- 지상: 지상 배수구·차수판 점검 / 지상 조명 전수 점검
- 지하: 지하 환기·제연 가동 점검 / 지하 조명 전수 점검
- 공통: 안내·규정 게시물 점검 / 주차유도·만차 표시기 점검

### 수 (wed)
- 지상: 지상 CCTV 사각지대 점검 / 지상 통행로 적치물 정리
- 지하: 지하 CCTV 사각지대 점검 / 지하 환기·제연 설비 점검
- 공통: CCTV 녹화 보존 확인 / 정산기 카드리더·시재 점검

### 목 (thu)
- 지상: 지상 바닥 청소·오염 제거 / 지상 통행로 이물질 제거
- 지하: 지하 바닥 고임물·오염 제거 / 지하 층별 재순찰
- 공통: 소화기·소화전 점검 / 주차장 화장실 집중 청소

### 금 (fri)
- 지상: 지상 전기차 충전구역 점검 / 지상 비상구·피난통로 점검
- 지하: 지하 전기차 충전구역 점검 / 지하 비상구·피난통로 점검
- 공통: 정산기 정밀 점검(지폐·동전·영수증) / 비상벨·유도등 점검

### 토 (sat)
- 지상: 지상 천장·벽면 누수 전수 / 지상 주말 혼잡 유도
- 지하: 지하 천장·벽면 누수 전수 / 지하 주말 혼잡 유도
- 공통: 주차유도·만차 표시기 전수 / 혼잡 대응 동선·임시 안내 점검

### 일 (sun)
- 지상: 지상 전 구역 대청소 / 지상 장기 미출차 차량 정리·기록
- 지하: 지하 전 구역 대청소 / 지하 장기 미출차 차량 정리·기록
- 공통: 장기 주차 차량 안내 조치 / 한 주간 미결·미비 점검 보완
