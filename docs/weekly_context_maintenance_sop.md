## 2. 정비 체크리스트 (각 항목 = 대상 · 판정 · 조치)

### A. 상시 컨텍스트 슬림화 — **주체: 웰리(CEO)** (매 턴 가장 무거운 본업)
| 대상 | 판정(이러면 정비) | 조치 |

| `CLAUDE.md` | 원칙 본문 하드카피(S2에 있어야 할 것) / 누적 경위 기록 | S2 포인터로 환원, 경위는 `docs/CLAUDE_이력.md`로 |
| 에이전트 프롬프트 `wellperion-agents/.claude/agents/ai-*.md` | R/R·원칙 하드코딩(S2 중복) | S2 포인터화, 부팅 주입 군더더기 제거 |

### B. 큐·산출물 적체 정리 — **주체: 각 C레벨(본인 배) · 시우(전체 위생)**

|---|---|---|
| `status/_queue.json` | terminal(DONE/폐기) 건이 14일+ 경과·다수 잔존 → 파일 비대 | 오래된 terminal 건 `status/_archive.json`으로 이관(잘게·단계검증). **활성(PENDING/IN_PROGRESS)은 그대로**. 시트=원본/_queue=미러 원칙 유지 |
| `cmo/review/review_queue.json` | 발행완료·오래된 검수건 누적 | `review_queue_archive.json`으로 압축(전례 691→446행) |

## 3. 측정 (정비 효과 = 숫자로)
주간 추세로 "가벼워지는지" 본다. 일요일 정비 후 기록:
- `MEMORY.md` 줄 수 / memory/*.md 개수 (정합=동일)
- `CLAUDE.md` 줄 수 · 에이전트 프롬프트 합계 줄 수
- `_queue.json` 활성/terminal 척 수
- 매 턴 상시 배경 추정 토큰(가능 시)
> 증가 추세면 다음 일요일 A·B 항목 강화. **목표: 월요일 시작 시 상시 컨텍스트 = 안정적 경량 유지.**

## 4. 운영 원칙
- 일요일 = 정비, 월요일 = 가벼운 시작. 주중엔 정비로 손 안 댐(긴급 외).
- **net-zero**: 메모리·문서에 더할 땐 같은 양을 뺀다(무한 증가 차단).
- **자동화 우선(박제)**: 반복 정비는 사람이 매주 하지 말고 점차 스크립트/측정 도구로 이관(예: 메모리 정합 체커·_queue 적체 측정기). 후속 자동화 항로로.
- **G1 가시화**: 일요일 정비 자체도 배(ship)로 G1에 올려 "정비 완료 1척"이 보이게.

## 5. 후속(자동화 발전)
- 메모리 정합 체커(고아·끊긴링크·net-zero 측정) 스크립트화
- `_queue` terminal 적체 자동 측정·아카이브 후보 리스트 산출(이관은 사람 확인)
- 상시 컨텍스트 토큰 측정기 → 주간 추세 텔레그램 1줄
- 본 SOP를 가이드 T1(기술/자동화)에 링크(웰리·GM 확인 후)
