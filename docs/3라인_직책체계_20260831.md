## 0. 한 줄 목표

회장님·대표님이 현장 걱정 없이 방향과 중요 결정에 집중할 수 있는 클럽.
그 구조는 **운영부 리더 / 시설부 소장 / 인사·재무 리더** 3개 직책이 각자 책임지고, GM은 세 라인이 제대로 돌아가는지만 보는 것.
**완료 기한 2026-12-31.**

원칙: 사람이 아닌 **직책 기준**으로 설계한다. 수행자가 바뀌어도 자리와 기준은 남는다.

회장님·대표님 보고: 세 라인을 묶은 **월간 경영 리포트 1장** + 즉시보고 기준 해당 건.

- [ ] 회장님 보고를 **월 1회 경영 리포트 + 즉시보고**로 전환

## 4. 리스크

1. **운영부 리더 수행자 불확실** — 8월 실장 평가 결과에 따라 직책 조정 가능. 직책 기준 설계라 구조는 유지, 해당 라인만 1개월 지연 가능.
2. **인사·재무 리더 부담 과중** — 두 영역을 한 직책이 맡음. 브로제이 전환으로 손익 자동화되면 완화. 12월 평가에서 분리 여부 판단.
3. **회장님 직접 개입 재발** — 반드시 발생. 대응: 막지 않고 "해당 건은 ○○ 리더가 이번 주 처리 후 리포트 등재"로 라인 경유 처리. 이 경험이 쌓여야 구조가 선다.
