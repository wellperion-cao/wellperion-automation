## 2. 타이포그래피 (Typography)

| 구분 | 공식 지정(가이드) | 실제 사용 폰트(무료·동봉) | 위치 |
|---|---|---|---|
| 영문 제목 — 메인 | ITC Avant Garde / Medium | Pretendard Bold로 대체 | 표지 대제목 |
| 영문 제목 — 스포츠클럽 | Hudson NY Serif | Pretendard Bold로 대체 | 스포츠클럽 표지 |
| 본문(한/영) | **Pretendard / Medium · SemiBold** | Pretendard Medium·SemiBold | 모든 본문·부제·풋터 |

- 폰트 파일: `2. 브랜드_공식문서/font/Pretendard-{Bold,SemiBold,Medium}.otf` (slide_compositor·make_reel가 자동 로드).
- **Pretendard가 사실상 표준** — ITC Avant Garde/Hudson NY는 유료라 자동화 파이프라인에서 Pretendard로 통일(가이드의 "본문=Pretendard"와 일치하므로 톤 깨지지 않음).
- 영문 대제목은 **대문자 + 자간(letter-spacing)** 적용(코드 `compose_main_slide`가 글자 단위 렌더로 구현).
- 한글 헤딩=Bold, 본문=SemiBold, 부가정보=Medium. (코드 `load_font` 매핑과 동일)

## 3. 로고 (Logo)

### 3-1. 기본 형태 (공식 가이드)
- **W 심볼** + `WELLPERION` 워드마크.
- **가로형(Horizontal)**: 심볼 좌, 워드마크 우 — 슬라이드 헤더 기본.
- **세로형(Vertical)**: 심볼 위, 워드마크 아래 — 정방형·좁은 공간.
- 기본 색: 다크 배경엔 **베이지**, 사진/밝은 배경엔 **화이트**.

### 3-2. 로고 PNG 자산 (코드가 쓰는 실제 파일)
위치: `instagram/_assets/logo/`
| 파일 | 용도 |
|---|---|
| `wellperion_white_alpha.png` | 사진 위(밝은 배경) — 반투명 다크 박스와 함께 |
| `wellperion_beige_alpha.png` | 다크 배경(텍스트 슬라이드) — 박스 없이 |
| `wellperion_white.png` / `wellperion_beige.png` / `wellperion_black.png` | 단색 배경별 변형 |

### 3-3. 계정별 로고 규칙 (SOP — `_AI시리즈_로드맵.md`가 정본)
| 계정 | 로고 | compositor 인자 |
|---|---|---|
| 개인계정 `namuk.wellperion` | **W 심볼만** 미니멀 | `logo_style="symbol"` |
| 회사 공식계정 `wellperion` | **풀 로고** | `logo_style="full"`(기본값) |

> 풀 로고 영문에 'SPA & FITNESS'가 남아 있는 것(피트니스 금지 원칙과 상충)은 **로고 자산 차원의 별개 사안**. **GM 결재(2026-06-04): 현상 유지(A) — 로고 락업 'SPA & FITNESS' 변경하지 않음.** 코드로 로고 PNG를 재합성하지 않는다. (이 항목 종결 — 재플래그 금지)

## 4. 사진 톤·구도 (Photography) — G: 시설 사진 실측 기준

대표 시설 사진(로비·카페·수영장·골프·헬스·필라테스·외부) 분석 결과 공통 패턴:

| 기준 | 웰페리온 사진의 특징 |
|---|---|
| **색감** | 따뜻한 뉴트럴 — 베이지 대리석·우드·아이보리 벽. 차가운 형광 톤 회피. 브랜드 베이지와 자연스럽게 맞물림 |
| **광원** | 밝은 자연광 + 균일한 다운라이트. 그림자 적고 깨끗함. 과한 콘트라스트 없음 |
| **구도** | **와이드 건축 구도** — 공간 전체가 들어오는 수평·대칭 프레이밍. 1점 투시로 깊이감 |
| **피사체** | **인물 없음(공간 위주)**. 시설·장비·마감재가 주인공. 럭셔리 호텔 라운지 무드 |
| **장비 색** | TechnoGym 등 **블랙** 장비 → 브랜드 BLACK과 조응 |
| **마감** | 대리석/스톤/우드 질감 강조. 정돈·여백 많음(미니멀) |

### 4-1. 슬라이드용 사진 가공 표준 (코드에 이미 구현)
- **듀오톤 변환**: 모든 메인/통일 슬라이드 사진은 `to_duotone()`로 **BLACK→BEIGE 듀오톤**(`#221F20`↔`#B79F8A`) 처리 → 어떤 사진이든 동일 브랜드 톤·럭셔리 매거진 무드. (정본 함수: `compose_barre.to_duotone` — `compose_ballet`도 이를 import 재사용)
- **다크 그라디언트 오버레이**: 텍스트 영역(하단)에 브랜드 배경색 그라디언트 → 가독성 확보(`apply_dark_gradient`). 사진은 전반적으로 약간(0.92) 어둡게.
- **레이아웃**: 메인/통일 템플릿 = 상단 **65% 사진(듀오톤) + 하단 35% 정보 영역**. (IG 메인 슬라이드 영구 템플릿)

### 4-2. 촬영·선정 가이드 (신규 사진 의뢰 시)
- 위 6개 기준을 따른다: 자연광·와이드·인물 없는 공간·따뜻한 뉴트럴·정돈된 여백.
- 원본 저장: 신규 수집 이미지 원본은 `instagram/Image/`에 누적(시디 자산 규칙).

## 6. 릴스·영상 제작 기준 (`scripts/make_reel.py`)

| 항목 | 기준값 |
|---|---|
| 해상도 | **1080×1920 세로**, H.264/libx264, 30fps |
| 배경색(레터박스) | 브랜드 BLACK `#221F20` |
| 움직임 | **Ken Burns 줌인/줌아웃 교차**(기본 ON) — 정적 슬라이드쇼 금지 |
| 줌 비율 | 1.0 ~ 1.12 |
| 장당 노출 | 기본 2.5초 |
| 전환 | CrossFade 0.4초 |
| 자막 | PIL+Pretendard 직접 렌더(ImageMagick 불필요). 하단 18% 위치 + 반투명 띠 + 외곽선 |
| 음악 | **사람이 받은 무료 음원만** `--music` 투입. 자동 다운로드 금지. 끝 0.5초 페이드아웃 |
| 출력 위치 | `instagram/Movie/{name}_{timestamp}.mp4` |

- 제작 비용 0(MoviePy + 동봉 ffmpeg + Pillow). 유료 스택(캔바 자동화) 미채택.
