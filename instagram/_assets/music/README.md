# 릴스 배경음악 풀 (저작권프리 음원 보관함)

**용도:** 릴스 제작(`scripts/make_reel.py`) 시 `--music` 인자로 넣을 배경음악 파일 보관 폴더.
이 폴더에 둔 .mp3를 릴스 제작 시 선택해 사용한다.

## 규칙

- **저작권프리(로열티프리) 음원만.** 상업적 사용 안전 곡만 보관.
- 추천 출처:
  - 유튜브 스튜디오 오디오 보관함(무료) — studio.youtube.com → 오디오 보관함 → 무료 필터
  - Pixabay Music — pixabay.com/music (상업적 무료)
- 형식: **.mp3 권장.** 파일명은 분위기로 작성 (예: `calm_01.mp3`, `upbeat_01.mp3`, `luxury_01.mp3`).
- 자동 다운로드 금지 — GM이 직접 받아 이 폴더에 넣는다.

## 사용법

GM이 초기 3~5곡을 이 폴더에 넣으면, 이후 릴스 제작 시 `--music` 인자에 해당 파일 경로를 지정해 자동 적용된다 (매번 수작업 불필요).

이 폴더가 비어 있으면 릴스는 무음으로 생성된다 (에러 아님).
