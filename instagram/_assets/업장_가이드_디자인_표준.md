# 업장 가이드 카드 디자인 표준 (SSOT)

> 모든 업장(필라테스·웰니스·골프·스쿼시·PT·수영·체조 등) **가이드 카드**(포스트 마지막 장 "WELLPERION GUIDE" 정보 카드)의 단일 디자인 표준.
> **새 업장 가이드를 만들 땐 이 문서 + 마스터 원본대로만 만든다.** 새로 그리지 않는다.

## 0. 정본 위치 (두 개)
| 정본 | 무엇 | 역할 |
|---|---|---|
| **픽셀 정본** | `instagram/_assets/guideline_card.jpg` | 사람 디자이너가 만든 마스터 원본. 로고·칩·제목블록·구분선·여백·폰트크기의 **픽셀 진실**. 함부로 재작성 금지 |
| **규칙 정본** | 이 문서 | 상속 방법·교체 규칙·금지사항 |

- 색·폰트 경로 코드 상수 = `scripts/brand_constants.py` (디자인 표준 마스터 정본).
- 좋은 예 = `각 업장 가이드/`의 웰니스·필라테스·골프 가이드 (전부 마스터 상속). 나쁜 예 = 과거 골프 from-scratch(제목46·항목20·헤더밑줄·배경변형 드리프트 → 본 표준으로 교정 완료).

### 완성 가이드 보관 (단일 폴더 · 2026-06-22 GM)
완성된 업장별 가이드 카드는 **모두 `_assets/각 업장 가이드/` 한 폴더**에 `{업장} 가이드.jpg` 명명으로 보관(단일 출처·드리프트 방지).
- 현재: `웰니스스튜디오 가이드.jpg` · `필라테스 가이드.jpg` · `골프 가이드.jpg`
- 코드가 이 폴더를 직독 — 골프: `compose_guideline_card_golf.py`가 `각 업장 가이드/골프 가이드.jpg`로 출력, `compose_golf.py`가 같은 경로 참조(루트 `guideline_card_golf.jpg` 폐지).
- `_assets/guideline_card.jpg`(루트) = 코드 빌드용 **마스터 베이스**(사람 열람용 아님), 별개 유지. 새 업장도 이 폴더에 추가.

## 1. 황금 규칙 — 상속하라, 새로 그리지 마라
**새 업장 가이드 = 마스터 `guideline_card.jpg`를 베이스로 복사 → 바뀌는 텍스트만 패치.**
- 공통 프레임(로고·우상단 칩·"WELLPERION GUIDE" 제목블록·중앙 세로 구분선·OPERATIONS·문의·주소)은 **마스터 그대로 둔다**(다시 그리지 않음).
- 업장마다 바뀌는 건 **가운데 3개 섹션의 제목·항목 텍스트뿐**.
- 참고 구현: `scripts/compose_pilates.py`의 `compose_guide_card_pilates()` — 마스터 jpg 위에 섹션명·항목만 erase+redraw.
- ❌ **금지**: 코드로 카드 전체를 처음부터 새로 그리기(from-scratch). 한 곳이라도 크기·색·여백이 어긋난다(골프 사고).

## 4. 레이아웃·구분선 (칸)
- **중앙 세로 구분선 1개**(좌/우 2칼럼 분리)만 사용 — 얇게(width 1), SEP_LINE 색.
- 상단(제목블록 아래)·OPERATIONS 위·문의 위에 **얇은 가로 구분선** 각 1개.
- ❌ **헤더마다 가로 밑줄 추가 금지**(골프가 섹션 제목마다 밑줄을 그어 빽빽·무거워짐).
- 하단 OPERATIONS 블록은 본문에서 **충분히 띄워** 아래쪽에 배치(여백이 고급감). 위로 당겨 붙이지 말 것.

## 5. 고정 구조 (6영역 · 순서 불변)
1. 좌상단 로고(beige_alpha, 폭 130, 위치 40,40) + 우상단 칩
2. 중앙 제목블록: WELLPERION GUIDE → A Day, Well Completed. → 하루의 완성 → "정성스러운 하루가 모여, 더 나은 일상을 만듭니다"
3. 좌상 섹션 **FOR MEMBERS 회원님들** (5항목)
4. 좌하 섹션 **FOR INSTRUCTORS 강사님들** / 업장 성격 따라 **FOR PROS 프로님들** 등 (5항목)
5. 우측 섹션 **{업장} FACILITY {업장} 시설 이용** (5항목) — 업장명만 교체
6. 하단 OPERATIONS 운영안내(2줄·전 업장 공통) + 문의 한 줄(`http://wellperion.com/ko/inquiry/`) + 주소 한 줄

## 6. 새 업장 가이드 만들 때 (체크리스트)
- [ ] 마스터 `guideline_card.jpg` 복사로 시작 (새로 그리지 않음)
- [ ] 우측 섹션 헤더 `{업장} FACILITY / {업장} 시설 이용`로 교체
- [ ] 좌하 헤더를 업장 성격에 맞게(강사→프로 등), 3개 섹션 항목 텍스트 교체
- [ ] 교체한 텍스트의 폰트·크기·색을 §3 정본값으로 (헤더 22 / 항목 16·연회색)
- [ ] 배경·여백·구분선·제목·로고·칩·OPERATIONS·문의·주소는 **손대지 않음**
- [ ] 시크릿 창에서 옛날 카드(웰니스·필라테스)와 나란히 두고 크기·여백 일치 눈검증

> 요약: **틀은 마스터가 정한다. 업장은 글자만 바꾼다. 키우지·굵히지·당기지 않는다.**
