# 참고자료 폴더 — 영상 제작 입력함 (GM → 시디)

이 폴더는 **GM(또는 시모)이 영상 제작에 쓰일 참고자료를 넣어두는 곳**입니다.
시디(디자이너)가 여기를 읽고 캡션·구성을 설계해 릴스를 만듭니다. 모두 무료 도구만 사용(결제 0).

## 어디에 무엇을 넣나
| 종류 | 넣는 곳 | 예시 |
|---|---|---|
| **사진 원본** | `instagram/Image/` | 촬영본, 매장 사진, 시설 사진 |
| **글·기획·톤·예시** | **이 폴더 (`instagram/참고자료/`)** | 카피 초안, 기획 메모, 톤앤매너 설명, 참고 영상 링크(txt), 레퍼런스 이미지 |
| (자동 생성) 영상 결과 | `instagram/Movie/` | 시디가 만든 릴스 mp4 |

## 넣는 방법 (간단)
1. **사진**은 `instagram/Image/` 폴더에 둡니다.
2. **글·기획·참고영상 링크·톤 설명**은 이 폴더에 자유롭게 파일로 넣습니다.
   - 텍스트 메모: `.txt` / `.md` (예: `기획_바레런칭.txt`)
   - 참고 영상 링크: `.txt` 안에 URL 한 줄씩
   - 레퍼런스 이미지: 그냥 이미지 파일
3. **자막을 직접 정하고 싶으면** 콘텐츠 폴더(또는 이미지 폴더)에 `reel_captions.txt` 를 두고
   **이미지 순서대로 한 줄에 캡션 1개**씩 적습니다. (자막 없는 장은 빈 줄)

## 그다음은 시디가 합니다
GM이 사진·참고글을 넣어두면, 시디가:
1. 참고자료를 읽고 → 2. 캡션·구성을 설계하고 → 3. 슬라이드(`slide_compositor`)+사진을 준비해 →
4. `make_reel.py`로 **움직임(Ken Burns)·음악·자막**을 입혀 릴스를 만들고 →
5. `instagram/Movie/`에 저장 + 텔레그램 미리보기 + M5 검수큐에 올립니다. (발행은 GM 승인 게이트)

## 음악 안내 (중요)
- 저작권 음악 자동 다운로드는 **하지 않습니다.** 무료 음원(유튜브 오디오 보관함 등)은
  **사람이 직접 받아서** 시디에게 전달하거나 이 폴더에 넣어주세요.
- 시디는 받은 mp3 파일만 `--music` 으로 영상에 입힙니다.
