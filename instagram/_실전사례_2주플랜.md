   - 만드는 법: ① 항목 목록 → ② 자동집계·이슈 등재 → ③ 폰에서 쓰기
3. **아침·시간대별 자동 보고** — 오픈·피크·마감 + 아침 8시 전사 현황 한 장(라이브)
   - 만드는 법: ① 볼 것 정하기 → ② 8시 자동 요약 → ③ 받을 곳 연결
4. **문의 한 길로 + 현황** — 전화·방문 제각각 → 한 창구·자동 기록·일/주/월 현황(라이브)
   - 만드는 법: ① 창구 하나로 → ② 자동 기록·집계 → ③ 대시보드
5. **글 하나로 채널 자동발행** — 한 번 검수 → 채널별 자동 발행(라이브)
   - 만드는 법: ① 채널 정하기 → ② 형식 맞춰 발행 → ③ 검수 한 번
