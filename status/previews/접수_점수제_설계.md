# 접수 처리 점수제 — 설계안 (코드 미구현 · GM 확정 대기)

2026-08-29 · 웰리. GM 원문: "일주일이 지난건 처리해도 −1점, 계속 냅두면 −3점(−3점 시 운영부 실장 이관·실장도 적용) / 바로 처리 +1점 / 정책·문화·가이드로 발생 시 +3점".
설계만 — 코드 0줄. 사람 평가에 걸리는 제도라 GM이 이 문서로 확정한 뒤 구현한다.

## ① 점수 규칙

| 점수 | 조건 | 경계(숫자) | 판정 방법 |
|---|---|---|---|
| **+1** 바로 처리 | 접수→완료 | **3일(72h) 이내** 〔제안값 — 접수처 기존 리마인드 계단(3일)과 같은 눈금 재사용〕 | 자동 — 접수일·완료일이 원장에 있음(소요일 복원 완비) |
| **+3** 정책·문화·가이드로 해결 | 같은 유형이 재발하지 않게 규정·안내문·구조를 만든 처리 | 완료 시점 무관(3일 넘어도 +3) 〔제안〕 | **자동 불가** — 화면 완료 처리에 「재발 방지 처리」 체크칸 1개 신설(사람 표시) + **GM 주간 승인 시 확정** 〔제안 — 자가신고만으로 +3이 남발되면 제도가 죽는다〕 |
| **−1** 늦은 처리 | 7일 초과 후 완료 | **7일(168h) 초과** 〔GM 확정〕 | 자동 |
| **−3** 방치 | 완료 없이 계속 열림 | **14일(336h) 초과 시점**에 확정 〔제안값 — 7일(−1 경계)의 두 배·기존 🔴 표시 기준(14일)과 일치〕 | 자동 |

- 하나의 건은 최종 상태 하나로만 채점(+1/−1/−3 중복 없음). −3 확정 건을 나중에 완료해도 −3 유지 〔제안 — 지웠다 살리기가 되면 방치의 값이 사라진다〕.
- **분실물은 점수제 제외** 〔제안〕 — 오늘 확정된 3단계 마감(보관30·공지30·이관폐기)이 담당하는 구조 건이라, 점수를 물리면 20건 전부가 무의미한 −3이 된다.

## ② −3 이관 규칙

- **이관 시점** = 14일 초과 확정과 동시에. 건의 부서를 운영부로 재배정(기존 reg_update dept 재배정 경로 실재)하고 처리 메모에 「14일 초과 — 운영부 실장 이관(원담당 −3 확정)」 자동 기록.
- **원담당 점수** = −3 그대로 유지(이관은 구제가 아니라 확정).
- **실장 시계** = 이관일부터 새로 0일. 이관 후 7일 초과 −1 · 14일 초과 −3 — **같은 규칙이 실장에게 재귀 적용**(GM 원문 그대로). 실장 −3 시 재이관처는 GM 〔제안 — 그 위가 없다〕.

## ③ 누구에게 붙는 점수인가

- **패널티(−1·−3) = 부서 책임자** — 접수처에는 담당자 칸이 없다(2026-08-21 GM 확정 · 사람 칸은 접수자·처리자뿐). 미완 건은 처리자도 비어 있으므로, 부를 사람은 부서 책임자 매핑(kpi.json 부서반장·팀리더 정본) 하나뿐이다. 아침 통이 이미 이 매핑으로 이름을 부른다 — 점수도 같은 사람이어야 제도가 돈다.
- **가점(+1·+3) = 처리자 칸의 사람** — 완료 시 실제 처리한 사람이 기록된다. 부서 책임자와 다르면 처리한 사람이 받는다(일한 사람이 받는 게 맞다).
- **부서 미정 건** = 운영부 실장 몫 〔제안 — 이관 규칙과 일관: 갈 곳 없는 건은 실장이 기본 수신자〕. 주차관리부 = 시설부 소장(GM 확정 2026-08-26).

## ④ 어디에 쌓이나 — 새 원장 불필요

기존 **GAS 점수판(reg_scoreboard · 접수 1점+완료 1점 주간, 2026-07-28 GM 지시)**이 이미 산다. 같은 서버 함수에 이번 4규칙 열을 얹으면 끝 — 판정 재료(접수일·완료일·처리자·부서)는 전부 reg_list에 이미 있다. **새로 필요한 것 = 「재발 방지 처리」 체크칸 1개**(+3용)뿐. 발표는 기존 아침·저녁 통의 점수판 절이 그대로 실어 나른다(새 발신 0).
