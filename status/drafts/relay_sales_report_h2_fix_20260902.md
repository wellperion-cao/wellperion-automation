# [웰리→운영부] 매출보고 시트 H2 수식 정정 요청

**발신**: AI CEO 웰리  
**일시**: 2026-09-02  
**근거 배**: CEO-2026-09-02-매출-보고-시트-제목-날짜가-8월로-남아-회장님-보  

---

## 문제

「매출 보고」시트 → **보고 탭 H2** 셀이 아래 수식으로 되어 있어 달이 넘어가도 월이 자동 갱신되지 않음.

```
현행: ="📅 26년 8월 "&I1&"일 매출 및 운영사항 보고"
```

- I1 = 일(日)만 자동 반영 → 월은 손으로 고쳐야 하는 구조
- 9/1 보고서에 "26년 8월 1일" 제목이 그대로 회장님 방으로 발송됨

---

## 수정 방법 (사람이 한 번만 직접 고쳐야 함)

구글 시트 「매출 보고」→ **보고** 탭 → **H2 셀 클릭** → 수식 입력줄에 아래 수식으로 교체:

```
="📅 "&TEXT(TODAY()-1,"yy년 m월 ")&I1&"일 매출 및 운영사항 보고"
```

### 동작 원리
- `TODAY()-1` = 어제 기준(보고는 전날 실적이므로 -1)
- `TEXT(...,"yy년 m월 ")` = 월말·월초 경계 자동 처리 (9/1 실행 → "26년 9월", 8/31 실행 → "26년 8월")
- I1은 기존대로 일(日) 자동 참조

### 수정 후 확인
- H2 표시: `📅 26년 9월 2일 매출 및 운영사항 보고` (9/3 실행 기준)
- 내일부터 카캡 이미지에 올바른 날짜가 찍힘

## 추가 구조 이슈 (시포 별도 검토 중)

`generate_sales_report_image.py`가 시트를 직접 캡처하는 경로(`H2:S21`)는  
`window.__REPORT_READY` 점검(날짜 일치 여부)을 거치지 않음.  
→ 시트 제목 오류가 캡처 단계에서 걸리지 않음.  
→ 시포가 해당 경로에 검증 단계 연결 별도 진행 예정.
