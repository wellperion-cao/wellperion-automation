# ERP 네이버·카카오 로그인 — GM 손으로 하는 앱 등록 체크리스트 (배1108 · 시토 · 2026-09-07)

GM 지시(2026-09-07 17:0x): 「ERP 로그인 시 네이버+구글+카카오톡 이렇게 로그인할 수 있게 셋업해줘」.
구글은 이미 켜져 있다. 네이버·카카오는 **각 회사 개발자 사이트에 우리 앱을 등록해 키를 받아야** 켜진다 — 이 등록은 네이버·카카오 계정 로그인이 필요해 GM 손으로만 된다(AI 는 코드·화면까지 준비).

키를 받으면 서버 터미널 없이 **ERP 권한 관리 콘솔(https://erp.wellperion.com/auth/admin) ▸ 「소셜 로그인 키」 칸**에 붙여넣고 [저장]하면 바로 켜진다.

두 사이트 모두에 넣을 공통 값(복사용):
- 서비스 URL / 사이트 도메인: `https://erp.wellperion.com`
- 네이버 콜백 URL: `https://erp.wellperion.com/auth/naver/callback`
- 카카오 리다이렉트 URI: `https://erp.wellperion.com/auth/kakao/callback`
- 애플리케이션 이름: `웰페리온 ERP`

## A. 네이버 (약 5분)

1. 크롬에서 https://developers.naver.com/apps/#/register 접속 → 네이버 아이디로 로그인. ✅ 「애플리케이션 등록」 화면이 보이면 성공.
2. 애플리케이션 이름: `웰페리온 ERP` 입력.
3. 사용 API: 목록에서 **「네이버 로그인」** 선택. → 아래에 「제공 정보 선택」 표가 펼쳐진다.
4. 제공 정보: **이메일 주소 = 필수** · **이름 = 필수** 체크. (나머지는 안 함) ⚠️ 이메일을 '선택'으로 두면 회원이 동의를 안 했을 때 가입이 안 된다 — 꼭 '필수'.
5. 로그인 오픈 API 서비스 환경: **「PC 웹」** 선택 → 서비스 URL 칸에 `https://erp.wellperion.com`, 네이버 로그인 Callback URL 칸에 `https://erp.wellperion.com/auth/naver/callback` 입력.
6. 맨 아래 [등록하기] 클릭. ✅ 「애플리케이션 정보」 화면에 **Client ID** 와 **Client Secret** 두 값이 보이면 성공.
7. 그 두 값을 ERP 콘솔 「소셜 로그인 키」 ▸ 네이버 칸 두 개에 붙여넣고 [저장]. ✅ 화면에 「네이버 ✅ 설정됨」 이 뜨면 끝.
⚠️ 네이버는 등록 직후 「개발 중」 상태라 **등록한 네이버 아이디만** 로그인 테스트가 된다. 실무진이 쓰려면 같은 화면 ▸ 「멤버관리」에 테스트 아이디를 추가하거나, 「검수 요청」(로고·개인정보처리방침 URL 필요 · 보통 1~3일)을 넣어야 한다. 검수 전에는 GM 본인 계정으로만 확인.

## B. 카카오 (약 7분)

1. 크롬에서 https://developers.kakao.com/console/app 접속 → 카카오 계정으로 로그인. ✅ 「내 애플리케이션」 화면이 보이면 성공.
2. [애플리케이션 추가하기] → 앱 이름 `웰페리온 ERP` · 회사명 `주식회사 웰페리온` · 카테고리 아무거나(예: 비즈니스) → [저장].
3. 만든 앱 클릭 → 왼쪽 메뉴 **「앱 설정 ▸ 플랫폼」** → 「Web」 [플랫폼 등록] → 사이트 도메인 `https://erp.wellperion.com` → [저장].
4. 왼쪽 메뉴 **「제품 설정 ▸ 카카오 로그인」** → 맨 위 「활성화 설정」 스위치 **ON** → 아래 「Redirect URI」 [등록] → `https://erp.wellperion.com/auth/kakao/callback` → [저장].
5. 왼쪽 메뉴 **「제품 설정 ▸ 카카오 로그인 ▸ 동의항목」** → **닉네임 = 필수 동의** · **카카오계정(이메일) = 선택 동의**(개인 개발자 앱은 이메일 '필수'가 막혀 있다 — 선택으로 두면 된다. 동의 안 한 회원은 카카오 번호로 식별해 가입 신청되고 GM 이 승인하면 쓸 수 있다).
6. 왼쪽 메뉴 **「앱 설정 ▸ 앱 키」** → **REST API 키** 복사. ✅ 32자 영숫자가 보이면 성공. (JavaScript 키·Admin 키는 쓰지 않는다)
7. (권장) 왼쪽 메뉴 **「제품 설정 ▸ 카카오 로그인 ▸ 보안」** → Client Secret [코드 생성] → 「활성화 상태」 **사용함** → 생성된 코드 복사.
8. ERP 콘솔 「소셜 로그인 키」 ▸ 카카오 칸에 REST API 키 + Client Secret 붙여넣고 [저장]. ✅ 「카카오 ✅ 설정됨」 이 뜨면 끝.
⚠️ 카카오도 처음엔 「개발 중」 이라 **팀원으로 등록한 카카오 계정만** 로그인된다(「앱 설정 ▸ 팀 관리」에서 추가). 전 직원 개방은 「비즈니스 ▸ 비즈 앱 전환」(사업자등록번호 입력 · 즉시) 뒤 가능.

## C. 확인 (키 저장 뒤 · 시토가 같이 본다)

1. 시크릿 크롬에서 https://erp.wellperion.com/auth/login 을 연다. ✅ 구글 · 네이버(초록) · 카카오(노랑) 버튼 3개가 보이면 성공.
2. 네이버 버튼 → 네이버 로그인 → 동의 → 「이름·부서」 화면이 뜨면 성공(가입 신청 · GM 승인 대기).
3. 콘솔 「가입 승인 대기」에 그 신청이 보이면 성공. 승인하면 그 계정으로 ERP 로그인된다.

## 기록
- 코드 = server/erp_auth/app.py(SOCIAL 표 · /auth/{naver,kakao}) · admin.html(소셜 로그인 키 칸) — 🔒 자물쇠 라인 카드 승인 뒤 배포.
- 키는 서버 `/srv/erp/auth/social_keys.json`(관리자 콘솔만 쓰기 · 값은 화면에 되돌려주지 않음)에만 있다.
