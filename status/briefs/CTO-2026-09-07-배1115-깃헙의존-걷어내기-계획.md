## 3. ERP 도메인 서빙 규칙 (server/erp_auth/erp.nginx.conf · erp-locations-pages-prefix.conf 실독)

- 기본: `location /`가 `auth_request /auth/check`로 전부 로그인 요구. 예외는 `/auth/*`(로그인 자체)와 `/wellperion-automation/*`(구 절대경로 접두 → 302 리다이렉트로 흡수) 둘뿐.
- **이미 있는 자동교정**: `erp-locations-pages-prefix.conf`가 server 컨텍스트에 `sub_filter 'https://wellperion-cao.github.io/wellperion-automation/' '/'`를 걸어놨다(text/html 전역 적용, 2026-09-03 시우 배956). 즉 **화면(HTML) 안에 박힌 github.io 절대주소는 erp.wellperion.com으로 보는 순간 서버가 이미 상대경로로 고쳐서 내려준다.** 로그인한 사람 기준으로는 §3의 11개 화면이 지금도 안 깨진다 — ③의 화면 교체는 급하지 않고 sub_filter 의존을 줄이는 정리 성격.
- **로그인 없는 공개 경로(`/public/`)는 현재 nginx에 없다.** ②를 하려면 새 location 블록 신설이 필요.
- **자물쇠**: `server/**`는 sparse-checkout 밖이라 커밋만으론 서버에 안 반영된다(scp 배포 필수, 09-07 교훈). `server/erp_auth/`가 `project_push_lock_gm_approval_gate`(배1098) 잠금 대상인지는 이 조사에서 확인 못 함 — ②착수 전 시토가 직접 재확인.
