# 실험 #1 — IG 캡션 첫 줄 문의 CTA 효과 (#4)

작성: 2026-06-06 · AI CMO(시모) → 웰리(CEO) 보고 → **GM 판단·결정**
성격: 발행 변경 → **M5 검수 게이트 + GM 승인** 경유 (비가역 발행 정책 준수)

## 가설
IG 게시물 캡션 **'첫 줄'**에 문의 CTA(`문의: wellperion.com/ko/inquiry`)를 고정 삽입하면, 문의 페이지 클릭률이 오른다. (현재는 캡션 말미·약함)

## 측정
- 지표: **문의 페이지 클릭**(GAS click_stats) + **이번 달 문의**(period_breakdown). 대시보드 **[기간] 조회**로 실험 전/후 비교.
- 방법: 2주간 A/B — A군=첫 줄 CTA 삽입, B군=기존(말미 CTA). 톤·주제·발행시간 동일 조건.
- 기간: 2주.

## 성공 기준
- A군의 문의 페이지 클릭률이 B군 대비 유의하게 ↑ (목표 +20% 이상).

## 리스크·제약
- 브랜드 톤(절제된 고급감) 훼손 주의 → CTA는 **1줄·간결**, 과한 판매 어조 금지.
- 모든 발행은 **M5 검수 대기 → GM 승인** 경유(개인계정/회사계정 톤 규칙 준수). 실험도 예외 없음.

## 진행 (GM 승인 시)
1. 시모가 콘텐츠 캘린더에 A/B 안 반영 → M5 검수 → GM 승인 → 발행.
2. 2주 후 [기간] 조회로 결과 집계 → 대시보드 '개선 실험 로그'에 기록 → **웰리 보고 → GM 판단**.
3. 승리안을 전 채널 캡션 표준에 반영(채널별 CTA 표준과 정합).
