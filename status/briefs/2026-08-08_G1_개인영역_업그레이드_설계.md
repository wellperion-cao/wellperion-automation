## 2. 핵심 진단 (3줄)

1. **살아 있는 장치(루틴 트래커)가 5월 이틀 기록 후 죽었다** — 칸이 없어서가 아니라 4겹 아래 묻혀 있고, 열어도 나를 반기는 것이 없어서다.
2. **손으로 채우는 칸은 전부 비었거나 멈췄고, 자동으로 채워지는 칸은 0개다** — 북극성 카드는 이미 있는 문장을 두고 "비어 있습니다"라고 말한다.
3. **회사 것(로드맵 메모·세션 로그)이 개인 영역에 섞여** "내 삶의 화면"이라는 정체성이 없다.

## 4. 상단 히어로 — "오늘 하루 한 장"

잠금 풀면 바로 보이는 카드 하나. 전부 기존 데이터 자동 + 탭 몇 번.

| 줄 | 내용 | 채워지는 방식 |
|---|---|---|
| ① | 오늘 날짜·요일 + **북극성 문장 한 줄** | 자동 (`gm_personal_routine.json`) |
| ② | **이어가는 날들** — "금연 439일째 · 절주 220일째 · 가계부 465일째" | 자동 계산 (기존 습관 표의 시작일에서) |
| ③ | 오늘 일정 (개인 캘린더에서 오늘 것만) | 자동 (기존 브라우저 저장 데이터) |
| ④ | 5토막 체크 (나🌱 아빠👨‍👧 남편💑 일💼 단순함⚖️) — 탭해서 켬 | 하루 10초 기록 (아래 5번) |
| ⑤ | 최근 7일 막대 + 기분 이모지 줄 | 자동 (쌓인 기록) |

**왜 이것인가:** GM 프로필 실측 — GM은 "화면에서 본 신호에서 일을 시작"하고, "보이는 것의 진위"를 중시한다(표면 점검 22회). 아침에 열 이유는 회사 숫자가 아니라(그건 자율현황) **"어제의 나가 오늘의 나에게 남긴 것"**이 반겨줄 때 생긴다. 특히 ②줄은 손 하나 안 대고 매일 저절로 커지는 자랑 숫자 — 열 때마다 어제보다 1 크다. 이것이 "행복하고 즐겁게"의 가장 싼 구현이다.

## 5. 하루 10초 기록 방식

**새 입력칸을 만들지 않는다. 기존 체크인 그대로 쓰되 두 가지만 바꾼다.**

1. **위치** — 체크인을 4겹 아래에서 히어로로 올린다. 열자마자 탭할 수 있게. (10초의 적은 칸이 아니라 이동 경로였다)
2. **기분 한 탭** — 기존 루틴축과 같은 순환 단추 방식으로 "오늘 기분" 한 칸: 😊 좋음 → 🙂 무난 → 😞 힘듦 순환. 저장은 기존 저장 단추·기존 정본 파일 그대로(`days` 안에 기분 값 하나 추가). 글자 입력 없음 — 탭 1번이 끝.

하루 최소 동작 = **기분 1탭 + 토막 몇 탭 + 저장 1탭** ≈ 10초. 비고 한 줄은 지금처럼 선택사항으로 남긴다(강요 없음). 쌓이면 히어로 ⑤줄에서 요일 막대 아래 기분 이모지가 나란히 보인다 — 이것이 "행복을 측정 가능하게"의 전부다. 감정 일기·새 장치 없음.

## 6. 자동으로 채울 수 있는 칸 (데이터 출처)

| 칸 | 출처 | 비고 |
|---|---|---|
| 북극성 문장 | `status/gm_personal_routine.json` → "북극성" 값 | 이미 있음 — 카드가 안 읽고 있을 뿐 |
| 습관 지속일수 (금연 N일째 등) | G1 안 습관 표의 시작일 5개 (금연 2025.6.27 등) | 오늘 날짜 빼기만 하면 됨 — 매일 자동 증가 |
| 오늘 일정 | 브라우저 저장 `gm1_unified_tasks` (할 일·캘린더 공용) | 이미 페이지가 읽는 데이터 — 히어로에 오늘 것만 거르기 |
| 주간 도달 추세·최근 기록 | `status/gm_personal_routine.json` → `days` | 이미 렌더 중 — 위로 올리기만 |
| 체중·수면 추세 | 같은 파일 `days`의 체중·수면 값 | 기록이 다시 쌓이면 저절로 그래프가 됨 |
| 건강 점검 다음 일정 | 습관 표 옆 점검 표(인바디 3·6·9·12월 1일) | 반복 일정으로 캘린더에 자동 표출 가능 |

손으로 새로 쓰는 칸 추가 = **0개**. 추가되는 입력은 기분 1탭뿐(요청된 측정 기능).

## 7. 먼저 할 것 3개 (순서대로)

1. **히어로 카드 이동** — 루틴 트래커(게이지+체크인)를 개인 영역 4겹에서 꺼내 G1 최상단으로. 북극성 문장 자동 표시 + 습관 지속일수 자동 줄 + 오늘 일정 줄 포함. (죽은 트래커를 살리는 최소 수술)
2. **죽은 것·회사 것 정리** — 세션 로그·개인 메모 로드맵·낡은 사용법 삭제, 습관 표·건강 점검 표·삶의 헌장을 3번 표대로 흡수. (지우기 전에 브라우저 메모 백업 여부만 GM께 한 번 확인)
3. **기분 한 탭 추가** — 기존 체크인에 순환 단추 1칸, 정본 파일 같은 자리에 저장, 주간 추세에 이모지 줄 표시.
