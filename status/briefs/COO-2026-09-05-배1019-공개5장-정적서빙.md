## 함정 1건 — 상대경로 CSS 링크

조각은 자기 위치(`coo|cmo/.../` 2단 깊이) 기준 `../../assets/wp-typography.css` 로 CSS 를 가리킨다.
산출물 경로(`public/ko|en/*.html`)도 우연히 2단 깊이라 문자열은 같지만, 실서비스 URL(`/ko/reception` 등)은
1단 깊이라 `../../` 가 사이트 루트를 뚫고 나가 404 (로컬 http.server 실측으로 확인). 빌드 스크립트가
산출물에서만 그 한 줄을 `/assets/wp-typography.css` 절대경로로 고쳐 내고, CSS 파일도 `public/assets/`
에 같이 복사해 낸다(조각 원문은 손대지 않음). nginx 초안에 `location ^~ /assets/` 를 추가해 대응.
