## 5-1. L2 클라이언트 — AWS Bedrock (계정 cao 통일) · 라이브 켜짐

`_anthropic_client()`는 **Bedrock(EC2 IAM 역할 · 키 0) → 1P(`ANTHROPIC_API_KEY` 있으면 대안) → None(백업)** 순으로 시도한다. 3중 가드: ①테넌트당 하루 질문 300건 넘으면 백업 자동 전환(`_over_daily_limit`) ②모델 오류 시 백업+`unanswered` 기록 ③AWS 예산 알람은 콘솔에서(코드는 일일 카운터만).

**경위(클래스 2번 교체)**:
1. 처음 쓴 `AnthropicBedrockMantle`은 오진 — `bedrock-mantle.{region}.api.aws` 도메인 자체가 DNS 에 없는(NXDOMAIN) 존재하지 않는 제품이었다(시보 지적).
2. 표준 `AnthropicBedrock`(`from anthropic import AnthropicBedrock`)으로 교체 → 정상적으로 `bedrock-runtime.ap-northeast-2.amazonaws.com`까지 붙었으나, 모델 `global.anthropic.claude-sonnet-5`는 이 계정(신규·프리 플랜)에서 **"not available for this account"**(AWS 영업 승인 필요) — boto3 `invoke_model` 직접 호출로 확인.
3. **claude-sonnet-4-6로 교체**(계약 완료·즉시 호출 가능) — `COUNSEL_MODEL` 코드 기본값 + 서버 `api.env` 둘 다 `global.anthropic.claude-sonnet-4-6`로 맞춤. **주 엔진이 라이브로 켜졌다.**
