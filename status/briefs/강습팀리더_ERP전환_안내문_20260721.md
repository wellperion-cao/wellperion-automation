📢 **강습 회원 관리 방식 변경 안내**

안녕하세요, 강습 팀 리더님들 🙌
그동안 팀별 시트로 강습 문의·회원을 관리해 주셔서 감사합니다.

그동안 **팀 시트 ↔ 통합 시트 자동 연동이 자주 끊겨** 숫자가 어긋나는 일이 있었습니다.
이 문제를 없애기 위해, 이제부터 강습 회원 관리를 **한 곳 — 웰페리온 ERP ‘강습 회원관리’ 페이지 — 에서** 진행합니다.

**✅ 오늘부터 바뀌는 점**
· 팀별 시트 입력은 **중단**합니다 (더 이상 시트에 적지 않으셔도 됩니다)
· 모든 강습 **문의 확인 · 담당 배정 · 상담 진행 · 등록/미등록 기록**은 아래 ERP 페이지에서 합니다

**🔗 접속 방법**
· 주소: https://wellperion-cao.github.io/wellperion-automation/cpo/member/membership.html?manage=lesson
· 입장 코드: **1200**
· 휴대폰·PC 모두 됩니다. 즐겨찾기 해두시면 편합니다 📌

**📝 페이지에서 하실 일**
1. **본인 담당(강사 이름)으로 걸러 보기** — 내 담당 회원만 모아 볼 수 있습니다
2. **새 문의 확인 → 담당 배정**
3. **상담 진행상태 업데이트** (컨택중 → 가망 → 등록 / 미등록)
4. 상담 내용은 **‘Contact’ 칸에 기록**
5. **등록**한 경우: 등록 종목·회수를 고르면 **유효기간이 자동 계산**됩니다 / **미등록**인 경우: 사유를 선택

**💡 좋은 점**
· 한 곳에서 **실시간**으로 봅니다 — 시트 연동이 끊길 일이 없습니다
· 팀 리더님과 본사가 **같은 화면**을 봅니다

**❓ 도움이 필요하시면**
사용 중 궁금한 점은 〔운영팀 / GM 연락처〕로 편하게 연락 주세요. 처음 한 번만 익히시면 훨씬 편하실 거예요 😊

감사합니다.
