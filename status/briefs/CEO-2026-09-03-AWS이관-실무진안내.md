# AWS 이관 — 실무진 안내 체계 (배 11215)

작성 AI 웰리 · 2026-09-03 최초 · 2026-09-05 v2(순서·담당 반영) · 발송 관문 `kakao_report_sender` (초안 → GM 승인 → 발송)

전환 실행은 시토 배 11299(短 1039) 가 맡는다. 이 문서는 **사람 쪽 안내**만 다룬다.
전환 순서(시토 배1039 확정) = ①회원(+시포 8건) → ②시우 화면 28장 → ③시모 자동화 7개 → ④매출·지출 원장(나우열M) → ⑤GAS 축소. 각 묶음 전환일이 정해지면 이 표에 먼저 적고, 그다음 D-1 안내가 나간다 — 날짜가 정해지기 전에는 보내지 않는다.

**전 화면 공통으로 바뀌는 것 두 가지**

1. **주소** — 기존 주소도 당분간 그대로 열린다. 새 주소는 `erp.wellperion.com`.
2. **로그인** — 화면마다 비밀번호를 넣던 것이 없어진다. **회사 구글 계정으로 한 번 로그인하면 그날은 모든 화면이 그냥 열린다.**

## 2. 카톡 3통 초안 — 모듈 묶음별 템플릿

발송 방은 **묶음마다 다르다** (GM 확정 2026-08-18) — §3 참고. 형식 규칙 = `wellperion-gm-report` §4-2-2(3줄·10줄 안·빈 줄 없음·쿼리 없는 주소·[AI 웰리] 머리·「N일째」·SSOT·배번호 금지).

아래는 **1번째 묶음(회원 관리 — 멤버십·강습)** 문안이다. 다음 묶음(운영부 화면 28장 → 문의·콘텐츠 자동화 → 매출·지출 원장)은 모듈 이름·링크·날짜만 바꿔 쓴다.

아래 3통은 **멤버십**(임정은M·이경연 실장) 대상 — 발송 방: ★중간관리자 + ★운영부. **강습**(파트너팀) 대상은 화면 이름·주소만 `.../cpo/member/lesson.html` 로 바꾸고 발송 방을 ★부서장으로 바꿔 별도로 보낸다.

### ① 전환 하루 전 (D-1)

```
[AI 웰리] 회원 관리 화면(멤버십·강습)이 서버로 옮겨집니다 — MM/DD(요일)
1️⃣ 하시는 일은 그대로입니다
   등록·상태 변경·LOSS 처리·화면·칸 전부 같습니다
2️⃣ 바뀌는 것은 로그인 한 가지
   주소가 erp.wellperion.com 으로 바뀌고 회사 구글 계정으로 한 번 로그인하시면 됩니다
3️⃣ 옮기는 동안 MM/DD 오전 O시~O시 잠깐 멈춥니다
   그 시간에 저장하신 건은 옮긴 뒤 그대로 남아 있습니다
👉 준비하실 것은 없습니다. 회사 구글 계정 비밀번호만 알고 계시면 됩니다
```

### ② 전환 당일 (완료 직후)

```
[AI 웰리] 회원 관리 화면 이전이 끝났습니다
1️⃣ 지금부터 새 주소로 열립니다
   erp.wellperion.com/cpo/member/membership.html — 기존 주소로 들어오셔도 그대로 연결됩니다
2️⃣ 처음 여실 때 구글 로그인 한 번
   회사 계정(@wellperion.com)으로 들어가시면 그다음부터는 바로 열립니다
3️⃣ 확인 한 가지만 부탁드립니다
   회원 한 분 조회해 보시고 정보가 그대로 나오는지만 봐 주십시오
👉 안 되는 게 있으면 ★중간관리자 방에 그대로 적어 주시면 바로 봅니다
```

### ③ 다음 날 (D+1)

```
[AI 웰리] 어제 옮긴 회원 관리 화면 — 불편하신 것 있으셨습니까
1️⃣ 어제 하루 등록·상태 변경 정상 처리됐습니다
2️⃣ 강습 배정·조회도 그대로 되고 있습니다
   저장되는 곳만 회사 서버로 바뀌었습니다
👉 느리거나 안 열리거나 이상한 게 있으면 ★중간관리자 방에 적어 주십시오. 오늘 중 봅니다
```

## 3. 지키는 것

- **손대는 것은 안 바뀐다고 먼저 말한다.** 바뀌는 건 뒤(서버)뿐이다.
- **연락처는 한 곳** — 묶음마다 지정된 방 하나. "안 되면 예전 링크로" 같은 이중 안내를 하지 않는다.
- **날짜가 정해지기 전에는 보내지 않는다.** 시토가 모듈 전환일을 잡으면 이 문서 표에 먼저 적고, 그다음 D-1 안내가 나간다.
- 카톡 한 통 10줄 안 · 빈 줄 없음 · [AI 웰리] 머리 (전달문 규칙 = `wellperion-gm-report` §4-2-2).
- 모듈별 표의 빈 칸은 담당이 채운다 — 운영 4부서 = 시우 · 회원 = 시포 · 문의·콘텐츠 = 시모.
- **발송 방 배분 (GM 확정 2026-08-18)** — 회원 = ★중간관리자 + ★운영부 / 점검·업무결재 = ★운영+시설+지원+주차 / 강습 = ★부서장. 콘텐츠 접수·문의 폼 선택지 확대는 방문자·강사진 대상이라 이 실무진 카톡 묶음에 넣지 않는다.
