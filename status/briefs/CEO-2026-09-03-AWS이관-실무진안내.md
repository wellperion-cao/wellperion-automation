작성 AI 웰리 · 2026-09-03 · 발송 관문 `kakao_report_sender` (초안 → GM 승인 → 발송)

전환 실행은 시토 배 11182·11220 이 맡는다. 이 문서는 **사람 쪽 안내**만 다룬다.
전환 날짜는 시토가 모듈별로 정하는 대로 이 표에 채워 넣는다 — 날짜가 정해지기 전에는 안내를 보내지 않는다.

**전 화면 공통으로 바뀌는 것 두 가지**

1. **주소** — 기존 주소도 당분간 그대로 열린다. 새 주소는 `erp.wellperion.com`.
2. **로그인** — 화면마다 비밀번호를 넣던 것이 없어진다. **회사 구글 계정으로 한 번 로그인하면 그날은 모든 화면이 그냥 열린다.**

## 2. 카톡 3통 초안

발송 방 = ★중간관리자 · ★부서장 · 4부서방 (공지 3방 기준).
아래는 **1호(종합접수처)** 문안이다. 다음 모듈은 모듈 이름과 날짜만 바꿔 쓴다.

### ① 전환 하루 전 (D-1)

```
[웰페리온 ERP] 접수 화면이 회사 서버로 옮겨집니다 — MM/DD(요일)

1️⃣ 하시는 일은 그대로입니다
   접수 주소·QR·화면·적는 칸 전부 같습니다.
2️⃣ 바뀌는 것은 로그인 한 가지
   비밀번호 대신 회사 구글 계정으로 한 번 로그인하시면 됩니다.
3️⃣ 옮기는 동안 MM/DD 오전 O시~O시 잠깐 멈춥니다
   그 시간에 들어온 건은 옮긴 뒤 그대로 남아 있습니다.
👉 준비하실 것은 없습니다. 회사 구글 계정 비밀번호만 알고 계시면 됩니다.
```

### ② 전환 당일 (완료 직후)

```
[웰페리온 ERP] 접수 화면 이전이 끝났습니다

1️⃣ 지금부터 새 주소로 열립니다
   erp.wellperion.com — 기존 주소로 들어오셔도 그대로 연결됩니다.
2️⃣ 처음 여실 때 구글 로그인 한 번
   회사 계정(@wellperion.com)으로 들어가시면 그다음부터는 바로 열립니다.
3️⃣ 확인 한 가지만 부탁드립니다
   접수 한 건 넣어 보시고 목록에 뜨는지만 봐 주십시오.
👉 안 되는 게 있으면 이 방에 그대로 적어 주시면 바로 봅니다.
```

### ③ 다음 날 (D+1)

```
[웰페리온 ERP] 어제 옮긴 접수 화면 — 불편하신 것 있으셨습니까

1️⃣ 어제 하루 접수 N건 정상 처리됐습니다
2️⃣ 사진도 그대로 올라가고 있습니다
   저장되는 곳만 회사 서버로 바뀌었습니다.
👉 느리거나 안 열리거나 이상한 게 있으면 이 방에 적어 주십시오. 오늘 중 봅니다.
```

## 3. 지키는 것

- **손대는 것은 안 바뀐다고 먼저 말한다.** 바뀌는 건 뒤(서버)뿐이다.
- **연락처는 한 곳** — ★중간관리자 방. "안 되면 예전 링크로" 같은 이중 안내를 하지 않는다.
- **날짜가 정해지기 전에는 보내지 않는다.** 시토가 모듈 전환일을 잡으면 이 문서 표에 먼저 적고, 그다음 D-1 안내가 나간다.
- 카톡 한 통 10줄 안 · 빈 줄 없음 (전달문 규칙 = `wellperion-gm-report` §4-2-2).
- 모듈별 표의 빈 칸은 담당이 채운다 — 운영 4부서 = 시우 · 회원 = 시포 · 문의 = 시모.
