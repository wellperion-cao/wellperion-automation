### 화면 로드 완료 판정 기준

| 선택자 | 의미 |
|---|---|
| `.audit.ok` | 서버 API 22칸 대조 정상 완료 |
| `.audit.bad` | 이상 → 실패 처리 후 기존 시트판 폴백 |
| `.audit.wait` | API 미응답 → 최대 15초 대기 |
