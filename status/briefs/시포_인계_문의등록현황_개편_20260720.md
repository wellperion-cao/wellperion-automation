## 2. ❌ 시우가 손대지 않은 것 = 시포 몫

전부 **CPO 백엔드(Survey.js·GAS)** 영역이라 의도적으로 남겼습니다.

### ★ 최우선 — 서버 집계 엔드포인트 신설 (`inquiry_stats`)

**이게 8할입니다.** 지금 화면이 느린 근본 원인은 **집계 기능이 없어서 원본 행을 통째로 끌어오는 것**입니다.

| 실측 | 값 |
|---|---|
| 멤버십 문의 | **632건 / 584KB** 전량 fetch |
| 강습 | 682KB |
| 가입 명단 | 1,695건 전량 |
| `member_active_list` | **콜드 GAS ~11초** (코드 주석이 자인) |

→ `inquiry_stats{from,to}` 같은 액션을 만들어 **집계값만** 반환하게 하면, 응답이 건수와 무관하게 작아집니다.
**참고 모델:** `cpo/member/renewal.html` — 서버가 월별 집계본만 주기 때문에 응답이 **약 4KB 고정**입니다. GM이 "잘 만들었다"고 한 이유가 이것입니다.

## 3. renewal.html 에서 더 가져올 것

시우가 이식한 것은 "탭 전환 무재조회" 하나입니다. 남은 좋은 패턴:

| 패턴 | 효과 |
|---|---|
| **3층 즉시 렌더** | localStorage → 파일 내 SNAPSHOT 상수 → 라이브. **네트워크 0회로도 첫 화면이 뜬다** |
| 12초 타임아웃 + 재시도 버튼 | 느린 GAS에 특히 유효 |
| 차트 `destroy()` 선행 | 메모리 누수 방지 |

## 4. 주의사항 (실제 사고 이력)

- **값을 복사하지 마라.** 오늘 시설부 점검 기준값이 3곳에 갈라져 "매번 이상건" 사고가 났다.
- **저장 성공을 확인하고 성공이라 표시하라.** 이 저장소엔 저장 실패를 성공처럼 표시한 사고가 3건(INC-011·INC-013 + 오늘 발견한 O2 종합접수처 처리자).
- **`USE_GVIZ` 재활성 금지.** gviz 행번호 어긋남으로 예약·편집이 사라진 사고(INC-013). 성능은 서버 집계로 풀어라.
- **커밋 경합 주의.** 여러 세션이 동시에 커밋한다. `git add` 후 **실제로 스테이지됐는지 확인하고** 커밋할 것 — 오늘 시우가 두 번 헛커밋했다.
