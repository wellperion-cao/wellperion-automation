## 2. 서버 주소 (화면이 실제로 부르는 것 — 참고용, 배선은 이미 끝남)

```
GET  https://erp.wellperion.com/api/funnel?action=funnel_conversion
GET  https://erp.wellperion.com/api/funnel?action=funnel_conversion_detail
GET  https://erp.wellperion.com/api/funnel?action=lesson_breakdown
GET  https://erp.wellperion.com/api/funnel?action=period_breakdown&from=YYYY-MM-DD&to=YYYY-MM-DD
```

서버 = `server/erp_api/api_funnel.py`(캐시 응답) + `server/erp_api/sync_funnel.py`(5분 cron 동기화) — 캐시에 없는 범위만 그 자리에서 GAS 1회.
