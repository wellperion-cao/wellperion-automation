## 4. 배정 푸시 설계안 (제안만 · 미발송)

**기존 인프라 재확인** — `scripts/unassigned_nudge.py`(배9206, 2026-07-23)가 이미 "미배정 배정 독려" 목적으로 존재한다. 오래 기다린 순 상위 N건을 종목별로 묶어 **기존 문의알림방**(`TELEGRAM_INQUIRY_CHAT_ID`, 새 채널 아님)에 "AI 시포" 서명으로 보내는 구조가 이미 갖춰져 있다 — 이번 설계는 이 모듈을 **개선하는 형태**로 흡수한다(새 채널 신설 없음).

**발견한 갭 2가지**(설계 반영 대상, 이번 회차엔 코드 미수정):
1. `unassigned_nudge.py`의 `STALE_MAX_DAYS=30` 상한 — 오늘 산출한 최우선 건(80~204일)이 **전부 이 30일 상한 밖**이라 지금 로직으로는 절대 안내되지 않는다. `report_stream_1_impl.py`의 일일보고 stale 섹션도 동일하게 30일 상한(`3 <= d <= 30`).
2. 정렬 기준이 순수 경과일 내림차순 — 종목별 비중(건수)·연락이력을 반영하지 못해 성인 수영처럼 절대량이 큰 종목이 묻힐 수 있다.

**제안**:
- 30일 상한을 없애거나, "3~30일 정상 독려" + "31일 이상 장기방치(별도 섹션, 어조를 압박이 아니라 확인 요청으로 조정)" 2단 구성으로 확장.
- 정렬을 위 §1 종목 점수(건수×경과일×연락이력) 기반으로 교체 — 지금 오래 기다린 순 로직 위에 종목 가중만 얹으면 됨(새 채널·새 수신자 없음).
- 100일 초과 건은 곧바로 "배정 요청"에 넣지 않고 §5 유효성 확인 절차를 먼저 거치게 분리.
- 발송 경로·문안 톤(AI 시포 서명, 셋업 어조, 입장코드 동봉)은 기존 그대로 유지.
- 실제 코드 반영·발송은 GM 승인 후 별도 회차에서 진행.

## 5. 100일 초과 건 — 유효성 판단 기준 (제안만, 정리·폐기 안 함)

임의로 정리하지 않는다. 대신 배정 전에 아래 기준으로 "아직 유효한 문의인지" 먼저 걸러보자는 **제안**:
- **연락이력 0건 + 100일 초과 + 상태가 신규/미정에 준함** → "장기 미접촉" 후보. 폐기 아님 — 팀장 확인 후 재접촉 시도 여부 결정.
- **연락이력이 있고 마지막 컨택이 비교적 최근**(예: 최근 30일 내 기록) → owner만 비어 있을 뿐 실제로는 진행 중일 가능성 높음 → **우선 배정** 대상으로 유지(폐기 후보 아님). §2 표의 성인 필라테스·성인 골프 건이 이 경우.
- **시즌성 프로그램**(여름특강 등) 문의가 시즌이 지나 오래된 경우 → 유효성 자체가 다른 기준(시즌 재개 여부)일 수 있음 — 이번 데이터로는 구분 불가, 담당 팀장 확인 필요.
- 이 기준은 **제안일 뿐**이며 최종 판단(폐기·보류·배정)은 GM.
