# S2 본문 vs ssot 중복률 실측 (2026-07-24)

> GM 지적("탭 접기는 순간방편, 근본 원인 해결 아닌 것 같다")에 대한 **측정 전용** 응답. 고치지 않았고 삭제 제안도 하지 않았다 — 아래는 실측 결과만이다.

## 1. 대조 기준 (분류 4종 + 측정 방법)

| 분류 | 정의 |
|---|---|
| **[중복]** | ssot 5개 파일(약속.json·CONSTITUTION.md·kpi.json·canon_values.json·incidents.json) 중 하나와 **문장·표현이 사실상 동일**하게 겹치는 블록 |
| **[렌더]** | `<script>`가 ssot를 fetch해 `innerHTML`로 채우는 **골격**(라벨·빈 슬롯) — 실제 콘텐츠는 파일에 하드코딩돼 있지 않음 |
| **[고유]** | ssot 어디에도 없는, S2에만 있는 콘텐츠 |
| **[AI전용]** | GM이 볼 필요 없는 Claude CLI 복붙용 프롬프트 |
| **[판정보류]** | ssot 항목과 "정신은 겹치나" 표현·범위가 달라 중복이라 단정하면 억지인 것 |

**측정 방법:** S2를 공통탭+역할탭7개(총 8개 `data-panel`)로 분해 → 각 탭에서 `<script>`(JS 렌더 코드)·`<!-- -->`(주석)를 제거한 **순수 텍스트**만 카운트 → 블록 단위로 위 5종 판정 → ssot 5개 파일 원문과 대조(약속.json 21개 항목 전체 재확인 포함).

## 2. 한 줄 총평

**S2 본문이 ssot를 문자 그대로 베낀 비율은 낮다 (전체 텍스트 38,567자 중 약 800자, 약 2.1%).** 그런데 GM이 느낀 "중복감"의 실체는 ssot 복제가 아니라 **S2가 자기 자신을 반복**하는 것(공통탭 요약↔본문, 탭↔탭)과, **ssot에 없는 회사 규칙이 S2 HTML 안에만 박혀있는 것**(8건)이다. 즉 "탭 접기"는 이 두 문제 중 어느 것도 건드리지 못했다 — 눈에 안 보이게 접었을 뿐 자기중복도, 근거 없는 규칙도 그대로 남아있다.

## 4. 전체 합계 및 "지우면 없어지는 양"

| 항목 | 글자수 | 비율(38,567자 대비) |

| **[중복]** (ssot 그대로 지워도 되는 것) | 800 | 2.1% |
| **[AI전용]** (GM 화면엔 필요 없는 것) | 3,859 | 10.0% |
| **[중복]+[AI전용] = 지우면 없어지는 양** | **4,659** | **12.1%** |

**즉 S2를 통째로 지워도 사라지는 ssot 중복분은 2.1%뿐이다.** "탭 접기"가 순간방편이었던 진짜 이유는 이 2.1%를 못 줄여서가 아니라, 아래 §6·§7의 두 구조 문제를 안 건드렸기 때문이다.

## 6. [고유]로 남는 것 — S2의 진짜 존재 이유

- **전 C-Level 통합 원칙 10테마**(공통탭, 3,791자) — 보고·자율·데이터위생·검증·고도화·효율·파이프라인·보안·토큰라우팅·박제원리. ssot 어디에도 없는 40여 개 세부 운영규칙. CLAUDE.md가 이 블록을 "정본=S2"로 명시 지목·역참조하는 구조 — 여기가 진짜 정본.
- **역할탭 7개의 핵심업무·협업리듬·Do/Don't·역할원칙**(CEO·COO·CFO·CMO·CTO·CHRO·CPO 전체) — 역할별 실무 판단기준·리듬은 ssot 4개 JSON 스키마에 아예 없는 영역. COO·CTO는 "공통 원칙은 공통탭이 원본, 여기선 참조만"이라고 명시하며 실제로 안 베끼는 **모범 포인터 설계**.
- **CMO 콘텐츠허브모듈·승인프로세스·마케팅 파이프라인(5단계)·발행루프(6단계)** — CMO 도메인 지식, ssot 미수록.
- **CFO 지출 승인 한도표**(0원/1원이상/긴급지출 3단계) — 결재선 정의, ssot 미수록.
- **웰리 운영 헌법 STEP 0~4**(CEO탭) — CEO 전용 SOP, `ssot/CONSTITUTION.md`와 이름만 같은 별개 문서임을 스스로 명시.

## 7. 규칙인데 화면(S2)에만 있는 것 — 헌법 위반 후보 8건

## 8. 판정보류 (억지분류 안 한 것)

**약 690자 (전체의 1.8%)** — 아래는 약속.json 항목과 "정신은 겹치나" 표현·구체성이 달라 [중복]으로 단정하지 않았다:
- 공통탭 "보고 표형식 의무"의 "일상어 의무" 행 ↔ L10·L17 (같은 취지, 다른 표현·다른 세부항목)
- 공통탭 통합원칙①의 "GM 채널 일상어"·"GM 호칭" 행 ↔ L10 (같은 취지, 더 세분화된 규칙)
- 공통탭 통합원칙④ "짧은 반려 검증" 행 ↔ L03 (같은 취지, 다른 적용 시나리오)
- 공통탭 "일의 브릿지" 도입부 1~2문장 ↔ L11 (L11은 1줄 원칙, 브릿지는 그걸 절차로 확장한 것 — 확장인지 중복인지 애매)

## 9. 삭제 시 위험 플래그 (참고용 — 삭제 제안 아님)

- Top #2 "AI 조직도 카드"는 [중복]이지만 **고정 스냅샷이라 kpi.json이 바뀌면 이 카드만 옛값으로 남는 drift 위험**이 있다는 점은 기록해둔다(삭제·수정 제안은 이번 범위 밖).
- §7의 8건은 [고유]로 분류했지만 **삭제하면 안 된다** — ssot에 없다는 것이 "지워도 된다"는 뜻이 아니라 "코드가 참조하는 근거가 HTML 하나뿐"이라는 뜻(특히 #1 완료4요건).
