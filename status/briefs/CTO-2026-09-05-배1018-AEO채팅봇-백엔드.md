## 지어내기 차단 (코드로)

모델 호출 없음. 질문↔FAQ 질문을 한글 2-gram(글자 바이그램) overlap coefficient 로 매칭 — 임계값(0.45) 이상이면 그 FAQ 의 답 + `faq_id`, 미만이면 고정 문구("정확한 안내를 위해 상담 예약을 도와드릴게요" + `meta.reservation_url`). 금지어(금액·의료) 가 질문에 있으면 매칭 자체를 건너뛰고 바로 고정 문구.

금지어 관문 = `scripts/diet_camp_agent.py` 의 `FORBIDDEN`(돈·계약 단어) 그대로 재사용 — 이 파일을 서버 `/srv/erp/api/`에도 같이 올렸다(다캠 에이전트는 GM PC 전용 스크립트지만 이 상수는 stdlib 만으로 끝나 파일 하나만 옮기면 됐다). 의료 단어는 다캠 에이전트에 없어 `server/erp_api/api_chat.py`의 `MEDICAL_WORDS`에 최소로 새로 뒀다(진단·처방·치료·질환·질병·의약·부작용·수술·임신·약물·합병증).

## 저장

- FAQ = `/srv/erp/faq/{tenant}/faq.json` — `{"meta":{"reservation_url":"..."},"faq":[{"id","q","a"}...]}`.
  `/srv/www` 가 아니라 `/srv/erp/faq`에 둔 이유: `/srv/www/1_wellperion`은 서버의 git 저장소 체크아웃(`/srv/erp/repo`)을 가리키는 심볼릭 링크라, 그 안에 파일을 쓰면 서버 쪽 git 워처와 충돌한다(약속: 임시인덱스·동시커밋 손상 전례). FAQ는 그 트리 밖 전용 폴더에 둔다.
  - `1_wellperion`: 라이브 홈 JSON-LD FAQPage(배1000·`scripts/wp_geo_apply.py`) 14문답 그대로 시딩.
  - `2_dietcamp`: 아직 CBO가 채운 FAQ 초안이 없어 빈 목록 + `meta.reservation_url` 도 빈 값. **CBO 가 채워야 할 것**.
  - 배포 스크립트는 파일이 이미 있으면 안 건드린다(이미 채운 내용 보호).
- 로그 = `/srv/erp/chat_log.jsonl` 한 줄(`ts`·`tenant`·`q`·`answered`·`faq_id`) — 이름·전화 저장 안 함. 실측 확인:
  ```
  {"ts":"2026-09-05T14:45:08","tenant":"1_wellperion","q":"운영 시간은 어떻게 되나요","answered":true,"faq_id":"f04"}
  ```

## 매칭 수리 실측 (2026-09-05, 배1018 후속)

실사고: 「주차 되나요」가 정원제 멤버십 FAQ(f02)에 `answered:true`로 오답 매칭됐다. 어미 "되나요"만 겹쳐 임계(0.45)를 넘긴 것 — 지어내기와 같은 사고다.

수리: `_best_match` 전에 `_normalize_q`로 조사·어미·물음 표현(되나요·인가요·있나요·하나요·어떻게·얼마·는지·가요·나요·까·요·습니까) 제거 → 정규화 길이 2자 이하면 무조건 미매칭, 아니면 정규화 2-gram 교집합 2개 이상 AND 비율 0.5 이상만 매칭 후보로 인정(`MATCH_THRESHOLD` 0.45→0.5).

로컬 `python server/erp_api/api_chat.py` selfcheck에 실제 FAQ(1_wellperion 14문답) 기반 6문장 추가 — 전부 통과.
