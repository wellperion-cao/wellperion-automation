# [작업지시] 종합접수처 습득물 접수에 '보관위치' 칸 추가

> 전달: GM → 준용M · 정리: 시토(2026-07-22) · 대상 = **직원 습득물(LF) 접수** (회원 분실물 폼 아님)

## 한 줄 요약
습득물(주운 물건) 접수 때 **습득장소·물품설명은 이미 있고, '보관위치' 하나만** 폼·시트·알림에서 빠져 있습니다. `keepLoc` 필드 하나를 아래 4곳에 추가하면 끝입니다.

## 왜 (배경)
- GM 요청: 습득물 접수 시 [습득장소 / 설명 / **보관위치**] 를 받아야 함.
- 현재: 습득장소(`foundLoc`)·설명(`itemDesc`)은 구현돼 있음. 보관위치만 전 계층 누락 → 물건을 "어디서 찾아주는지"가 기록 안 됨.

## 어디를 (4곳 — 모두 `keepLoc`로 통일)

| # | 계층 | 파일 | 위치 | 할 일 |
|---|---|---|---|---|
| 1 | 습득물 등록 페이지 | `3. 웰페리온 가이드/coo/reception/lost_found_register.html` | 습득장소 입력칸(`foundLoc`, 약 160~163행) 바로 아래 | **보관위치 입력칸 신설** + payload 조립(약 240~242행)에 `keepLoc` 키 추가 |
| 2 | WP 주입 쌍둥이 | `3. 웰페리온 가이드/coo/reception/wp_lost_found_register_block.html` | 위와 동일 위치 | **동일하게** 입력칸 + payload에 `keepLoc` 추가 (두 본이 같아야 함) |
| 3 | GAS 저장 핸들러 | `3. 웰페리온 가이드/coo/voc/apps_script_voc.js` | `_lfSubmit` (약 1184~1222행), `foundLoc` 읽는 곳(약 1186행) 근처 | `body.keepLoc`를 읽어 `_set('keepLoc', body.keepLoc)` 저장 라인 추가 |
| 4 | 시트 열 | 같은 파일 `LF_HEADERS` (약 1041~1062행) | **배열 맨 끝에 append** | `{key:'keepLoc', label:'보관위치'}` — ★반드시 맨 끝(중간 삽입 금지: `_lfIdx_` 위치기반 쓰기라 기존 행이 밀림) |

### (시토 지정) 텔레그램 알림 라인 — 같은 GAS 편집에 함께
- `_lfSubmit` 알림 문자열(약 1213~1220행, "습득장소·설명·등록직원" 표시부)에 **`'보관위치: ' + (keepLoc||'-')` 한 줄 추가**.
- 이 한 줄은 알림(시토 소관)이지만 같은 파일·같은 배포라 이 작업에 함께 넣습니다.

## 입력칸 형태 (권장)
- **드롭다운(select) 권장** — 자유 텍스트보다 정리됨. 예시 항목: `헬스 리셉션 서랍` / `수영장 데스크` / `프론트 금고` / `락커 보관함` / `기타(직접입력)`.
- 습득장소(`foundLoc`)가 select면 같은 패턴 그대로 복사해서 만들면 됩니다.
- **필수 권장**: 회수 실무상 "어디서 찾아주는지"가 핵심이라 필수값 권장(습득장소/설명은 현재 '둘 중 하나' 필수 규칙 — 보관위치는 별도 필수 권장).
- 고가·귀중품(`category=valuable`) 선택 시 기본값을 "프론트 금고"로 안내하면 좋음(선택).

## 배포 (GAS 웹앱)
- 위 GAS(`apps_script_voc.js`)는 코드만 고치면 라이브 반영 안 됨 — **`/exec` 새 버전 재배포** 필요.
- 저장소 규율: `scripts/gas_deploy_guard.py` 경유(`docs/GAS_배포_규율.md`). 배포 전 버전 잔여 확인.
- 시트 헤더는 `_lfGetSheet_` 자가치유 로직(약 1087~1095행)이 신규 `보관위치` 열을 자동 보강하므로, 배포 후 첫 접수 때 열이 생깁니다.
- 프론트 2본(register + WP block)도 함께 반영.

## 검증 (완료 기준)
1. 시크릿 크롬으로 습득물 등록 페이지에서 **보관위치 칸이 보이고** 입력됨.
2. 테스트 접수 1건 → 시트에 `보관위치` 열 생기고 값 들어감.
3. 텔레그램 알림에 `보관위치:` 줄이 나옴.
4. 기존 습득장소·설명·등록직원 표시가 안 깨짐(열 밀림 없음).

## 주의 (함정)
- `reception_block.html`·`종합접수처_현황.html`의 `keepWhere`(라벨 "보관요청")는 **회원 분실물 폼의 죽은 키** — 재사용 금지. 이번 건과 무관(별개 정리 대상).
- 라이브 GAS가 저장소 사본보다 앞설 수 있음(드리프트) — 배포 전 라이브 폼 1회 육안 확인 권장.
