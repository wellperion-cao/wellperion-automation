## 건별 처리 절차

### 건 1 · 건 2 — 대조키 없음 (이마커스 · 이효주)

**왜 자동에서 뺐나**  
`apply_auto_assign()`은 GAS에 `keyPhone`(전화번호) 또는 `rowKey`(지문키) 중 하나를 반드시 동봉해야 한다. GAS는 이 대조키로 실제 행을 재검증한 뒤 수정하는 fail-closed 구조(INC-013·INC-020 재발 방지). 두 건 모두 두 키가 빈칸이라 자동으로 넣으면 rowIndex(행 번호)만 믿게 되고, 시트 행이 바뀌어 있으면 다른 사람 행을 덮어쓴다.

**처리 절차**  
1. 강습 원본 시트(GAS 대시보드가 아니라 실제 Google Sheet)에서 `이마커스` · `이효주`를 검색해 해당 행을 식별한다.
2. 실제 전화번호가 그 행에 있는지 확인한다. 있으면 lesson.html 화면에서 **이름 + 접수일 + 종목**으로 건을 찾아 수동으로 담당자 드롭다운을 선택·저장한다.
3. 전화번호도 없는 경우: 해당 인물이 실제 회원/문의자인지 브로제이 또는 다른 경로로 확인 → 전화번호를 시트에 먼저 입력(담당자 칸보다 먼저) → 이후 lesson.html에서 정상 배정.
4. 아무리 찾아도 전화번호가 없고 회원 확인도 불가하면 GM 보고 후 처리 방향(보류/LOSS) 결정.

**배정 후 담당자 안**  
- 이마커스(WSC 수영/골프/필라테스): 첫 종목(수영) 기준 → **박민서** 팀장  
- 이효주(성인 수영) → **박민서** 팀장  
*→ 확인 후 lesson.html 드롭다운에서 직접 선택·저장*

### 건 3 · 건 4 — 종목 팀장 미정 (김민정 · 노수정)

**왜 자동에서 뺐나**  
- **웰니스 프로그램** · **WSC 키성장 P.T** 두 종목은 `AMBIGUOUS_SPORT_KEYS`에 등록돼 있다.  
  이미 배정된 이력에서 최다 담당자를 실측했을 때 표준 편차 이내(3표 차 안)라 기계적으로 찍으면 틀릴 확률이 높아 제외(시토 실측 2026-08-07).  
- 시토가 GM께 이름 확인을 요청 중.

**처리 절차**  
1. **GM 회신 대기** — 웰니스 프로그램 담당·WSC 키성장 P.T 담당 이름 확정.
2. GM 이름 확인 후 lesson.html 화면에서 해당 건을 찾아 담당자 드롭다운 선택·저장.
3. 확정 이름이 드롭다운에 없으면 시토에게 강사 명단 추가 요청(membership.html 강사 로스터 수정).

**참고** — 코드 기준 유사 종목 팀장  
- 웰니스 → 발레/루프메소드 계열: `루프메소드` (외부 파트너, GM 지정값)  
- 키성장 P.T → PT 팀: `김상식` (단, 키성장 특화 담당이 따로 있을 수 있음 — GM 확인이 정본)

### 건 5 — 지문키 중복 (조이진 · 여름방학특강 - 체조)

**왜 자동에서 뺐나**  
GAS의 `lesson_inquiry_update` 액션은 `rowKey`(타임스탬프+전화번호 합성 지문키)로 행을 찾을 때 동일 키를 가진 행이 2건 이상이면 `fail-closed` 거부한다(어느 행인지 기계가 판단 불가 = 안전한 쪽을 선택). 조이진 건의 키가 2개 이상의 행에서 겹쳐서 거부됨.

**처리 절차**  
1. 강습 원본 시트에서 이름 `조이진` + 종목 `여름방학특강 - 체조` 로 행 전체 검색.
2. 나온 행 목록에서 **실제 문의 행(타임스탬프·접수 내용·상태가 실제 데이터)**을 눈으로 확인.
3. 중복 행(내용 없음·테스트성·빈 행 등)은 시트에서 해당 행 삭제 또는 빈 칸으로 비워 지문키 충돌 해소.
   - ⚠️ 삭제 전 반드시 두 행 중 어느 쪽이 실 고객 데이터인지 확인 — INC 기록(reference_row_index_delete_race_deleted_real_customers.md) 재발 방지.
4. 중복 정리 후 lesson.html에서 정상 배정: 체조 종목 → **이형주** 팀장.
