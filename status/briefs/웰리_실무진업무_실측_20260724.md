## ⑤ 서포트 후보 3개

1. **S3 결재대기 5건(전부 GM, 58일) 선제 알림** — 소유: **웰리(CEO)**. GM 본인 몫으로 두 달 가까이 멈춰 있는 결재 5건을 G1/텔레그램에 별도로 짚어주는 장치가 있는지 먼저 확인하고, 없으면 최소 배선(신규 스크립트 없이 기존 헬스체크·G1 렌더 경로에 편입)으로 표면화.

2. **월간운영계획 자동 진척 매핑 고도화** — 소유: **시우(COO)**. `sync.rule="status_map"`이 진행중 항목을 전부 `auto_value=50`으로 평탄 매핑해, 최소 4곳에서 사람이 수기로 "이 값은 미채택·정직 하향"이라 다시 조정하고 있다(반복 수작업). SSOT(TODO)의 실제 진행 단계를 더 세분화해 매핑하면 매달 반복되는 수기 보정이 줄어든다.

3. **마감초과·장기무갱신 자동 플래그** — 소유: **시우(COO)**. S3 최고령 10건(58일)과 월간운영계획 마감초과 2건(26일·55일)이 지금은 사람이 직접 문장으로 적어야만 드러난다(이번 조사도 수작업 스캔). 이미 존재하는 worklog_gaps류 감지 규칙에 "결재요청 후 N일 무처리" · "당초기한 경과 + 최근기록 M일 이상 없음" 규칙만 추가하면(신규 파일 0) 자동으로 잡힌다.

## 확인 불가

- S3의 91건(결재선 없는 순수 업무기록)이 실제로 "완결" 처리된 것인지, 애초에 결재가 필요 없는 성격인지는 필드만으로 구분 불가 — 카테고리·내용 개별 판독 필요(이번 조사 범위 밖).
- GM반려 1건(멤버십 7월 프로모션)이 이후 재작업·재제출됐는지는 S3 필드에 후속 이력이 없어 확인 불가.
- 월간운영계획의 `practitioner_progress`(개인 도달율)는 이번 조사 범위(업무&결재 SSOT·월간운영계획 진척)와 별개 지표라 심층 대조하지 않음 — 필요 시 별도 조사.
