## 확인된 사실 (재조사 불필요)

### 문의 유실은 없다
최근 30일 ②구간 하단 유입 **142건**(성인 66 + WSC 76) 전수 확인:
- 전부 실제 성명 + 010 연락처. 테스트·패딩 0건
- **ERP 강습 문의 목록에 142/142 전부 노출. 누락 0**
→ 시트를 직접 스크롤하는 사람만 못 본다. 화면 쓰는 실무진은 다 본다. **심각도 중.**

### 타임스탬프는 원인이 아니다
- 문자열(시분초 없음) 22건뿐이고 전부 ①구간(신규) 안에 있다 — 위치는 정상
- ②구간은 `isDate:true`(진짜 Date)인데도 오름차순 → **타입 수리로는 안 고쳐진다**

### 미착수 문의 45건 (별건)
최근 30일 중 담당자·연락이력·진행상황이 **전부 빈** 건: 성인 28 / WSC 17.
정렬 탓인지 정상 대기인지 **인과 확정 불가**(ERP엔 다 뜨므로 정렬과 무관하게 발생 가능).
