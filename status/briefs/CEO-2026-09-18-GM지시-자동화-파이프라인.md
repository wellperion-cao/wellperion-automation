## 1. 목표 파이프라인

**아침: 전일 이행 점검 (Close the Loop)**

```
전일 지시 이행 점검 → 현황 보고(✅🔄⚠️❌) → 미완료 자동 이월
```

**주간: 신규 지시 처리 — 입구 2개, 파이프라인 1개**

| 입구 | 상황 | 방식 |
|------|------|------|
| PC | 주 업무 시간 | 메모장을 지정 폴더(예: D:\GM지시\)에 저장 → 파일워처 자동 감지, 또는 기존 CLI 직접 전달 |
| 텔레그램 GM지시방 | 이동·현장·퇴근 후 | 봇 수신 |

두 입구 모두 동일한 정리 엔진 → 동일한 SSOT로 수렴한다. 정본이 하나면 입구 수는 무관하다.

```
GM 날메모 (PC 파일워처 / CLI / GM지시방)
   ↓
자동 정리 (표준 포맷 적용 + 완료 기준 부착 + 이월 건 병합)
   ↓
GM 확인 (초기 운영: 승인 후 게시)
   ↓
업무 SSOT 게시 (정본)
   ↓
담당별 배포 + [담당] 태깅 (AI 에이전트 + 사람 관리자)
```

**텔레그램 채널 구성 (시토 금주 셋업)**

- [ ] GM지시방 신설: GM + 웰리봇 2인 전용. 이 방의 모든 텍스트는 지시로 간주 — 분류·검열 없이 전부 파이프라인 처리
- [ ] 하루방: 웰리→GM 발신(알림) 전용 유지. GM지시방과 방향 분리, 혼용 금지
- [ ] AtoA방(GM·우열M·업무보고봇·CHRO봇): 협업방으로 유지. 날메모 입력 금지
- [ ] 라우팅 규칙: 인사·재무 태그 건은 웰리가 정리 완료 후 AtoA방으로 배포 — 우열M은 날메모가 아닌 완성본만 수신 (보안 + 공유 양립)

- GM이 하는 일은 메모 쓰고 전송, 승인 두 가지로 축소한다
- 기존 인프라 활용: welperion-automation 텔레그램 봇 라인 재사용 (신규 구축 최소화)

## 5. 전일 이행 점검 — Close the Loop (필수)

지시는 내려가기만 하면 방치된다. 매일 아침 웰리가 전일(및 이월) 지시의 이행 현황을 먼저 보고한다.

**아침 사이클 (신규 지시 정리보다 먼저 실행)**

```
전일 지시 대비 이행 점검 → 이행 현황 보고 → 미완료 건 자동 이월 → 오늘 지시 병합
```

- [ ] 상태 4분류로 보고: ✅완료 / 🔄진행중 / ⚠️중단·정체 / ❌미착수
- [ ] 미완료 건은 자동 이월 — GM이 다시 말하지 않아도 오늘 목록에 살아있어야 한다 (조용한 소멸 금지)
- [ ] ⚠️중단·정체 건은 사유 1줄 필수 (누가/무엇 때문에 막혔는지)
- [ ] 3회 이상 이월된 건은 🚩플래그 → GM에게 결정 요구: 계속 / 중단 / 재설계 중 택1
- [ ] 완료 처리는 완료 기준 충족 시에만 — "했습니다"가 아니라 산출물·결과 링크 첨부

**완료 기준(DoD) 부착 규칙**

- [ ] 웰리는 지시 정리 시 각 항목에 완료 기준 1줄을 붙인다 (예: "SSOT에 게시됨", "GM 승인 받음", "라이브 반영 확인")
- [ ] 완료 기준이 모호한 지시는 웰리가 GM에게 역질문해 확정한다 — 마무리가 안 되는 지시의 대부분은 끝의 정의가 없는 지시다

## 6. 상시 지시 분리 (핵심)

매일 반복 지시를 없애기 위해 지시를 2종으로 분리한다:

| 구분 | 정의 | 처리 |
|------|------|------|
| 상시 지시 (Standing Order) | "100%까지 계속", 체계 구축 등 지속 과제 | 에이전트별 상시 지시문에 1회 등록, 일일 메모에서 제외 |
| 일일 지시 | 신규 건, 변경 건, 예외 건 | 파이프라인으로 매일 처리 |

- [ ] 웰리: 26.9.17 지시 중 상시 지시로 전환할 항목을 분류해 GM에게 1차 제안할 것
- [ ] 이후 GM 일일 메모는 신규·변경·예외만 담는 것을 원칙으로 한다

## 7. 확장 — 사람 관리자 지시 추적 (동일 파이프라인)

AI 에이전트뿐 아니라 사람 중간관리자에게 내린 지시도 같은 엔진으로 추적한다. 목적: 관리자 지시 누락 제거 + "집중할 것에만 집중"하는 가이드 제공.

- [ ] [담당] 태그에 사람 포함: 이경연 실장 / 이정헌 소장 / 나우열M 등 3라인 리더
- [ ] 사람 지시는 기한 + 완료 기준 필수 부착 — 없으면 웰리가 GM에게 역질문해 확정 후 배포
- [ ] 배포 시 업무&결재 SSOT + 전사일정에 자동 등재
- [ ] 관리자별 "오늘 집중 업무 Top 3" 생성 — 전체 목록이 아니라 그날 봐야 할 것만 추려서 제공 (목록이 길면 아무것도 안 보게 된다)
- [ ] 아침 이행 점검에 사람 지시 포함 — ✅🔄⚠️❌ 4분류, 자동 이월, 🚩3회 이월 플래그 동일 적용
- [ ] 완료 확인: 관리자의 간단 회신 기준. 초기 2주는 GM이 주간 미팅에서 직접 크로스체크
- [ ] 리마인드 발신: 기한 전일 + 기한 당일, 웰리가 자동 발송 (채널: 관리자 텔레그램 또는 기존 카카오톡 — GM 확정 필요)

⚠️ 도입 원칙: 3라인 리더에게는 시행 전 취지를 직접 설명한다 — "감시"가 아니라 "GM이 같은 걸 두 번 말하지 않게 하는 장치"로 소개. 관리자가 시스템을 적으로 인식하면 보고 품질이 떨어진다.
