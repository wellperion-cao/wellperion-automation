## 4. 실행 (시토)

- `account_perms.json` 구조: `roles{역할: allow 목록}` + `accounts{계정: 역할}` — 빼기 목록 37개 두 벌 폐지. 관리자만 `all`.
- 앱 셸 첫 화면: 내 역할 모듈만 · 그룹 4 + 문서함. `modules.json` roles 칸 삭제(정보 0).
- 이름 사전 `erp_module_desc.json name` + 생성기 반영. 옛 용어 검사(canon 금지어) 생성기에 한 줄.
- 계정 이름 변경(coo@→manager@ 등)은 로그인 중인 실무진 안내 1통(웰리 · 중간관리자 방) 뒤 같은 날.
- 검증 = 계정 7개로 각각 로그인해 첫 화면 카드 수·목록 캡처(표 ③과 대조).
