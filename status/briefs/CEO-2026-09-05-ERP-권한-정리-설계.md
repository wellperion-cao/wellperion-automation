## 3. GM 결정 (2026-09-05 카드 답 · 확정)

1. **계정 2층 = 부서 메인 계정 + 개인 구글 계정.** 메인 계정은 부서마다 하나(경영지원부 cao@ · 운영부 info@ · 강습&파트너팀 lessons@ · 시설부 · 지원부 · 주차부 · 리셉션 키오스크 ask@). 직원·강사는 **개인 구글 계정으로 로그인 → 부서 선택 → 등록 신청(대기)** → **GM 승인 때 권한을 사람별로 분할**해 준다(부서 기본 권한 + 개인 추가/제한). 인사·재무도 이 방식 — 나우열M 개인 계정에만 인사·재무 모듈.
2. **개인 예외 2건:** 월간 운영계획 = 이경연 실장 개인 계정에만 / GM 업무 = 김남욱 GM 개인만.
3. **권한 관리 페이지 1장 신설(GM 전용 · GM 지시):** "권한 분할로 모듈 가능한 것들을 내가 보기 편하게 UI/UX 해서 페이지 하나". 대기 중 신청 → 승인, 사람 × 모듈 체크 매트릭스, 부서 기본 템플릿 — 아래 §4-2.
4. 문서함 = 정리 차원에서 OK(모듈 카드 자체는 GM 요청 아님 — 기존 ERP 를 고치는 선에서).
5. GM 추가 지적: "링크 이동해서 들어가고 안 들어가고 — 페이지 관련 정리가 하나도 안 됐다" → 페이지 이동(링크·뒤로가기·모듈 안 하위 페이지) 구조 정리는 **별도 건**으로 나중에(§5).

## 4. 실행 (시토)

### 4-1. 백엔드·앱 셸

- `account_perms.json` 구조: `dept_templates{부서: allow 목록}` + `accounts{계정: 부서}` + 개인 계정은 서버 DB(부서 + 개인 예외) — 빼기 목록 37개 두 벌 폐지. 관리자만 `all`.
- 앱 셸 첫 화면: 내 역할 모듈만 · 그룹 4 + 문서함. `modules.json` roles 칸 삭제(정보 0).
- 이름 사전 `erp_module_desc.json name` + 생성기 반영. 옛 용어 검사(canon 금지어) 생성기에 한 줄.
- 계정 이름은 바꾸지 않는다. 개인 계정 흐름을 켜는 날 실무진 안내 1통(웰리 · 중간관리자 방).
- 검증 = 메인 계정 7개 + 개인 계정 2(실장·나우열M)로 로그인해 첫 화면 카드 수·목록 캡처(표 ③·§3 예외와 대조).
- 개인 계정 흐름: 구글 로그인(배982 라이브) → 부서 선택 화면 → 대기 → 권한 관리 페이지에서 승인·분할.

## 5. 나중 별도 건 (GM 2026-09-05)

- **페이지 이동 구조 정리** — 모듈 안에서 링크로 드나드는 하위 페이지(가이드·안내·보고서)가 어디로 가는지·돌아오는지 정리가 안 됨. 문서함과 같은 날 하지 않고, 권한 정리 뒤 별도 설계(웰리) → 시토. GM 시점 지시 때 배로.
