# 배1076 — 권한 관리자 콘솔(admin.html) 서버 마운트

## 무엇을 했나
시모가 만든 `server/erp_auth/admin.html`(SPA)을 서버(`GET /auth/admin`)가 직접 내도록 바꾸고,
그 화면이 쓰는 데이터 API `GET /auth/admin/api/state`를 새로 붙였다. admin.html 자체는 손대지 않았다.

## 변경 파일
- `server/erp_auth/app.py`
  - `GET /auth/admin/api/state` 신설 — admin.html 맨 아래 STATE_SHAPE 그대로 반환. 관리자 아니거나
    관리자 비밀번호(`ERP_ADMIN_SITE_PW`) 미입력이면 401.
  - `GET /auth/admin` — 옛 서버 렌더(계정 표 + 권한 매트릭스)를 지우고 `admin.html`을 그대로 내려보내는
    걸로 교체. 로그인 안 했으면 여전히 `/auth/login`으로 보낸다. 관리자 확인은 화면 쪽(api/state 401)이 한다.
  - 옛 렌더 전용 함수 삭제(zero-caller grep 확인) — `_admin_row`·`_dept_badge`·`_delete_form`·
    `APPGROUPS`·`_matrix_row`·`_matrix_section`·`_perms_row`, GET `/auth/admin/{uid}/perms`(`perms_page`).
  - `_row_perms`는 `dept_apply`(POST, 유지)가 여전히 써서 남겼다.
  - POST `/auth/admin/{uid}/perms`(`perms_save`)는 그대로 두되, 리다이렉트 목적지를
    `/auth/admin/{uid}/perms` → `/auth/admin`으로 바꿨다(옛 상세 페이지가 없어져 그리로 가면 404가 났다).
- `server/deploy_auth.sh` — `admin.html`을 `app.py`·`account_perms.json`과 같이 서버로 올리는 줄 추가.
- `server/erp_auth/admin_mock.json`(신규) — admin.html의 `?mock=1` 미리보기가 읽는 목업 데이터.

## 실측
서버 15.164.151.105, `erp-auth` 재기동 후 직접(127.0.0.1:8000) 확인.

| 확인 항목 | 결과 |
|---|---|
| GET `/auth/admin`(쿠키 없음) | 303 → `/auth/login` (그대로) |
| GET `/auth/admin/api/state`(쿠키 없음) | 401 |
| 로그인 + 관리자 비밀번호 입력 후 GET `/auth/admin/api/state` | 200, 키 7개(`me·users·modules·dept_modules·common_modules·exception_ids·history`), 사용자 3·화면 105·이력 2건 |
| GET `/auth/admin`(로그인 쿠키) | 200, `text/html`, admin.html 내용 |
| 기존 POST `/auth/admin/{uid}/perms`(같은 값 재저장) | 303 → 리다이렉트 따라가면 200 |

브라우저(Playwright)로도 실제 도메인에서 로그인→관리자 비밀번호 입력까지 통과해 화면이 뜨는 것 확인
(`qa_screenshots/admin_console_live.png`). 관리자 비밀번호 입력 전 상태 화면도 확인
(`qa_screenshots/admin_console_live.png`을 덮기 전 캡처, 안내 문구 "관리자 확인이 필요합니다" 정상 노출).
미리보기(`admin.html?mock=1`, 서버 없이)는 로컬에서 별도 확인(`qa_screenshots/admin_console.png`).

## 알려진 제한(원인 있음, 별건)
- `api/state`의 `users[].google` 필드는 항상 `false`로 낸다. DB `users` 표에 구글 로그인 여부를 담는
  열이 없어(스키마에 없음) 판별할 방법이 없다 — 배지가 안 뜨는 것만 영향, 기능 차단 아님. 필요해지면
  스키마에 열 추가가 별도 작업.
