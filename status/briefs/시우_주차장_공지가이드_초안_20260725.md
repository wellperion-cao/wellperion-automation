### 1-2. CCTV 확인 요청 절차

1. **요청 접수** — 사고·컴플레인 당사자(회원/방문객/직원)가 CCTV 확인을 요청
2. **목적 확인** — 사고·민원 처리 목적만 허용(개인정보보호법 제35조 열람청구 + 기존 내부 규정 "사고·민원 처리 목적+책임자 승인 한정")
3. **책임자 승인** — 팀장·소장 승인 없이 임의 열람 절대 금지(기존 규정 유지)
4. **제3자 정보 보호** — 요청자 본인과 무관한 제3자(다른 차량·얼굴 등)는 모자이크·블러 처리 후 열람 제공
5. **열람 기록** — 열람일시·열람자·목적·승인자를 대장에 기록(사후 감사 대비)
6. **원본 미제공 원칙** — 화면 열람 또는 캡처 제공이 원칙. **원본 파일 반출은 수사기관의 공문 요청 시에만**

### 1-3. 경찰 접수 기준·절차

**기준(트랙 구분):**

| 상황 | 트랙 | 근거 |
|---|---|---|
| 고의로 타인 차량 파손(재물손괴 의심) | 형사 — 경찰 신고 | 형법 제366조(비친고죄 — 피해자 의사와 무관하게 진행 가능) |
| 자주식 차량 간 단순 접촉·과실 사고 | 원칙 민사(당사자 간 보험 처리) — 뺑소니·연락처 미상 시 신고 | 기존 내부 규정("양측 당사자 연결+보험 안내") |
| 쓰레기·담배꽁초 상습·악의적 투기 | 경찰 신고(경범죄) 또는 구청 신고(과태료) 병행 가능 | 경범죄처벌법 3조1항11호 / 폐기물관리법 8·68조 |

**절차:**
1. 현장 보존 — 사진 촬영 + CCTV 시각 기록(기존 규정 준용)
2. 경중 판단 — **직원 임의 판단 금지.** 팀장·소장 보고 후 신고 여부 결정
3. 신고 접수 — 112 신고 또는 인근 지구대 방문. CCTV 영상은 수사기관 공문 요청 시 협조 제공
4. 사건사고사실확인원 — 피해자가 보험 처리용으로 필요 시 관할 경찰서 민원실에서 발급 신청 가능함을 안내
5. 사후 기록 — 사고대장에 신고 여부·접수번호 기재 → 소장 서명(기존 규정 유지)

### 1-4. 관리자 책임 범위 (한계 포함)

- **자주식(회원 직접 주차):** 임치계약 미성립이 원칙 → 관리자는 시설 관리 주의의무(순찰·설비 점검)만 부담. 차량 자체의 도난·파손에 대한 배상책임은 원칙적으로 지지 않음. **단, 차단기 고장·조명 미비 등 시설 하자가 사고 원인으로 명백한 경우**는 별도로 관리자 과실책임(민법 제750조 불법행위) 발생 가능
- **발렛(직원이 차량 인수):** 묵시적 임치계약 성립 가능성 높음 → 선관주의의무 위반 시 배상책임. **이미 배상보험 가입·적용 중**(기존 규정 유지)
- **한계(불변 원칙):** 직원은 현장에서 배상액·과실 비율을 **임의로 판단·약속 금지.** 전액 보험사·법적 절차로만 처리(기존 내부 규정 그대로 유지 — 이 배에서 강화 없이 재확인만)

### 2-2. ★핵심 미정 구간 — "1~2시간 띄워 수업" 산정 기준 (GM 선택지, 시우 임의 확정 없음)

| 안 | 산정 방식 | 장점 | 단점 |
|---|---|---|---|
| **안 1 · 합산형** | 강습 시간만 합산(100+150=250분) 무료. 대기시간은 초과요금 부과 | 정책 취지(강습받는 시간만 무료)에 가장 부합, 무료 시간 악용 소지 최소 | LPR 시스템은 입출차 1회 기준으로 총 체류시간을 계산하는 구조 — "강습시간만 골라 합산"이 기술적으로 까다로움(재입출차 없이는 시스템이 자동 구현 어려움) |
| **안 2 · 구간별형** | 강습 A 종료 후 반드시 출차, 강습 B 전 재입차 — 각각 100분/150분 무료를 별도 세션으로 적용 | LPR 자동정산 구조와 정합(세션 단위 무료시간 적용), 시스템 구현이 가장 쉬움 | 회원이 1~2시간 공백마다 실제로 차를 빼고 다시 들어와야 해 번거로움 — 실제로는 시설 안에 머무는 경우가 많아 현실성 낮음 |
| **안 3 · 대기시간 포함 통합형** | 강습 A 시작~강습 B 종료까지 전체를 하나의 세션으로 보고 총 체류시간 전부 무료(대기시간 포함) | 회원 편의 최고, 시스템 구현 쉬움(무료 상한을 강습시간 합산값으로 늘린 쿠폰 발급 방식) | 대기시간이 길수록 사실상 장시간 무료주차 특전 — 형평성 문제(연속 강습 회원 대비) 및 방문객 요금 손실 가능성 |

- 세 안 모두 **회원 혜택 변경에 해당해 GM 결재 영역** — 시우는 확정하지 않음.
- 참고: 현재 THEHAM 시스템의 무료시간 반영 방식(쿠폰제)이 세션 단위인지 누적 단위인지는 이번 조사로 확인되지 않음 — 안 채택 전 시스템 기술 확인 필요(관리자 화면 실측 별도 필요).

### 2-3. 다른 차량 가져왔을 때 등록 절차 (배96 연계)

**현재 상태:** 문서화된 절차 없음(위 실측 §0 참고). 종합접수처 6종 분류에도 차량 항목 없음 — 배96(PENDING)이 이 공백을 다루는 중.

**초안 절차(배96 완료 전 임시 운영안 + 배96 접수 항목 신설 시 그대로 흡수 가능한 형태로 설계):**

1. 회원이 프론트·컨시어지에 차량 변경 사실 고지(방문 전 사전 연락 권장, 당일 현장 고지도 허용)
2. 프론트가 회원 본인 확인(회원번호·성함) + 기존 등록 차량번호 대조
3. 신규 차량번호를 주차관리부 담당자에게 전달(현재는 구두·문자 등 수기 — 배96에서 종합접수처 신설 항목으로 전환 시 그 폼으로 대체)
4. 주차관리부 담당자가 THEHAM 관리자 화면에서 기존 차량번호를 신규로 교체 반영(**1인 1차량 등록제** 원칙상 "추가"가 아닌 "교체" — `상품기획.html` 확정 원칙과 정합)
5. 반영 전까지는 방문객 요율(최초 10분 무료 후 10분당 1,500원) 적용 원칙 — 회원 무료시간 소급 적용 불가
6. 반영 완료를 회원에게 안내(문자/구두)
7. **개인정보 취급:** 차량번호는 개인정보 — 기존 접수폼(종합접수처)과 동일 수준으로 취급(외부 유출·임의 열람 금지, 접수 목적 외 사용 금지)

> 이 절차는 배96(종합접수처 차량 변경 접수 항목 신설 검토)의 설계 초안으로도 그대로 활용 가능 — 배96 진행 시 참조.
