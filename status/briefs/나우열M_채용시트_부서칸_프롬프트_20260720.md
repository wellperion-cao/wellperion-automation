# 나우열 매니저님께 — 채용 시스템 마무리 3가지 (붙여넣기용)

> 아래 **「여기부터 복사」 아래 전체**를 그대로 복사해서, cao 계정 AI(클로드)에 붙여넣으시면 됩니다.
> 배경 설명은 프롬프트 안에 다 들어 있어서 따로 설명하실 필요 없습니다.
> 작성: 시우(AI COO) · 2026-07-20 · 요청자: GM

## 왜 이걸 부탁드리는지 (매니저님용 3줄 요약)

1. 각 **부서 체계 페이지**에 "우리 부서 지금 누구 뽑고 있나"가 자동으로 뜨도록 배선을 깔았습니다 (시우 작업 완료).
2. 그런데 **채용 시트에 '부서' 칸이 없어서**, 지금은 공고 제목에 든 단어로 부서를 눈치껏 맞추고 있습니다 — 제목이 조금만 바뀌면 연결이 끊깁니다.
3. 그리고 **주차 공고가 옛 소속인 "(시설부)"로 등록**돼 있습니다. 주차관리부는 독립 부서로 정리됐으니 정정이 필요합니다.

---

## 여기부터 복사 ↓↓↓

당신은 웰페리온 인사(채용) 실무를 돕는 AI입니다. 아래 3가지를 순서대로 처리해 주세요.

### 배경

웰페리온은 채용 공고를 구글 시트(`db:hire`)에서 관리하고, Google Apps Script 웹앱이 그 내용을 웹페이지로 내보냅니다.

- GAS 웹앱 주소: `https://script.google.com/macros/s/AKfycbyyXrdM7nSXKPG3Dy8wI6_3AI1spZs24d-uHTzQZlsqzoRXKkFbSFnX-hr42D3ScQSSHQ/exec`
- 이 웹앱에 `{"action":"public-job-status"}` 를 POST 하면 현재 공고 목록이 나옵니다.
- 현재 응답 형태:
  ```json
  {"ok":true,"jobs":[
    {"position":"주차관리자 · 발렛파킹 (시설부)","bucket":"발렛파킹","status":"공고중","closed":false}
  ]}
  ```
- 이 응답을 **채용 공고 상세 페이지 5종**과 **각 부서 체계 페이지 5종**이 함께 씁니다.

### 할 일 1 — 채용 시트에 '부서' 칸 추가

`db:hire` 시트에 **'부서'** 칸(열)을 하나 추가하고, 기존 공고마다 값을 채워 주세요.

쓸 수 있는 부서 이름은 **아래 5개 중 하나만** 씁니다 (띄어쓰기·표기 그대로):

```
주차관리부 / 시설부 / 운영부 / 지원부 / 파트너팀
```

기존 공고 배정 기준:

| 공고 | 부서 |
|---|---|
| 주차관리자 · 발렛파킹 | **주차관리부** |
| 26.4. 주차관리자&발렛주차 | **주차관리부** |
| 남자사우나 주임 | 지원부 |
| 오전 골프 프로 | 파트너팀 |
| 운영부 사원 (리셉션) | 운영부 |
| 사내이사 수행기사 | 운영부 |

그리고 GAS 코드에서 `public-job-status` 응답에 이 값을 **`dept`** 라는 이름으로 함께 내보내도록 수정해 주세요. 즉 응답이 이렇게 되어야 합니다:

```json
{"position":"주차관리자 · 발렛파킹","bucket":"발렛파킹","dept":"주차관리부","status":"공고중","closed":false}
```

**중요:** 기존 칸(`position`·`bucket`·`status`·`closed`)은 이름도 값도 그대로 두세요. `dept`만 **추가**하는 것입니다. 기존 페이지들이 그 칸들을 쓰고 있어서 이름이 바뀌면 화면이 깨집니다.

수정 후 **웹앱을 새 버전으로 배포**해야 반영됩니다 (코드 저장만으로는 반영 안 됨 — 배포 > 배포 관리 > 새 버전).

### 할 일 2 — 주차 공고 소속 정정

현재 공고 제목이 `주차관리자 · 발렛파킹 (시설부)` 인데, **주차관리부는 시설부에서 분리된 독립 부서**입니다. 제목의 `(시설부)` 를 `(주차관리부)` 로 고쳐 주세요. 마감된 옛 공고(`26.4.주차관리자&발렛주차 (운영부 주차관리 파트)`)도 같은 이유로 `(주차관리부)` 로 정정하면 기록이 깔끔합니다.

### 할 일 3 — 채용 목록 허브 페이지 디자인 통일

파일: `3. 웰페리온 가이드/chro/recruiting/index.html`

- 공고 상세 페이지 5종(`parking.html`·`sauna.html`·`operations.html`·`golfpro.html`·`chauffeur.html`)은 2026-07-18에 **벤토 카드형 디자인**으로 이미 전환됐습니다.
- 그런데 **목록 허브(index.html)만 구버전 디자인**이고, 게다가 "채용중 / 준비중 / 마감" 표시가 **손으로 적은 고정값**이라 시트와 따로 놉니다.

두 가지를 해 주세요:

1. `index.html`을 상세 페이지들과 **같은 벤토 카드형 디자인**으로 맞춥니다. (색·폰트·카드 모양은 `parking.html`의 스타일을 그대로 가져다 쓰면 됩니다)
2. 카드 목록을 **손으로 적지 말고**, 위 GAS `public-job-status` 응답을 불러와 **자동으로 그리도록** 바꿉니다. 공고를 추가·마감할 때 시트만 고치면 허브가 따라오게 하는 것이 목적입니다.
   - 부서별로 묶어서 보여주면 더 좋습니다 (할 일 1에서 `dept` 칸이 생기므로 가능).
   - 조회에 실패하면 **빈 화면 대신 "채용 목록을 불러오지 못했습니다" 안내 + 문의 이메일**을 보여 주세요.

### 지켜야 할 원칙

- **값은 한 곳에만.** 급여·근무시간 같은 값을 여러 파일에 복사하지 마세요. 시트가 원본입니다.
- **없는 내용을 지어내지 마세요.** 모르는 값은 비워 두고 무엇이 비었는지 알려 주세요.
- 고친 파일은 **깃에 커밋·푸시**해야 실제 웹페이지에 반영됩니다.

### 다 하고 나서 확인해 주세요

1. 웹앱에 `{"action":"public-job-status"}` POST → 응답에 `dept`가 들어 있고 값이 위 5개 부서명 중 하나인가?
2. `https://wellperion-cao.github.io/wellperion-automation/chro/recruiting/` 를 **시크릿 창**으로 열어 → 허브가 새 디자인이고 공고가 자동으로 떠 있는가?
3. `https://wellperion-cao.github.io/wellperion-automation/coo/check/주차관리부 체계.html` 를 열어 → **"🧑‍💼 주차관리부 채용 현황"** 칸에 주차 공고가 떠 있는가?

3번까지 확인되면 완료입니다. 결과를 GM님과 시우(AI COO)에게 알려 주세요.
