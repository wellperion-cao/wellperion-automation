## ① `/api/todo` — GM 행 게이트 + GAS 와 같은 봉투

문제: `sync_todo.py` 는 `include_gm=1` 고정으로 미러를 뜨고, `api_todo.todo_list` 는 그걸 필터 없이 돌려준다. 업무 현황 SSOT 화면은 GAS 를 `include_gm` 없이 불러 **김남욱GM 행이 빠지는 것이 의도**(배326 · 무인증 중계 보호)다. 그대로 이으면 GM 개인 업무가 업무 현황 보드에 새로 노출된다.

`server/erp_api/api_todo.py` `todo_list()` 에 파라미터 2개·필터 1줄·봉투 2키 추가:

```python
def todo_list(
    status: Optional[str] = None,
    dept: Optional[str] = None,
    owner: Optional[str] = None,
    include_gm: int = Query(0, ge=0, le=1),   # GAS todo_list 와 같은 이름
    gmkey: str = Query(""),                   # GAS _gmKeyOk_ 와 같은 열쇠(환경변수 GM_TODO_KEY)
    limit: int = Query(100, ge=1, le=1000),
    offset: int = Query(0, ge=0),
):
    where, args = ["tenant_id = %s"], [db.TENANT]
    if not (include_gm == 1 and gmkey and gmkey == os.environ.get("GM_TODO_KEY", "")):
        where.append("creator <> %s"); args.append("김남욱GM")   # GAS 와 같은 기준 칸(생성자). 담당자 기준이면 owner 로 바꾼다 — GAS _gmKeyOk_ 쪽 판정 칸을 그대로 따른다
    ...
    return {"ok": True, "data": [_row(r) for r in rows],      # GAS 봉투 그대로 — 화면 어댑터 제거용
            "total": total, "count": len(rows), "limit": limit, "offset": offset, "rows": [_row(r) for r in rows], "_source": SOURCE}
```

- `rows` 는 남겨 둔다(이미 쓰는 화면 2장 — GM업무·_owner_directive.js 가 `rows` 를 읽는다). `ok/data` 는 추가.
- GM 행 판정 칸(생성자 vs 담당자)은 `.deploy-todo/업무&결재 현황.js` `_gmKeyOk_` 가 거르는 칸과 **같게** — 시토가 그 함수 한 번 보고 결정.
