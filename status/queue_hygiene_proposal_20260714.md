## ✅ 즉시 적용분 (커밋 완료)

### ① 완료훅 중복배 생성 — 코드 억제(가역)
- **원인지점**
  - `wellperion-agents/scripts/clevel_post_action.py` `update_queue_with_bridge()` — `--next` 마다 새 `NEXT-*` PENDING 배 무조건 append.
  - `scripts/auto_log_adhoc_to_queue.py` `main()` — 굵직한 커밋마다 새 DONE ad-hoc 배 append.
- **수리(둘 다 명시 마커일 때만 억제 · 애매하면 기존 동작 유지)**
  - `clevel_post_action.py`: `--next-parent <umbrella_task_id>` 신규. 지정 시 '다음'을 새 배로 만들지 않고 umbrella `note`에 한 줄 흡수(멱등).

- **효과**: 한 기능의 하위단계 완료가 umbrella 한 배로 모임. 순수 opt-in — 기존 파이프라인 무회귀.
- **서브에이전트 규약**: 하위단계 완료 시 커밋 본문에 `[umbrella:<본 배 task_id>]`를 달거나 `--next-parent`를 넘긴다. **별도 완료-배를 새로 만들지 않는다.**

- **GM 택**: ⓐ 권장대로 현행 유지 / ⓑ 특정 umbrella만 하위 흡수 지시(배 번호 지정).
