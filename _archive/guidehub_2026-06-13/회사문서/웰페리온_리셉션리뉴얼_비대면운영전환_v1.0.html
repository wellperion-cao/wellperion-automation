①입장 비대면 전환 — 예상 이슈 & 대책

카테고리주요 이슈대책 · 보완 방안
A
회원 서비스		바스타올 수령 — 수건 대여 혼선사우나·수영장 입장 시 자동 발권 키오스크 → 이용권 인증 후 수건 교환
신규회원 상담 — 가입 전환율 저하영상 안내 / QR 상담 접수 → 담당 매니저 전화 상담 연결
WSC 결제 후 주차 — 주차증 자동 발급 불가영수증 출력 시 "2번 상담실 방문하여 주차증 수령" 문구 자동 노출 + 안내 배너
B
출입·보안		문 제어 시스템 — 비회원 출입 위험회원카드 또는 얼굴 인식 기반 통제 · 유소년은 얼굴 인증 대체
비회원 체험·지인 입장 제한NOTICE 배너 설치 → 규정 강조 및 제재 진행
C
시설·용품		분실물 처리 — 담당자 부재로 문의 누락분실물 신고함 + QR 신고 접수 · 관리자 매일 확인
소모품 부족 (타올·어메니티)센서 기반 재고 알림 시스템 또는 일정 주기 점검 배정
D
고객 응대		불만 접수·CS — 즉시 대응 불가키오스크 내 '불만 접수' 메뉴 + CS 전용 번호 + 담당자 알림 시스템
긴급 상황 — 부상·응급 대응 지연AED · 응급키트 비치 + CCTV 모니터링 담당자 지정 · 비상벨 연동
E
운영 관리		결제 오류·환불 — 즉시 해결 불가자동 영수증 QR 환불 신청 → 관리자 일괄 처리
데이터 관리 — 정보 누락 위험회원 DB · 결제 내역 · 출입 로그 통합 관리 시스템 구축
F
마케팅·유지		신규 등록 전환율 저하QR 상담 등록 → 담당 매니저 자동 배정 → 24시간 내 전화 상담
재등록 리마인드 부재 — 회원 이탈자동 문자 — 만료 3일 전 · 당일 리마인드

③3 Core Zone System — 3개 상담실 활용 제안

1번 · FC
멤버십 회원 상담실
"매출과 회원 유지의 프런트"
  • 신규 가입 · 재등록 · PT · 그룹강습 · 유소년 프로그램 등록
  • 회원 이력·결제 이력·이용 패턴 즉시 확인
  • 자동 결제 시스템 (VOS 연동) — 상담 중 실결제 가능
  • 상담 데스크 2~3석 · 결제 태블릿 · CRM 모니터
  • 브랜드 디스플레이 (영상 · 후기)
2번 · CS
커뮤니티 & 브랜드 상담실
"사람 접점을 강화하는 감성 허브"
  • 주차권 발급 · 분실물 · 일반 CS
  • 회원 커뮤니티 미팅 · 이벤트 · 브랜드 홍보
  • 신규회원 웰컴 오리엔테이션
  • SNS 콘텐츠 촬영·인터뷰 공간
  • 카페형 인테리어 · 히스토리월 · 녹화용 배경벽
3번 · VOS
운영·관리 시각화실
"운영 데이터가 움직이는 관제실"
  • VOS 운영 — 매출·출입률·예약율·CS 실시간 대시보드
  • 문제 발생 시 알림 + 조치 로그 기록
  • 매니저 교육 · 운영 분석 · 리포트 작성
  • CCTV · IoT 연동 모니터링
  • 회의 테이블 + 브리핑 스크린 · 데이터 PC 2대

④키오스크 시스템 — "명확, 충분한 안내"

① 결제 키오스크
회원 결제 · 모두싸인 계약서
유소년 등록 시 주차권 제공 · 모두싸인 발송 시 서명 요청 · 결제 흐름 자동화
② 발권 키오스크
발권 단순화
아랫단 번호 최소화 · 발권으로 일어나는 이슈 정리 · 자동 발권 후 수건 교환
③ 안내 키오스크
와이드 모니터 정보 제공
정보 제공 → 예약·상담 문의 → 연락처·담당자·QR Survey 제공
  • 배너 설치 — 키오스크 역할·기능을 초등학생이라도 쉽게 따라할 수 있도록 NOTICE
  • 브로슈어로 웰페리온 이용 가이드 (성인 / 유소년 분류) 제공
  • 전체 흐름 — 고객 입장 → 키오스크 등록 → 상담 목적 선택 → 자동 상담실 배정 → 피드백 → 운영실 데이터 통합

⑤비대면존 운영 콘셉트 — 6대 핵심

① Clarity
명확한 안내 시스템
"고객이 스스로 이해하고, 혼란이 없도록 설계한다"
목표 보지 않아도 길이 보이는 구조
② Information Depth
충분한 정보 제공
"고객이 묻기 전에, 시스템이 먼저 알려준다"
목표 질문이 생기기 전에 답을 주는 시스템
③ Non-Contact Comfort
비대면의 편안함
"직원 없이도, 감정적 불편 없는 서비스"
목표 니즈 예약 시 분석·파악하여 빠르게 연결
④ Emotional Experience
감성적 브랜드 경험
"웰페리온 컬러·조명·향기·음향 통합 연출"
목표 웰페리온 브랜드 & 정체성 표출
⑤ Smart Feedback Loop
운영+CS 통합 피드백
"운영 데이터 + 만족도 + 이슈 접수의 통합 루프"
목표 루프가 돌수록 발전하는 서비스
⑥ Operational Autonomy
운영 효율의 자동화
"예약 → 결제 → 락커 → 입장 → CS의 자동 흐름"
목표 체계와 시스템으로 운영 전환
기대 효과 — Expected Outcomes
항목정량적 효과정성적 효과
상담 프로세스상담 대기시간 -30%회원 응대 품질 일관성 확보
운영 관리데이터 기반 의사결정률 +40%감에 의존한 운영 → 수치 기반 경영 전환
고객 경험재등록률 +8% · 이탈률 -10%브랜드 충성도 향상 · 입소문 효과
